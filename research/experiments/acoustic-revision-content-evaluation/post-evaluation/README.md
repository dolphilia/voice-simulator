# 封印後の静的診断

`reading-audit-20261003-v2` は、保存済み200件の認識文字列に対する辞書の読み候補監査。音声・ASR・ニューラル重みの実行をせず、原稿で候補を選ばない。元の台帳・個別認識・比較集計・封印へ上書きしない。

`reading_audit.py` の `DictionaryReadings` が公開MeCab C APIを既存ライブラリから呼ぶ。入力は短いNULなし文字列。上位16解析のうち、最上位と境界・品詞・活用・原形が一致するものだけを見る。全読みの網羅、意味の妥当性、実音の正解、完全音素列、自然さの資格は保証しない。数字等の後処理前の未知箇所を残す。辞書を変更したりユーザー辞書を登録したりしない。

読み候補を外部へ提供する場合は、既存辞書の `COPYING` を出力に併置し、そのハッシュを記録する。現在の出力には `DICTIONARY-COPYING` を保持した。

`reading-audit-20261003-v1` は初期化失敗と当時のソースを残した。v2でオプション文字列を引数配列へ変更し、同じライブラリと辞書で正常終了した。どちらも追加の音声生成・AI評価・学習は0回である。
