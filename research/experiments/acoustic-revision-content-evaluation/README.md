# 保存済み改訂音声の内容評価

承認済みの追加200回を独立ID `nas-content-20261002-v1` で実行する。教師生成・レンダー・学習は0回。既存の認識モデルと100 WAVを読み取り再利用し、通常／隔離の同一波形は重複評価しない。

既存Python環境で、`campaign.py`、`evaluate.py --engine whisper`、`evaluate.py --engine reazon`、`summarize.py` の順に実行する。契約と個別結果は追記のみで作成する。認識失敗も200回に計数し、再試行しない。容量はこの実験ディレクトリ全体、時間は契約開始から最大1時間。

内容保持は同文・同条件の既定HMMとの誤り数差で診断する。認識器間で平均せず、短文・長文・指定条件群ごとの悪化を残す。診断上の非悪化を自然さの非劣性と解釈しない。これらの結果で再学習やモデル選別をしない。
