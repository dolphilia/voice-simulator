# F0・継続長の切り分け：静的準備

[追加実験案](../../../docs/plans/acoustic-control-factorial-proposal-2026-10-02.md)の準備段階。生成・ASR・学習のcampaignは開始していない。追加枠の承認は未受領。

`controlled_axes.py` は、F0のみ・継続長のみ・共同補正の設定を計算する純粋関数。固定軸の指令が変わった状態を拒否し、制御範囲への飽和を記録する。実音響の軸間干渉をなくす保証ではない。

`prepare.py` は既存の前段と固定20係数の回帰で12文を解析し、旧文章との重複、語彙・三つ組文脈、目標値を保存する。音声生成の入口とニューラル依存を拒否した状態で実行する。旧32組の共同補正設定を再計算して照合し、単独軸の固定を検査する。入力原稿からの非ニューラル予測のみであり、新しい教師や認識音声は生成しない。

初版 `preparation-20261003-v1/` は「箱を運ぶ。」の既使用を検出して停止した。差し替え後の準備結果は `preparation-20261003-v2/`。実音響・内容・自然さの結果を、設定の静的検査で代用しない。実際のレンダーとASRには承認された別のcampaignと費用台帳が必要である。
