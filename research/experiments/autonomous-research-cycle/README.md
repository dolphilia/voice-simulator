# 包括予算による音声合成研究

2026-10-04承認の包括予算を共有して、新しいcampaignを実行する研究ワークスペース。
最終非ニューラル、品質条件、旧封印は維持する。

`budget.py` は処理前の永続予約、包括/個別回数・時間・容量、累積書込、
排他、失敗attempt計数、保存上書き拒否、外部変更照合を扱う。
`control/state.json` は全campaignで共有し、初期化し直さない。
各実稼働セッションを開始/終了し、停止中は時間を加算しない。
制御ファイルと結果を含めた保存量に余裕を確保する。

`test_budget.py` は上限の拒否経路を実際の一時領域で検査する。
この検査は音声品質の証拠ではない。

新しい成果は `campaigns/` に保存する。旧成果はhash参照とする。
途中状態・次の処理・費用は `progress.json` の追記版に残す。
