# 保存短イベントの局所周期性測定

承認済み `docs/plans/saved-short-event-alternative-meters-proposal-2026-10-03.md` を実施する。保存24信号に、30ms局所正規化自己相関と20ms局所調波説明率を各一回適用する。既知F0・駆動マスクは評価専用。旧評価コードを同一hashのまま参照し、既知有声域・境界の欠損を除去しない。

既存Python 3.11環境で `-B` を使い、`campaign.py`、`prepare.py`、`run.py`、`summarize.py`、`closeout.py`、`seal.py` の順に実行する。終了後は再実行しない。通信禁止の `offline.sb` をsandbox-execに渡し、NumPyの実行スレッド環境を `OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 OMP_NUM_THREADS=1` に固定する。学習・モデル・新環境・外部取得は使わない。

`prepare.py` は24WAV・正解・旧DIO保存値・旧評価・全ソースhash・全仕様を測定前に凍結する。二方式の開発を保存してから、確認を固定診断として実施する。開発不通過を確認で救済しない。結果後の方式選択・ensemble・閾値変更は禁止。

調波辞書のQR分解は6基底の局所最小二乗残差を計算するための固定行列処理で、測定値だけを返す。制御器のfit・波形逆推定・音声生成ではない。QR辞書はメモリ内で構築し、保存資産にはしない。窓の平均除去後にHannを掛け、基底自体は掛けない。これは計画にある「窓処理した信号へのsin/cos基底投影」を実装した解釈であり、測定前に固定する。

自己相関の局所最大は探索端でも隣接lagを計算する。選ばれた最大値が非正、放物線分母ゼロ・補間範囲外・F0範囲外なら欠損にし、次のピークへ再選択しない。調波同値残差は昇順格子の最初を使う。非有限・エネルギーゼロ・特異は明示的な不正測定として拒否する。低RMSの無声判定とは区別する。

上限30分・50MB、追加生成/AI/fit/逆推定/教師/取得0、非学習測定48、再試行0。失敗を含む測定予約48件を先に計数し、新規呼出数も別保存する。符号化後容量予約・排他保存・外部変更検出・旧19封印照合・終了封印を継続する。日本語の追加解析や旧主採択条件の改訂は行わない。
