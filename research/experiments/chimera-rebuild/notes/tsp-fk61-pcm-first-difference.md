# FK61_01で最初のPCM差が現れる段

## 読解と比較方法

第61版で固定上流と研究版のPCMが最初に異なった `FK61_01` のフレーム1989を調べる。以前に整えた女性の設定と本文を固定し、48 kHzの最初の2048出力フレームと、対応する96 kHzの内部4096標本を観測する。通常CLIのPCMは発話全体でも保存済み比較に照合する。 [事前登録](../cases/tsp-fk61-pcm-first-difference.json)・[第61版の観測](tsp-f2-full-held-candidate.md)

| 処理 | 読んだ箇所と比較する値 |
| --- | --- |
| 発話と放射 | 上流の `render::say` が `HumanVoice::render` を呼び、肺圧・声門・気道を内部レートで進めて `AirwayNetwork::step` の放射を得る。研究版は `ArticulatedVoice::step` から口端・鼻端・壁面の流量と合計の1標本差分を取得する。 |
| 間引き | 上流 `Decimator::with_taps` と研究版 `Decimator::new` は係数49個のKaiser窓付きFIRを作る。 `push` は内部標本2点ごとに、時系列の古い標本から係数を逆順に掛けて加算する。 |
| ゲインとDC除去 | 両実装は間引き後の値にゲインを掛け、`x[n] − x[n−1] + p y[n−1]` を計算する。 `p` は48 kHzで25 Hzに対応する極。ゲイン、極、直前値を固定して再計算する。 |
| リミッターと変換 | レベル包絡、保持フレーム、減衰を更新し、必要に応じてレベルを制限する。計測区間で制限が動作したかを確認し、最初の差が出るペアの隣接float32値と中点を求める。 |

放射差分にPCMより早い差があると予測した。両実装で実測したFIR係数とDC極を使い、放射入力を交換したときの出力を独立に計算する。各実装の係数と出力段で、入力側に対応するPCMが再現するかを見る。最後にフレーム1989で、丸め直前の値が隣接float32値の中点のどちら側にあるか照合する。 [出力段の計測入口](../tools/measure_tsp_fk61_pcm_first_difference.py)・[固定上流の声](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/src/voice/human_voice.rs)・[研究版の出力](../crates/vocal-core/src/output.rs)

## 実測

両実装とも通常CLIと観測器で得た発話全体のPCMが保存済みの値とバイト一致した。観測した2048出力フレームでは、最初の差が次の順に表れた。

| 観測点 | 最初の差 |
| --- | ---: |
| 口端流量、合計放射流量、放射差分 | 内部標本3968 |
| 壁面放射流量 | 内部標本3969 |
| 声門流量 | 内部標本3972 |
| 声門前後の圧差 | 内部標本3973 |
| 間引き、ゲイン、DC除去、包絡の倍精度値 | 出力フレーム1984 |
| float32のPCM | 出力フレーム1989 |

内部標本3968の口端流量は固定上流で `1.61485380506e-8 cm³/s`、研究版で `1.61485380972e-8 cm³/s` だった。標本3968は128標本ごとの制御更新境界で、両方で口端流量と放射差分が初めて非ゼロになった。観測区間の呼気ゲートは両方とも0で、鼻端流量は一致した。FIR係数49個、DC極とゲインが一致し、放射入力を交換した独立再計算は、どちらも入力側のPCMを全2048フレームでビット単位に再現した。観測範囲ではリミッターとソフトクリップの作動は0フレーム。 [各段の最初の差と入力交換](../runs/tsp-fk61-pcm-first-difference-20261123-a/summary.json)・[実測の出力係数](../runs/tsp-fk61-pcm-first-difference-20261123-a/artifacts/coefficients.json)

フレーム1989で、固定上流の変換前の値はfloat32の丸め中点より `1.11e-20` 下、研究版の値は `7.22e-22` 上にあった。このため隣接する二つの値に丸まり、出力に最初の差が現れた。観測した各段の順から、次は口端流量を作る分岐の更新を内部標本3967〜3970で調べる。 [中点と区間の実測値](../runs/tsp-fk61-pcm-first-difference-20261123-a/summary.json)

## 実行と保存

macOS 15.6.1 arm64、Rust 1.94.1、Python 3.14.4。通常CLI、観測器、係数の試験ビルドをRTL9210B-CGで実行し、観測した先頭区間、FIRとDCの係数、独立計算とログを保存した。

```bash
CHIMERA_RUN_STORAGE=rtl9210b CHIMERA_RUN_BYTES=4294967296 \
  ../../.venv/bin/python tools/measure_tsp_fk61_pcm_first_difference.py \
  tsp-fk61-pcm-first-difference-new
```

研究ワークスペースと `/tmp` から各4判定を通過した。出力係数、通常PCMの一致結果、観測区間と要約の4出力がバイト一致した。間引きで初めて差が出たフレームを1989に置き換えた監査対照は不合格だった。 [再実行](../runs/tsp-fk61-pcm-first-difference-20261123-repeat/manifest.json)
