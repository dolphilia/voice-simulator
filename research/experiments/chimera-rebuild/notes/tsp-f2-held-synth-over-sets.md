# 確認女性の合成F2を文集合ごとに集約する

## 読解と比較方法

第57・58版で測ったFKとFLの合成側の強勢付き `/ɛ/` のF2を、5件と10件の2文集合として保存記録から取得する。過去の音素対応と測定窓は固定し、同じ39位置・2値で事前に求めた女性10名と男女19名の参照を使う。対照は15件を直接まとめる集約、FLを先頭2件にした集約、両方とも先頭2件にした集約の3つ。 [事前登録](../cases/tsp-f2-held-synth-over-sets.json)・[確認話者別の計測](tsp-f2-pooled-reference-held-fl.md)

| 固定上流の関数 | 入力と更新順 |
| --- | --- |
| `score`、`held_out` | 話者の文集合ごとに合成の測定値を集める。話者IDがK・Lで終わる女性の文集合から `over_sets` の入力を作り、同じ女性向け学習参照を費用に使う。 |
| `term_defs`、`values` | 1つの文集合で有限な強勢付き `/ɛ/` のF2が3件以上ならHz中央値を求め、`log2` にする。支持数には有限測定数を入れる。 |
| `over_sets` | 文集合ごとの有限値に対して、もう一度中央値を求める。有効な集合数の下限は全体の半分を切り上げた数。2集合では1集合あれば値が出る。支持数は両集合の測定数の合計なので、支持数を持つ欠測値も生じ得る。 |
| `costs`、`fold`、`a_missing_measurement_has_no_cost` | 学習参照の中心と集約値の差を参照幅で割り、1を引いた値の非負部分を使う。値が欠測なら費用も欠測となり、有限なときだけ `formants` 欄に含まれる。 |

集合ごとに集約すると男女参照は全条件で費用0となり、女性参照はFK単独より費用0が増える一方で正の費用も残ると予測した。15件の直接集約では、少なくとも1条件で費用0になるかどうかが変わると予測した。固定上流の観測入口は実際の `over_sets` と `costs` を呼び、独立式はHz中央値、`log2` 値の中央値、費用の順に照合する。 [固定上流](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera-cli/src/compare/tsp.rs)・[観測入口](../tools/upstream_tsp_f2_training_reference_probe.rs)・[独立計算](../tools/measure_tsp_f2_held_synth_over_sets.py)

## 実測

FKの合成F2の中央値は2,059.93 Hz、FLは2,043.75 Hz。上流の `over_sets` は両集合の `log2(Hz)` 値に同じ重みを付ける。この2集合での値は幾何平均に当たる2,051.83 Hz相当だった。15件のHz中央値を直接求めると2,045.90 Hzとなり、値は5.92 Hz離れた。 [集約値と費用](../runs/tsp-f2-held-synth-over-sets-20261123-a/summary.json)

| 集約条件 | 支持数 | 女性参照で費用0 | 男女参照で費用0 |
| --- | ---: | ---: | ---: |
| 上流の文集合ごとの集約 | 15 | 73 / 78 | 78 / 78 |
| 15件を直接集約 | 15 | 78 / 78 | 78 / 78 |
| FLを2件にした対照 | 7 | 64 / 78 | 78 / 78 |
| 両集合を2件にした対照 | 4 | 0 / 78（全件欠測） | 0 / 78（全件欠測） |

女性参照で上流の費用が正だった5条件は、いずれも学習話者FAの音素に822.19 Hzを代入した条件だった。各条件で費用は0.03464。たとえば `FA01_03` の対応音素列の13番では、2,045.90 Hzは評価幅に収まり、2,051.83 Hzは幅を超えた。支持数が合計7になるFL不足対照の値は、支持数5のFKの値と一致した。両集合が不足した対照は、支持数が合計4でも集約値と費用が欠測だった。予測3件が成立し、基準を含む費用632点のうち474点は有限値が一致、158点は双方が欠測だった。 [固定上流の出力](../runs/tsp-f2-held-synth-over-sets-20261123-a/artifacts/native.json)

今回の集合はFKとFLから選んだ一部の発話に限る。次は確認女性の文集合を全発話へ広げ、同じ学習参照に対して集約値と費用0の頻度がどう変わるかを調べる。

## 実行と保存

macOS 15.6.1 arm64、Rust 1.94.1、Python 3.14.4。保存済みの2文集合のF2と参照を読み、固定上流の一時コピーに観測入口を追加した。ビルドと成果をRTL9210B-CGに保存し、上流の `over_sets` と独立計算を照合した。

```bash
CHIMERA_RUN_STORAGE=rtl9210b CHIMERA_RUN_BYTES=1073741824 \
  ../../.venv/bin/python tools/measure_tsp_f2_held_synth_over_sets.py \
  tsp-f2-held-synth-over-sets-new
```

研究ワークスペースと `/tmp` の両方で4判定と上流6試験に通過した。固定入力、上流出力、観測パッチ、上流試験結果、要約の5出力がバイト一致した。不足対照で欠測だった無介入時の費用だけを0へ変えた対照は、独立式との照合で不合格だった。 [再実行](../runs/tsp-f2-held-synth-over-sets-20261123-repeat/manifest.json)
