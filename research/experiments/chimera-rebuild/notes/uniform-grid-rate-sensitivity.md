# 一様管の3,250 Hzでセル長と時間刻みを分ける

## 上流の枝と観測点

固定上流 `c6147d0198890475dbe8a65a0bb8f56240c539b7` の `tests/airway.rs` にある `uniform_tube` は、`AirwayNetwork::add_tube` と `add_radiation` で40セルの一様管と最後のセル中心の放射負荷を作る。 `fdtd_peaks` は入口の `ext_flow` にインパルスを置き、`step` の出力で共鳴を測る。今回は前回と同様に元の体積流量を `radiated_flow` から直接取得する。 `TubeSpec::viscous(0)` で管内の粘性を外し、断面一定なので狭窄による非線形損失も消える。放射抵抗はそのまま用いる。[上流の試験と測定点](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/tests/airway.rs)・[上流の一様管と枝](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/src/airway/network.rs)

断面積 `A`、セル長 `Δx`、密度 `ρ`、音速 `c` のとき、節点コンプライアンスは `C=AΔx/(ρc²)`、隣接セル中心の枝の慣性は `L=ρΔx/A`。圧力 `pⁿ` の差から枝流量を半ステップ更新し、その流量を節点の収支へ使って `pⁿ⁺¹` を得る。口端では並列R–L負荷の慣性枝の旧値と新値の平均、および圧力の中点値から求めた抵抗枝の流量を足す。圧力は dyn/cm²、体積流量は cm³/s、枝慣性は g/cm⁴。入口の流量を指定し、上流の `step` が返す cm³/s² の放射差分も別の列として照合する。波動管は圧力波を往復させ、同じ負荷に流れる体積流量を比較点とした。[候補の一様管の更新](../crates/vocal-core/src/airway.rs)・[計測用の上流と波動管の入口](../tools/upstream_uniform_waveguide_probe.rs)・[共通の終端](uniform-waveguide-matched.md)

## 事前登録と対照

管は17.5 cm・3 cm²。体積0.001 cm³の入口インパルスと共通の6 kHz FIRを使い、3秒の記録を解析する。20・40セルと96・192 kHzの全組み合わせを計測する。40セルのまま96→192 kHzとした変化と、192 kHzを保って40→80セルとした変化も個別に比較する。80セル・96 kHzはクーラン数が1を超えるため、通常のCLIが出力を作る前に拒否することを確認する。主要観測点を3,250 Hz、比較する周波数を250〜3,750 Hzの16点、第4共鳴の探索窓を3,050〜3,650 Hzに固定した。[事前登録](../cases/uniform-grid-rate-sensitivity.json)

3,250 Hzの振幅差の変化について、時間だけを変えた差は0.25 dB以内、セル長を半分にした改善は0.35 dB以上かつ時間だけの変化の3倍以上と予測した。口端の半セルの慣性を理論上足し戻すと、96 kHz・40セルの振幅差の75%以上が解消すると仮定した。以前の0.9 dB基準は各周波数に適用し、前回の不通過を保存する。[以前の判定](../runs/uniform-waveguide-matched-20261121-bandlimited-b/summary.json)

## 伝達行列による独立計算

流量と同じ半時刻に圧力をそろえると、両変数の時間差分は `sΔ=2j·sin(ωΔt/2)/Δt` で表せる。枝の直列インピーダンスは `sΔL`、節点の並列アドミタンスは `sΔC`。 `T_L=[[1,sΔL],[0,1]]`、`T_C=[[1,0],[sΔC,1]]` とし、音圧・流量の列ベクトルを負荷から入口へ戻す。左右に半枝を持つ対称セルの全体は `T_sym=(T_{L/2} T_C T_{L/2})^N`。通常のセル中心の管はコンプライアンスがN個、間の枝がN−1個なので、左右の半枝を除いた `T_{-L/2} T_sym T_{-L/2}` になる。

波動管の終端アドミタンスは `Y_R=1/Rᵣ+1/(2j·fs·tan(ωΔt/2)·Lᵣ)`。FDTDでは旧・新の圧力の平均を取るため、半時刻の圧力に対する終端は `Y_R cos(ωΔt/2)`。任意の伝達行列 `T` で入口流量を1とすると、口端負荷の流量は `H=Y/(T₂₁+T₂₂Y)`。この式で、波動管から対称セルへの変更、口端の時間平均、口端半枝の除去、入口半枝の除去を順に測る。入口で直列要素を加減する行列の第2行は `[0,1]` なので、流量を指定する条件では入力圧だけが変わり、口端流量は変わらない。通常のセル中心の結果は、独立した節点の三重対角解とも照合する。[節点方程式](../tools/measure_uniform_waveguide.py)・[伝達行列と比較器](../tools/measure_grid_rate_sensitivity.py)

| 内部レート | セル数 | 3,250 Hz 振幅差 | 3,250 Hz 位相差 | FDTDの第4共鳴 |
| --- | ---: | ---: | ---: | ---: |
| 96 kHz | 20 | −1.763 dB | +1.116° | 3,400.97 Hz |
| 96 kHz | 40 | −1.487 dB | +2.058° | 3,393.78 Hz |
| 192 kHz | 20 | −1.571 dB | +0.690° | 3,396.96 Hz |
| 192 kHz | 40 | −1.278 dB | +1.606° | 3,389.71 Hz |
| 192 kHz | 80 | −0.823 dB | +1.262° | 3,379.23 Hz |

表の差はFDTDから同じレートの波動管を引いた値。波動管の第4共鳴はそれぞれ3,362.60 Hzと3,362.91 Hzだった。時間刻みだけを半分にすると3,250 Hzで0.210 dB改善し、その後セル長だけを半分にすると0.455 dB改善した。時間だけの対照の内訳はFDTDの振幅変化が+0.198 dB、波動管の離散終端による変化が−0.011 dB。空間側の改善は時間側の2.17倍で、登録した3倍の仮説は不通過。20・40セルの全組み合わせで求めた時間効果の平均は+0.201 dB、空間効果は+0.285 dB、二要因の差の差は+0.017 dBだった。以前の計測点に共鳴周辺を加えると、192 kHz・80セルにも3,350 Hzで−1.54 dBの差が残ることが分かった。[全16周波数の実測](../runs/uniform-grid-rate-sensitivity-20261121-a/summary.json)

40セルでレートを変えても初回の入口圧は1,064 dyn/cm²で一致した。与えた体積と入口のコンプライアンスが同じためである。次のサンプルでは旧圧力差から流量を進める刻みが異なり、96 kHzの325.11 dyn/cm²に対し192 kHzは879.28 dyn/cm²になった。192 kHzのままセル長を半分にすると同じ体積を受ける入口のコンプライアンスが半分になり、初回から2,128 dyn/cm²となった。口端流量が非ゼロになるのは40セルで内部サンプル39、80セルで79。初回の非ゼロ時刻は計算格子の支持を示す。[40セル・192 kHzの初期波形](../runs/uniform-grid-rate-sensitivity-20261121-a/artifacts/192k-40cells/native-prefix.csv.gz)・[96 kHzと192 kHzの元波形](../runs/uniform-waveguide-matched-20261121-long/manifest.json)

## 口端の半セル

96 kHz・40セルでは、3,250 Hzで波動管を基準にすると、対称セルの差は+0.222 dB。放射端で圧力を中点平均する影響は+0.034 dB。口端の半枝を除くと−1.743 dB変わり、入口の半枝を除いても口端流量の比は変わらなかった。口端の半枝だけを足し戻すと残差は+0.256 dBとなり、標準の差の絶対値を82.8%減らした。96 kHz・40セルの登録16点の最大差は3.05 dBから0.575 dBに下がる計算。一方、20セルでは、この補い方で差が増える点がある。周波数領域で確かめた対照であり、時間更新での安定性、減衰、軟壁や閉鎖時の挙動は別に検証する。[伝達行列の段別結果](../runs/uniform-grid-rate-sensitivity-20261121-a/summary.json)

離散節点の式と標準FDTDの伝達行列の相対複素差は1.47×10⁻¹³以下、帯域制限した時間系列と独立節点式の差は3.15×10⁻⁹以下だった。固定上流との時間系列も相対ピーク誤差1.45×10⁻¹⁴未満。再利用した2条件では、以前の確定実行と登録8周波数の値が完全一致した。CLIは80セル・96 kHzをクーラン数の条件で拒否した。[数値と登録判定](../runs/uniform-grid-rate-sensitivity-20261121-a/summary.json)・[コマンドと失敗対照](../runs/uniform-grid-rate-sensitivity-20261121-a/manifest.json)
