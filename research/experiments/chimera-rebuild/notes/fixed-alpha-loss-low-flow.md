# 固定 /ɑ/ の低流量側の損失変更と、高流量側との相互作用

前回は定常流量を超える順流だけで、二次損失を定常点の接線に替えた。今回は低流量側だけを変更し、無変更と両側の受動化を含めた4条件で、個別の複素差の和と同時変更の複素差を比べる。描画前に、双方の差は同時変更の複素差の1%未満になると予想した。 [事前登録](../cases/fixed-alpha-loss-low-flow.json)・[高流量側の対照](fixed-alpha-loss-high-flow.md)

## 枝の流量を求めるまで

固定上流 `c6147d0198890475dbe8a65a0bb8f56240c539b7` の `HumanVoice::render` は肺圧と声門の設定を更新し、内部標本ごとに `AirwayNetwork::step` を呼ぶ。固定姿勢プローブの `write_fixed_airway` では、咽頭入口に保存した流量を入れてこの気道網だけを進める。研究版は `vocal-cli render` → `render_fixed_airway` → `AirwayNetwork::step` → `Branch::step` と進む。 [上流の発声入口](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/src/voice/human_voice.rs#L371)・[上流の固定姿勢プローブ](../tools/upstream_sagittal_probe.rs#L269)・[研究版CLI](../crates/vocal-cli/src/main.rs#L371)・[研究版の枝の更新](../crates/vocal-core/src/airway/network.rs#L189)

枝の両端の圧差、印加源圧、前回の流量の運動量項を合わせた駆動項を `c` とする。固定姿勢では慣性 `L` と粘性抵抗 `R` が一定で、標本周期 `Δt` に対し `B = R + L/Δt` となる。枝の次の流量 `U`（cm³/s）は `c = BU + F(U)` を満たす。圧力損失 `F` は dyn/cm²。上流は流量を求めてから運動量と節点の流量収支を書き換え、壁、節点圧と放射負荷を更新する。短い狭窄の上流試験では全セルと1/4セルの形状で定常流を測り、ベルヌーイ近似に15%以内で一致することを確認する。 [上流の枝と節点](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/src/airway/network.rs#L1028)・[上流の狭窄試験](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/tests/airway_adversarial.rs#L92)

`Q₀ = 139.8857905134376` cm³/s、順流の係数を `K₊` とすると、接線は `T(U) = K₊Q₀(2U − Q₀)`。低流量側だけを変える対照では、`0 ≤ U ≤ Q₀` で `max(T(U), 0)`、逆流と `U > Q₀` では元の符号付き二次損失を使う。定常点で損失と傾きが連続し、仕事率 `UF(U)` は非負になる。駆動項で判定すると、区間は `0 < c ≤ BQ₀ + K₊Q₀²`。そのうち `c ≤ BQ₀/2` なら `U = c/B`、その上なら `U = (c + K₊Q₀²)/(B + 2K₊Q₀)`。この区間の外では既存の二次式を解く。上流と研究版の隔離ビルドだけにこの分岐を加えた。 [隔離差分の生成](../tools/measure_fixed_alpha_loss_tangent.py#L58)

## 4条件の複素差

固定 /ɑ/、96 kHz、通常発声と固定LFの保存流量、節点26→27の1枝と節点25→28の3枝を使った。切替は標本76,800。切替前の1標本、切替後128標本、最後の22周期19,200標本と直前の1標本を保存した。定常流のみの対照も再描画し、高流量側、両側の受動化、無変更の保存波形と照合した。

口端流量の直接DFTを入口流量の直接DFTで割った複素比を `H` とする。添字 `0` は無変更、`L` は低流量側のみ、`H` は高流量側のみ、`LH` は両側変更とする。相互作用は `(H_LH − H_H) − (H_L − H_0)`。同じ流量に4つの損失式を入れた場合、この差はゼロになる。再描画では条件ごとに枝流量が異なるため、各条件の流量で評価した損失から定常点の接線を引き、残差の組み合わせを選択枝と未選択枝ごとの圧力源として離散節点方程式に与えた。低流量側単独の効果も同じ方法で再構成した。 [4条件の計測](../tools/measure_fixed_alpha_loss_low_flow.py#L41)・[離散節点計算](../tools/measure_fixed_alpha_branch_loss.py#L179)

## 実測

低流量側の変更による複素差を、無変更の口端応答から線形予測へ向かう方向に射影した。この値は無変更時の複素距離に対する割合。相互作用は、個別効果の和と同時変更との差の大きさを、同時変更の複素差で割った割合で示す。

| 再入力 | 対象枝 | 周波数 | 低流量側の射影 | 相互作用 |
| --- | --- | ---: | ---: | ---: |
| 通常発声 | 1枝 | 660 Hz | +0.56% | 0.00894% |
| 通常発声 | 1枝 | 770 Hz | −2.51% | 0.00895% |
| 通常発声 | 3枝 | 660 Hz | +1.43% | 0.02244% |
| 通常発声 | 3枝 | 770 Hz | −6.36% | 0.02241% |
| 固定LF | 1枝 | 660 Hz | +2.72% | 0.00428% |
| 固定LF | 1枝 | 770 Hz | +1.98% | 0.00951% |
| 固定LF | 3枝 | 660 Hz | +6.90% | 0.01098% |
| 固定LF | 3枝 | 770 Hz | +5.03% | 0.02399% |

通常発声の770 Hzでは低流量側が高流量側の効果を弱めた。残る6条件では低流量側は高流量側と同じ向きに働いた。相互作用は8条件すべてで事前に予想した1%を下回り、未選択枝の寄与の大きさは相互作用の最大0.239%だった。同一の流量で評価した圧力損失の相互作用は全条件でゼロ。低流量側の最初の波形差は1枝で標本76,815、3枝で76,813の選択枝付近に現れた。相互作用が最初に観測閾値を超えたのは、通常発声で76,925、固定LFで76,926で、高流量側単独の差が現れた標本と一致した。 [再実行の複素値と最初の差](../runs/fixed-alpha-loss-low-flow-20261124-repeat/summary.json)

両版の時系列はピークに対して相対2.01×10⁻¹⁴以内、圧力損失の観測値と式は3.47×10⁻¹²以内、定常流対照は基準尺度に対して3.45×10⁻¹³以内で一致した。負の仕事率は丸め許容差を超えた標本が0件で、最小値は約−5.17×10⁻¹¹ erg/s。低流量側単独の複素差を相対4.59×10⁻¹¹以内で、相互作用を同時変更の複素差に対して相対1.14×10⁻¹¹以内で再構成した。一方、無変更時の流量に新旧の式を適用する直接項だけでは、低流量側の効果に対して最大0.673%の差が残った。
