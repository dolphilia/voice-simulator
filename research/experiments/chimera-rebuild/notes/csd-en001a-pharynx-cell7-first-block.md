# CSDの咽頭セル7で第1制御ブロックの流量収支を比較する

`en001a` の咽頭セル7では、初期面積だけを交換すると測定線5の座標交換後の全PCMを再現した。最初の内部2標本では体積速度が各版で一致していた。今回は96 kHzの第1制御ブロック128標本を採り、体積速度差が出る時刻と、その前後の圧力・枝流量を比較する。 [初期面積の実験](csd-en001a-pharynx-cell7-source.md)・[事前登録](../cases/csd-en001a-pharynx-cell7-first-block.json)

## 更新順と観測点

上流は `HumanVoice::control` で次の制御周期の断面を決め、研究版は `ArticulatedVoice::step_with_glottal_pressure` から `begin_tract_block` を通る。両版ともセル面積と長さを標本ごとに更新し、前後の体積の差から体積速度を得る。上流は差に内部レートを掛け、研究版は標本幅で割る。絞りがある場合は近隣へ配分し、その後に二段平滑して各節点の流量へ足す。 [上流の制御更新](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/src/voice/human_voice.rs#L457)・[研究版の幾何補間](../crates/vocal-core/src/airway/network/geometry.rs#L110)・[先行の体積源の独立計算](../tools/measure_tsp_fk61_node42_volume_source.py#L82)

隣接節点間の枝では、左右の圧力差に乱流圧を加え、前の流量を慣性に応じて引き継ぐ。慣性（g/cm⁴）は両半セルのセル長と断面積に、抵抗（dyn·s/cm⁵）は粘性に、非線形損失は狭窄後の断面拡大などに依存する。枝流量（cm³/s）を二次式から求めて節点の収支に足し引きする。壁の速度はその標本の更新前の節点圧力から求め、壁へ流れる体積速度を引く。セル7は節点20で、節点19〜21は内部にあり、放射負荷の中点式を使わず、圧力を `p += dt/C × 正味流入` で更新する。コンプライアンス `C`（cm⁵/dyn）は開いた直列セルでは体積を空気の体積弾性率で割った値となる。 [上流の枝と節点](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/src/airway/network.rs#L923)・[研究版の枝と節点](../crates/vocal-core/src/airway/network.rs#L724)・[枝と壁の独立計算](../tools/measure_tsp_fk61_lip_front_terminal_branch.py#L87)・[上流の気道の試験](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/tests/airway_adversarial.rs)

体積速度は全節点を独立に計算する。局所の圧力伝搬は節点19〜21と内側の枝19→20・20→21を再計算し、外側の枝18→19・21→22からの流量を採取値として与える。体積源、コンプライアンス、内側の枝係数、壁係数、外側の枝流量を個別に交換する。この比較で最初の制御ブロックにおける節点20の圧力差への寄与を測る。

## 実測

標本番号は96 kHzの内部時計で0始まり。差は各版の `initial_only − native`。すべての観測で節点19〜21の枝流量を加える前の値は二段平滑後の体積速度と一致した。内側2枝の乱流圧は各版の条件間で全標本一致した。 [再実行の要約](../runs/csd-en001a-pharynx-cell7-first-block-20261124-repeat/summary.json)

| 観測量 | 上流 | 研究版 |
| --- | ---: | ---: |
| 節点20のコンプライアンスの初差 | 0 | 0 |
| 節点20の更新後の圧力の初差 | 0 | 0 |
| 標本0の圧力差（dyn/cm²） | −4.235×10⁻²² | +4.235×10⁻²² |
| 標本0の正味流入差（cm³/s） | 0 | 0 |
| 左の枝19→20の流量の初差 | 1 | 2 |
| 右の枝20→21の流量の初差 | 1 | 1 |
| 節点20の壁流量の初差 | 1 | 2 |
| 節点20の配分前の体積速度の初差と差がある標本数 | 12、20/128 | 8、32/128 |
| 節点20の二段平滑後の体積速度の初差と差がある標本数 | 12、116/128 | 8、120/128 |

標本0の更新前圧力は全条件で0、正味流入は −3.6104565546888317×10⁻⁷ cm³/s。初期面積を交換すると上流のコンプライアンスは減り、研究版では増えた。この違いが `dt/C` を逆向きに変え、最初の圧力差の符号も両版で逆になった。

5群を個別に双方向に交換した。コンプライアンスだけを換えると両版で標本0の圧力を相手に一致させた。残差が最初に現れた標本は `native` に `initial_only` を渡す方向で上流4、研究版1だった。各群を単独で交換したときに残った最大圧力差は、同じ方向の上流で枝係数とコンプライアンスがともに2.220×10⁻¹⁴ dyn/cm²、研究版でコンプライアンスが3.952×10⁻¹⁴ dyn/cm²だった。体積源のみ、または外側流量のみの交換では、どちらの版も元の条件間差より最大残差が大きくなった。5群と初期状態をまとめて交換すると、3節点の圧力・壁運動と内側両枝流量が相手と完全一致した。外側2枝は採取値で与えており、ここで再現した経路は節点18・22より内側に限る。次は節点20の標本0のコンプライアンスだけを切り替える描画で、口端へ達する初差とPCMを測る。

## 実行と採取物

macOS 15.6.1 arm64、Rust 1.94.1、Python 3.14.4、NumPy 2.4.4で実行した。事前登録のSHA-256は `8a9e0526ebd0b6c202e5e085473a08076357221a90580d03083678e3afa56968`。固定上流の気道・幾何試験と研究版の再標本化試験を一時ビルドで実行した。両版の2条件について、先行実行と各201,600 PCMフレーム、歌唱計画、フレーム0・1・65の観測を照合した。全節点の体積計算・配分・平滑と、3節点の壁・圧力および4枝の流量を独立に再計算した。 [修正後の初回マニフェスト](../runs/csd-en001a-pharynx-cell7-first-block-20261124-verified/manifest.json)・[再実行のマニフェスト](../runs/csd-en001a-pharynx-cell7-first-block-20261124-repeat/manifest.json)

初回 `csd-en001a-pharynx-cell7-first-block-20261124-registered` は描画と採取後、集計に `wall_cm3_s` を取り込む列指定が欠けていたため `KeyError` で終了した。マニフェストを書き出す前の例外で、4本の観測CSVとPCMは外部ディスクの試行ディレクトリに残った。列指定を修正してその採取物を再集計し、新しい実行IDでも一時ビルドから再実行した。合否基準は事前登録時と同じ。4本の観測CSV、PCM、PCMハッシュと歌唱計画の記録、短区間の観測と両版の観測パッチの9出力は、初回と再実行でもSHA-256が一致した。 [初回の採取物](/Volumes/RTL9210B-CG/voice-simulator/scratch/chimera-runs/csd-en001a-pharynx-cell7-first-block-20261124-registered/artifacts)
