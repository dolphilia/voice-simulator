# 39箇所のF2介入に対する女性参照と男女参照の感度

## 読解と比較方法

第54版で使ったFA〜FEの強勢付き `/ɛ/` 39箇所に、同じ822.18949 Hzと2,009.78764 Hzを個別に代入する。女性10名と、第56版で実録音から測った男性9名の入力を利用する。比較のたびに同じ無介入の学習F2へ戻し、FKの録音・合成F2は固定する。各コホートの基準を原点にして費用の符号付き変化と絶対変動を求める。[事前登録](../cases/tsp-f2-pooled-reference-sweep.json)・[固定した男女の入力](../runs/tsp-f2-reference-pooled-sexes-20261123-repeat/artifacts/inputs.json)

| 固定上流の関数 | 入力と観測点 |
| --- | --- |
| `compare::tsp::run`、`measure_pair`、`score` | 録音と合成の同一IPAの組から測定する。通常のスコア入口は確認用話者と学習用話者を分け、録音の学習側測定から参照を組み立てる。今回の観測は、前段が保存した強勢付き `/ɛ/` の有効F2の直後から始める。 |
| `term_defs` と `values` | 3件以上の有限F2がある話者のHz中央値を `log2` に直す。1箇所の介入ごとに話者内中央値を作り直す。 |
| `reference`、`mad_sd`、`spread_floor` | 有効な同性話者5名以上で性別ごとの中心を求める。各話者から同性の中心を引いた残差をまとめ、その補正MADを求める。0.07オクターブの下限を適用して幅を決める。女性のみと男女の参照について、中心、性別内MAD、残差と下限適用前後の幅を保存する。 |
| `costs`、`fold`、`a_missing_measurement_has_no_cost` | 費用は絶対差を幅で割って1を引いた値の非負部分。診断欄 `formants` に記録される。上流試験は幅内の費用0、幅外の正値、欠測がNaNとなる場合を検証する。 |

男女をまとめると両側の最大変動が小さくなり、幅の下限に届く条件は減ると予測した。同時に、男女をまとめたことで個別の絶対変動が増える条件もあると予測した。固定上流の一時コピーに第56版で使った観測入口を読み込み、1回のビルドで78条件を実行する。第54版の女性のみ78条件と、第56版の1位置の男女両条件を再現してから、全156条件の集約を照合する。[固定上流](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera-cli/src/compare/tsp.rs)・[観測コード](../tools/upstream_tsp_f2_training_reference_probe.rs)・[計測入口](../tools/measure_tsp_f2_pooled_reference_sweep.py)

## 実測

| FKの診断費用 | 最大絶対変動（女性のみ → 男女） | 男女の方が小さい | 等しい | 男女の方が大きい |
| --- | --- | ---: | ---: | ---: |
| 録音 | 0.63034 → 0.40198 | 32 | 42 | 4 |
| 合成 | 0.11591 → 0 | 14 | 64 | 0 |

女性中心と女性内MADは各条件で一致し、男性9名の残差は全介入で一致した。評価幅の下限に達したのは女性のみで9条件、男女で0条件。FK合成側の費用は、女性のみでは78条件中64条件、男女では全78条件で0だった。録音側で費用0だったのは女性のみで0条件、男女で9条件。録音・合成とも、基準からの変動の符号が反転した条件は0件。事前予測3件を満たした。[全条件と件数](../runs/tsp-f2-pooled-reference-sweep-20261123-a/summary.json)

第56版で使った `FD19_10` の対応音素列の15番は、女性のみの最大変動を再現した。男女で録音側の最大変動を示した位置の一つは `FE25_07` の9番で、2,009.79 Hzを代入すると、参照中心は10.93027から10.96224 `log2(Hz)` へ移り、評価幅は0.11706から0.10677オクターブ、FK録音側費用は0.06433から0.46631になった。[固定上流の全156条件](../runs/tsp-f2-pooled-reference-sweep-20261123-a/artifacts/native.json)

録音側の絶対変動が増えた4条件はすべてFBの音素に高い方の値を代入したときで、増分の差は各0.02201だった。たとえば `FB07_02` の4番では参照中心は一定。女性のみの評価幅は0.10027から0.09417、男女の評価幅は0.11706から0.10677へ縮んだ。録音側の費用は女性のみで0.24257から0.32314へ増え、男女では0.06433から0.16691へ増えた。この比較は確認用FKの1話者で行った。次はもう一人の女性確認話者FLの録音・合成で、同じ参照と介入に対して評価幅内の費用0がどの程度続くか調べる。

## 実行と保存

macOS 15.6.1 arm64、Rust 1.94.1、Python 3.14.4。第56版の音響測定と音素対応を記録から読み、固定上流の観測入口を呼んだ。ビルドの一時ファイルをRTL9210B-CGに置き、固定入力、上流出力、要約、観測用パッチとログを保存した。

```bash
CHIMERA_RUN_STORAGE=rtl9210b CHIMERA_RUN_BYTES=1073741824 \
  ../../.venv/bin/python tools/measure_tsp_f2_pooled_reference_sweep.py \
  tsp-f2-pooled-reference-sweep-new
```

研究ワークスペースと `/tmp` の両方で4判定と上流6試験に通過した。固定入力、上流出力、要約、パッチの4出力がバイト一致し、上流と独立集計の基準値・介入結果も一致した。最大差の取得を1回に整理した現行コードで、保存済みの結果を第57版の監査で再計算した。[再実行](../runs/tsp-f2-pooled-reference-sweep-20261123-repeat/manifest.json)
