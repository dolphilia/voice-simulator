# 固定 /ɑ/ の定常点を超える順流だけで接線を使う

前回の受動化では、順方向の接線をゼロで下限処理した。定常点での圧力差と傾きは保てるが、それより低い順流域でも元の二次損失と差がある。今回は元の式と接線を定常点でつなぎ、元の二次損失と前回の受動化を対照にした。条件は描画前に登録した。 [事前登録](../cases/fixed-alpha-loss-high-flow.json)・[前回の受動化](fixed-alpha-loss-passive.md)

## 呼び出しと更新順序

固定上流 `c6147d0198890475dbe8a65a0bb8f56240c539b7` の `HumanVoice::render` は肺・声門の設定を更新して `AirwayNetwork::step` を呼ぶ。今回の上流プローブの `write_fixed_airway` は保存した声門流量を固定姿勢の咽頭入口に与え、同じ気道網を進める。研究版は `vocal-cli render` から `render_fixed_airway` に入り、`AirwayNetwork::step` を経て各 `Branch::step` を呼ぶ。 [通常発声の入口](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/src/voice/human_voice.rs#L371)・[固定姿勢プローブ](../tools/upstream_sagittal_probe.rs#L269)・[研究版CLI](../crates/vocal-cli/src/main.rs#L371)・[研究版の固定姿勢](../crates/vocal-cli/src/geometry_case.rs#L569)

固定姿勢では、上流が保持する運動量は前標本の枝流量に慣性 `L` を掛けた値になる。枝は前標本の節点圧差・枝の源圧とこの運動量から駆動項 `c` を組み立てる。粘性抵抗を `R`、標本周期を `Δt` とすると、`B = R + L/Δt`。次の枝流量 `U` は `c = BU + F(U)` を満たす。流量は cm³/s、駆動項と圧力損失は dyn/cm²。枝の流量・運動量を更新して両節点の流量収支に加え、続いて壁、節点圧、放射負荷を更新する。上流の定常狭窄試験は1セルと1/4セルの狭窄を0.25秒進め、流量をベルヌーイ近似の15%以内で照合する。 [上流の枝から節点への更新](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/src/airway/network.rs#L1028)・[研究版の枝](../crates/vocal-core/src/airway/network.rs#L189)・[上流の狭窄試験](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/tests/airway_adversarial.rs#L92)

## 高流量側の切替

元の式を `F₀(U) = K₊U|U|`（順流）、`K₋U|U|`（逆流）とする。`Q₀ = 139.8857905134376` cm³/s の接線は `T(U) = K₊Q₀(2U − Q₀)`。選択枝で `U > Q₀` のとき `T(U)` を、他の流量では `F₀(U)` を使う。接合点で値 `K₊Q₀²` と傾き `2K₊Q₀` が一致し、どの流量でも `U F(U) ≥ 0` となる。

`BU + F(U)` が単調増加するため、切替は既知の駆動項による `c > BQ₀ + K₊Q₀²` で判定できる。条件を満たす場合は `U = (c + K₊Q₀²)/(B + 2K₊Q₀)`、それ以外では既存の二次方程式の解を使う。この分岐を固定上流と研究版の隔離ビルドへ挿入した。 [隔離差分の生成](../tools/measure_fixed_alpha_loss_tangent.py#L58)

96 kHzで通常発声と固定LFの保存流量を再入力し、標本76,800で節点26→27の1枝、または節点25→28の3枝を切り替えた。切替前1標本、切替後128標本、最後の22周期19,200標本とその直前1標本を観測した。定常流のみの対照も実行した。圧力損失は前標本の圧差から慣性と粘性の項を引いて求め、新しい枝流量との積を仕事率（erg/s）として調べた。

660 Hzと770 Hzの口端応答は、注入流量と口端流量を直接DFTして複素比を取った。無変更からの差は高流量側だけの変更を含む。前回の受動化からの差の出発点では、双方の損失式が違うのは定常点より低い順流域だけで、その変更による流量の変化は境界を越えて他の標本や枝にも伝わる。両対照それぞれに対し、対照の流量で新旧の損失を評価した直接項、選択枝の流量が変わった分、未選択枝の流量が変わった分の3項を定常点の離散節点方程式に与え、再描画の複素差を照合した。 [圧力差と口端応答の計測](../tools/measure_fixed_alpha_loss_high_flow.py)

## 再実行と初回判定

最初の起動は隔離差分を作るPythonの分岐位置が誤っていて、実行記録を作る前に構文エラーで終了した。分岐位置を修正して描画した初回と別ディレクトリからの再実行では、定常点の増分抵抗を節点方程式に入れたうえで全損失の差を与えたため、増分抵抗を二重に数えた。複素差の再構成誤差は相対0.186〜0.239%となり、16判定が不合格だった。修正では各状態の損失からその流量で評価した定常点の接線を引き、2状態の残差の差を与えた。直接項では、同じ流量での差なので接線項は相殺される。判定の閾値を保ち、描画と隔離差分がバイト一致することを照合した。 [初回](../runs/fixed-alpha-loss-high-flow-20261124-registered/manifest.json)・[初回の再実行](../runs/fixed-alpha-loss-high-flow-20261124-repeat/manifest.json)
