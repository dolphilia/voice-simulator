# 加圧した軟壁管の閉鎖移動と再開口

## 上流の経路と更新順

上流の `a_realistic_sliding_closure_with_trapped_pressure_releases_without_spikes` は、40セル・17 cmの軟壁管の入口を円形ポートで固定圧力節点につなぎ、口端に放射負荷を付ける。肺圧は30 msで8 cmH₂Oまで上昇し、以後一定。上流の `PortSpec::new` の既定値に従い、1 cmの円形ポートに縮流係数0.4と拡大係数1.0を使う。壁の定数は `WALL_SOFT`、壁面放射割合は0。圧力はdyn/cm²、体積速度はcm³/s、出力は合計放射の時間差分でcm³/s²。[上流の境界テスト](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/tests/airway_adversarial.rs)・[上流のネットワーク](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/src/airway/network.rs)

64サンプルおきに、次のブロックの終端を評価時刻として、セル `k` の目標面積を `max(0, 3·[1−d·exp(−((k−x)/1.6)²)])` cm²とする。深さ `d` は50–75 msで0から1.3へ、400–412 msで1.3から0へ変わる。中心 `x` は100–350 msでセル30から24へ後退する。上流の `set_tube_targets` と `begin_block` は平均と最小の両断面を同じ目標に向けて補間する。

`step` は断面と体積源を更新し、狭窄が閉じると通常枝の流量と運動量をゼロにする。枝を更新した後に壁流量を節点収支から引く。閉鎖した内部セルの圧力は、開いた隣接セルの平均に時刻ごとに差の2%だけ近づく。開口部で閉鎖した場合は大気圧へ緩和し、放射流量も減衰する。閉鎖解除時にどの圧力から開いた枝を駆動するかが再開口の過渡を左右する。[体積移動](moving-area.md)・[壁振動](network-wall.md)

## 実装前に登録した比較

[ケース](../cases/sliding-closure.json)は96 kHzの57,600サンプル。上流テストと同じ窓で、開いたセルの最大圧力を肺圧の2.5倍未満、移動中の放射差分ピークを再開口の0.25倍未満、再開口のピークを閉鎖前の10倍未満とする。区間の端点は上流と同様に含めない。上流テストは、実装前の実行で開いたセルの圧力ピーク15,609.2 dyn/cm²、移動中・再開口・閉鎖前のピークをそれぞれ約5.18×10³、1.32×10⁶、4.11×10⁵ cm³/s²と出力した。

さらに、保持後半では肺側のセル20が肺圧の0.8倍超、口側のセル35が絶対値で肺圧の0.1倍未満と予測する。セル30と24で閉鎖を観測し、周辺で閉鎖した節点に接する通常枝の流量がゼロであること、再開口後に全セルが初期断面に戻ることを確かめる。候補と上流で全セルの圧力・面積、閉鎖周辺の枝、壁、放射を照合し、各観測列の最大絶対差は上流同列のピークに対して `10⁻⁹` 未満を目標とする。上流の公開状態を取得するプローブの区間ピークは、ネイティブテストが出力したピークとも照合する。

## 実装と結果

CLI で管、ガウス形状の幅、中心と深さの時刻列を指定する。Rust は制御ブロックの終端で二つの時刻列を補間して各セルの面積目標を計算し、既存の `AreaProgram` へ渡す。上流比較用の入力は Python で独立に展開し、上流プローブが公開 API へ渡した実際の目標列を `upstream-input.txt` に保存する。[候補の軌跡](../crates/vocal-cli/src/network_case/constriction.rs)・[計測器](../tools/measure_sliding_closure.py)

57,600サンプルの10判定が通過。上流113系列の最大差は、各基準系列のピーク比で `1.82×10⁻¹²`。開いたセルの最大圧力は15,609.17 dyn/cm²で肺圧の1.990倍。閉鎖保持後半のセル20の平均圧力は肺圧の99.998%、口側のセル35の最大絶対圧力は肺圧の `5.51×10⁻⁷`。観測した閉鎖枝の78,990サンプルは流量ゼロで、再開口後の全セルの面積は初期値との差が `1.25×10⁻¹⁴` cm²未満だった。[実行結果](../runs/sliding-closure-20261119-b/summary.json)

移動時の放射差分ピークは再開口時の0.394%、再開口時は閉鎖前の3.20倍だった。保存した候補CSVで、30 msより後の `abs(radiation_flow_derivative_cm3_s2)` の最大行はサンプル6312（65.75 ms）。閉鎖を形成している区間で、セル30の面積は0.541375 cm²、放射差分の絶対値は `1.73×10⁶` cm³/s²だった。上流ネイティブテストの全体ピークも同じ値を報告している。閉鎖形成と再開口を別の窓で測ると、この差が見える。[計測要約](../runs/sliding-closure-20261119-b/summary.json)・[CSVの所在とハッシュ](../runs/sliding-closure-20261119-b/manifest.json)
