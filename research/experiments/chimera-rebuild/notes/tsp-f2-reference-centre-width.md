# 同じF2介入で参照中心と評価幅の寄与を測る

## 読解と比較方法

保存済みの5名・10名の比較から、録音側FKの費用の変動がともに最大になった `FD19_10` の対応音素列の15番を固定した。元のF2は1,763.88308 Hz、介入値は2,009.78764 Hz。この実行では保存済みのF2から集約をやり直すため、録音・合成の音素境界とLPC窓も前回のままにした。各コホートの基準と介入から得た2中心×3幅をFKの同じ録音・合成の値に適用し、計24点を比較した。[事前登録](../cases/tsp-f2-reference-centre-width.json)・[前回の読解](tsp-f2-training-reference-ten-speakers.md)

| 固定上流の関数 | 入力と処理 |
| --- | --- |
| `compare::tsp::run` → `score` → `values` | 対応音素の強勢付き `/ɛ/` から話者ごとのHz中央値を算出し、`Values.terms` に `log2(Hz)` で保存する。FKの録音・合成の二つの値は介入中に固定する。 |
| `reference`、`mad_sd`、`spread_floor` | 参照の3要素は `(中心, 費用に使う評価幅, 性別内の補正MAD)`。女性のみの今回のコホートでは補正MADと0.07オクターブの大きい方が評価幅。同じ中心のまま補正MADを幅に渡す条件も測り、下限による差を得る。 |
| `costs`、`cost` | `Values` の値と参照中心の絶対差を計算する。幅が正で両方が有限なら `max(0, 絶対差 / 幅 − 1)` を返す。絶対差が幅以下なら費用0。 |
| `group_of`、`fold`、`a_missing_measurement_has_no_cost` | `F2 ɛ` は `formants` の診断に入る。試験では幅0、欠測、幅の内側で費用0、外側で正となる例を確認している。今回の観測入口も `costs` と `fold` を実際に呼ぶ。 |

基準→中心のみ→両方と、基準→幅のみ→両方の二経路を測る。各経路で録音・合成の費用差を別々に保存し、どちらの順序も両方を変えた差へ合計できることを照合する。片方の効果はもう片方を先に変えたかで異なるため、両順序の平均と、順序で動いた差も保存する。参照幅の下限を外す列は、同じ中心で評価幅だけを変える数値対照とする。[固定上流](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera-cli/src/compare/tsp.rs)・[観測入口](../tools/upstream_tsp_f2_reference_centre_width_probe.rs)・[独立計算](../tools/measure_tsp_f2_reference_centre_width.py)

## 実測

| 学習話者とFKの区分 | 無介入 | 中心のみ | 幅のみ | 中心と幅 | 中心と下限適用前の幅 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 5名・録音 | 0.14472 | 0.23590 | 0.36575 | 0.47453 | 4.34714 |
| 5名・合成 | 0.28245 | 0.19128 | 0.53008 | 0.42130 | 4.15409 |
| 10名・録音 | 0.24257 | 0.30750 | 0.77992 | 0.87292 | 1.05370 |
| 10名・合成 | 0 | 0 | 0.11591 | 0.02291 | 0.12165 |

録音側は5名・10名とも幅だけを変えた増分が中心だけの増分を上回った。10名で両順序を平均すると、総増分0.63034のうち中心の寄与は0.07896、幅の寄与は0.55138だった。5名と10名の総増分の差0.30053も、平均した幅の寄与が0.32155増え、中心の寄与が0.02102減ったことで説明できる。この内訳は2つの差し替え順を同じ重みで平均した結果。[独立計算の全24点](../runs/tsp-f2-reference-centre-width-20261123-a/summary.json)

10名の合成側で、無介入の中心とFK値の差は0.07811オクターブで、幅0.10027以内だった。幅だけ0.07にすると費用が0.11591になった。中心も介入後へ替えると絶対差が0.07160へ縮み、費用は0.02291まで下がった。第54版の計測ノートに残っていたこの条件の費用0という記載を訂正した。固定データと計測結果は一致している。[固定上流の再計算](../runs/tsp-f2-reference-centre-width-20261123-a/artifacts/native.json)・[第54版の上流出力](../runs/tsp-f2-training-reference-ten-speakers-20261123-repeat/artifacts/native.json)

介入後の補正MADは5名で0.01930、10名で0.06384オクターブ。上流の0.07の下限を使うと、録音側の費用は補正MADを直接使ったときより、それぞれ3.87261と0.18078下がる。3つの事前予測を満たした。コホートの比較には女性の残差だけが入った。次は同じ `FD19_10` の1介入を使い、実録音から得た男性学習側の残差を加えると、女性参照の中心・幅・FK費用のうち何が動くかを見る。[保存した参照と確認値](../runs/tsp-f2-reference-centre-width-20261123-a/artifacts/inputs.json)

## 実行と保存

macOS 15.6.1 arm64、Rust 1.94.1、Python 3.14.4。固定上流の一時コピーに観測入口を追加し、既存の `costs` と `fold` を呼んだ。2つの保存済み計測と上流出力を照合し、コマンドとハッシュ、標準出力、診断の全観測を実行記録に保存した。

```bash
CHIMERA_RUN_STORAGE=rtl9210b CHIMERA_RUN_BYTES=1073741824 \
  ../../.venv/bin/python tools/measure_tsp_f2_reference_centre_width.py \
  tsp-f2-reference-centre-width-new
```

研究ワークスペースと `/tmp` からの再実行はそれぞれ4判定と上流6試験に通過した。固定上流と独立計算は全24点で数値が一致し、入力、上流出力、パッチ、上流試験ログ、要約の5出力が再実行でバイト一致した。[再実行](../runs/tsp-f2-reference-centre-width-20261123-repeat/manifest.json)
