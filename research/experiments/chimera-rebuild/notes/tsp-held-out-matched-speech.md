# 確認用12発話の音源と初期舌先を揃える

既存の調整用6発話から独立した確認用12発話を、登録順のまま用いる。女性・男性それぞれ6発話で、`fine` を含む女性の `FK64_08` と `seems` を含む男性の `MK61_01` も含める。既定音源と同じ揺らぎを与えた `fine` では全PCMの最大差は1.16×10⁻¹⁰だった。揺らぎを0に揃え、初期舌先も一致させた `seems` では4.66×10⁻¹⁰だった。今回は通常の上流設定を全確認用発話に適用して同じ傾向が得られるかを測る。[事前登録](../cases/tsp-held-out-matched-speech.json)・[先行の初期舌先比較](tsp-seems-initial-tip.md)

## 上流の読解

- `crates/chimera-cli/src/render.rs` の `say` は英語辞書から音素を得て、`phonetics/planner.rs` の `plan_phrases` で体型と基準F0（男性112 Hz、女性205 Hz）を使った計画を組む。開始時刻0.05秒を渡し、発話末尾に0.3秒を足して48 kHzの出力長を丸める。同じ `say` がTSP評価の合成にも使われる。計画の音素位置には秒を使い、比較では半開のフレーム区間へ揃える。
- `voice/human_voice.rs` の `HumanVoice::new` は自由舌先の休止位置で初期の気道を作り、男性の出力ゲイン5.5×10⁻⁷に体型の倍率を掛ける。女性は0.875倍で4.8125×10⁻⁷。`apply_source` は既定のドリフト5セント、roughness 0.1から周期のジッター0.00455とシマー0.042を指定する。`control` は発話計画を128内部標本ごとに評価し、96 kHzの `render` が声門面積、圧差（dyn/cm²）、口端・鼻端・声道壁の流量（cm³/s）、放射差分を更新する。
- `sources/glottis.rs` の `ParametricGlottis::next` はF0を周期倍率で割った位相増分を蓄積し、周期の境界で種777の乱数から周期倍率、振幅倍率の順に更新する。圧差は平滑化と有声度を介して面積へ伝わる。放射の流量差分には独立な間引き・DC除去・レベル調整を適用して同じ48 kHz出力へ照合する。研究版の `timing_case/speech_voice.rs` では同じ3つの揺らぎを既存の入力項目から渡す。
- `tests/golden_planning.rs` は発話と区間の計画を、`tests/golden_voice.rs` はPCMとブロック分割時の一致を検証する。今回は各版の合成計画の音素境界を使い、PCM差が現れた48 kHzの標本番号を両方の計画へ対応付ける。

## 実測

固定上流の通常CLIを全12発話で再実行し、保存WAVと観測器の全PCMに一致することを確認した。研究版の入力は、舌先の休止座標、体型別ゲインと音源の揺らぎ3値だけを設定した。対応する通常CLIと観測器の全PCMが一致し、元の研究版の計画も維持された。休止舌先は全発話で独立に計算した座標と一致した。

| 観測 | 結果 |
| --- | ---: |
| PCMを比較したフレーム数 | 1,487,586 |
| 両版で音素列・強勢・区間が一致した発話 | 12 / 12 |
| 一致した計画音素 | 316、うち母音122 |
| −35 dBの発話区間が一致した発話 | 12 / 12 |
| 設定を揃える前の全発話での最大PCM差 | 0.8124529421 |
| 設定を揃えた後の全発話での最大PCM差 | 1.8626451492×10⁻⁹ |

先頭32フレームは全発話で一致し、全PCMにおける閾値1×10⁻⁶の超過は0件だった。最大差は女性の2発話で同じ値だった。 `FK61_01` では第16,682フレーム（約347.54 ms）の `plea` の /i/、`FK61_02` では第129,260フレーム（約2,692.92 ms）の `stranger` の /ɝ/ に現れた。両箇所の差は隣接するfloat32値の1刻み。子音の例では、女性の `FK64_09` の /f/ で最大9.31×10⁻¹⁰だった。 `FK61_01` の最初の内部差は第3,968標本の口端流量と放射差分、`FK61_02` では第4,879標本の声門流量だった。記録した音素は合成計画の区間で、ビット差が計画音素の間や発話の減衰区間に現れる場合もある。

独立計算した周期位相は全観測標本で一致し、研究版の振幅倍率も一致した。20 ms窓の平均二乗を累積和でも求め、最大差2.62×10⁻¹⁴を確認した。音素計画の区間は通常入力と調整後入力で同じだった。計測6判定と事前登録の3仮説はすべて成立した。[発話別の集計](../runs/tsp-held-out-matched-speech-20261123-repeat/summary.json)

次は設定を揃えたPCMを既存のTSP母音評価へ渡し、既存の対応区間でLPC候補・採択F2・欠測がどう変わるかを照合する。実録音との比較には、すでに登録した窓と条件を使う。

## 再実行

`research/experiments/chimera-rebuild` で別の実行IDを指定する。

```bash
CHIMERA_RUN_STORAGE=rtl9210b CHIMERA_RUN_BYTES=2147483648 \
  ../../.venv/bin/python tools/measure_tsp_held_out_matched_speech.py tsp-held-out-matched-speech-new
```

両版の全PCMは `matched-pcm.npz`、設定を揃えた入力と両版の計画は発話IDごとのフォルダに保存した。96 kHzの観測系列は内部状態の比較に使い、保持した要約に最初の差と最大差を記録した。実行環境はmacOS 15.6.1 arm64、Rust 1.94.1、Python 3.14.4、NumPy 2.4.4。一時ファイルと計測成果はRTL9210B-CGを使用した。[初回](../runs/tsp-held-out-matched-speech-20261123-a/manifest.json)・[再実行](../runs/tsp-held-out-matched-speech-20261123-repeat/manifest.json)

実験ディレクトリと `/tmp` から実行し、PCM、各発話の入力と計画、要約の38出力がバイト単位で一致した。固定上流10試験、研究版17試験は両回で通過した。[固定上流の試験ログ](../runs/tsp-held-out-matched-speech-20261123-repeat/artifacts/upstream-tests.log)・[研究版の試験ログ](../runs/tsp-held-out-matched-speech-20261123-repeat/artifacts/candidate-tests.log)
