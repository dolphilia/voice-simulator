# 確認女性FK・FLの全発話でF2を集約する

## 読解と比較方法

第59版はFK・FLそれぞれ6録音を元に合成F2を集約した。今回は固定上流の音素注釈にあるFKの第61〜66リストとFLの第67〜72リスト、各60発話を使う。全発話を同じ固定上流でレンダー・整列・計測し、前回と同じ女性参照と男女参照、39位置×2値を使って、発話範囲だけを変えた対照を作る。 [事前登録](../cases/tsp-f2-full-held-women.json)・[部分文集合の比較](tsp-f2-held-synth-over-sets.md)

| 固定上流の関数 | 入力と処理順 |
| --- | --- |
| `compare::tsp::run` と `load_utts` | 文ID、話者ID、文、録音音素境界（秒）を読み、指定した話者の全発話を選ぶ。 |
| `say_all`、`align_synth` と `mfa.yaml` | 文IDと性別の組で固定上流の合成を行う。合成音に整列用の微小雑音を足し、G2P辞書とMFAで音素境界を測る。整列は各発話を独立に扱い、ディザと話者適応を無効にする。 |
| `measure_pair`、`match_phones`、`Sig::formants` | 文ごとに同じIPAの音素を対応させ、元録音と雑音を加える前の合成を計測する。対応音素の強勢は合成側に揃える。女性のF2は間引いた12 kHzの波形から、音素の35、50、65%を中心とする25 ms窓を使い、12次LPCで得た値の中央値を求める。 |
| `values`、`over_sets`、`costs`、`fold` | 各文集合の有限で強勢付き `/ɛ/` のF2からHz中央値を取り、`log2` 値にする。FKとFLの値を `over_sets` で集約する。参照中心・評価幅から診断費用を求め、`formants` に出す。 |

共有する12録音では音素対応・境界・F2が再現すると予測した。全発話の合成値でも男女参照は全78条件で費用0となり、女性参照の費用0の件数は変わると予測した。旧録音で差が出たときは、対応音素の各欄の最初の差を記録する。固定参照を引き継いだ4集約方式を、独立計算と照合する。 [上流のTSP比較](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera-cli/src/compare/tsp.rs)・[固定MFA設定](../../../../docs/reference/chimera-vocal-synth/upstream/tools/tsp/mfa.yaml)・[計測入口](../tools/measure_tsp_f2_full_held_women.py)

## 実測

FKとFLの全120録音を固定上流で整列し、対応音素を取得した。共有する12録音では対応音素、秒区間、録音・合成のF2が一致した。全録音側の有効F2はFK34件、FL36件の計70件。録音WAVからこれらを独立に計算した最大差は `1.52e-10 Hz` で、欠測判定も一致した。 [全120録音の音素対応](../runs/tsp-f2-full-held-women-20261123-a/artifacts/collection/native.json)

| 観測点 | 部分文集合 | 全発話 |
| --- | ---: | ---: |
| FK合成F2の中央値 | 2,059.93 Hz（5件） | 2,041.73 Hz（34件） |
| FL合成F2の中央値 | 2,043.75 Hz（10件） | 2,054.77 Hz（36件） |
| 上流 `over_sets` の集約値 | 2,051.83 Hz相当 | 2,048.24 Hz相当 |
| 合成F2を直接まとめたHz中央値 | 2,045.90 Hz | 2,047.81 Hz |
| 上流集約の女性参照で費用0 | 73 / 78 | 78 / 78 |
| 上流集約の男女参照で費用0 | 78 / 78 | 78 / 78 |

全発話を使うと上流の集約値が約3.59 Hz下がり、女性参照で正の費用だった5条件が費用0になった。たとえば `FA01_03` の対応音素列の13番に822.19 Hzを代入した場合、女性参照の費用0の上端は2,048.379 Hzだった。全発話の集約値2,048.240 Hzは約0.140 Hzだけ内側に入った。元の12発話は同じ測定値を保ったため、この比較の差は追加した発話による。予測3件を満たした。 [集約値と全条件](../runs/tsp-f2-full-held-women-20261123-a/summary.json)

基準を含む79条件×2参照×4集約方式の費用632点について、固定上流と独立計算で有限474点と欠測158点が一致した。次は研究版が同じFK・FLの文集合を合成するとき、女性参照の上端に近い条件でどの段に差が現れるかを照合する。 [固定上流の集約出力](../runs/tsp-f2-full-held-women-20261123-a/artifacts/native.json)

## 実行と保存

macOS 15.6.1 arm64、Rust 1.94.1、Python 3.14.4、MFA 3.4.3。確認用120録音の展開と合成・整列をRTL9210B-CG上で実行し、ビルド、録音ハッシュ、音素対応、上流集約結果と実行ログを保存した。

```bash
CHIMERA_RUN_STORAGE=rtl9210b CHIMERA_RUN_BYTES=4294967296 \
  ../../.venv/bin/python tools/measure_tsp_f2_full_held_women.py \
  tsp-f2-full-held-women-new
```

研究ワークスペースと `/tmp` から再実行し、ともに4判定と上流6試験に通過した。録音ハッシュ、120発話の音素対応、固定入力、上流出力、パッチ、要約を含む9出力がバイト一致した。 [再実行](../runs/tsp-f2-full-held-women-20261123-repeat/manifest.json)
