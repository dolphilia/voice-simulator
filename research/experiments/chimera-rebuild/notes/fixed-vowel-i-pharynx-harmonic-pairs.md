# 咽頭の二次損失を少数の周波数対で近似する

固定 /i/ の2,310 Hzで、平均流量まわりに線形化した咽頭内17枝のモデルでは鼻端の複素誤差が増えた。前回、逆流のない枝22→23の流量を二乗したときの寄与上位は、110 Hzと2,200 Hz、−110 Hzと2,420 Hz、220 Hzと2,090 Hzだった。今回はこの3組を全17枝に共通に適用する。平均と選んだ倍音から逆流も再構成し、観測流量に接線抵抗だけを掛けたときの鼻端誤差が50%以上減るか調べる。 [前回の観測](fixed-vowel-i-pharynx-mean-flow-tangent.md#節点2223で差が生じる項)・[事前登録](../cases/fixed-vowel-i-pharynx-harmonic-pairs.json)

固定上流では `HumanVoice::render` が声門開口を更新し、`AirwayNetwork::step` が前標本の圧力差・運動量を使って枝流量を解く。通常枝の二次項は、順流で `K₊U²`、逆流で `−K₋U²`。係数は狭い側の最小面積から下流側の平均面積に向けた拡大損失を主とし、反対側の拡大損失の一部が加わる。圧力は dyn/cm²、流量は cm³/s。定常狭窄のテストは全セルと1/4セルの場合の流量をベルヌーイ近似に照合する。 [上流の発声ループ](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/src/voice/human_voice.rs#L371)・[流向別の枝更新](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/src/airway/network.rs#L954)・[定常狭窄試験](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/tests/airway_adversarial.rs#L92)

流量を平均 `ū` と変動 `u′` に分けると、符号付き損失は `K₊(ū² + 2ūu′ + u′²) − (K₊ + K₋)U² · 1[U < 0]`。最後の項は、順流式を負の流量まで延長した値を逆流式に置き換える圧力補正になる。100 ms窓で2,310 HzはDFTの231番に当たる。`a[j] = DFT(u′)[j]/9600` と置くと二乗項は `Σⱼ a[j]a[(231−j) mod 9600]`。異なる2周波数の組は順列が2通りあるため積を2倍する。負の周波数は実信号の共役成分で、周波数の差による寄与もこの和に含まれる。 [前回のDFT照合](fixed-vowel-i-pharynx-mean-flow-tangent.md#節点2223で差が生じる項)

近似には、3組の入力になる110、220、2,090、2,200、2,420 Hzと、接線項に必要な2,310 Hzの計6周波数、および平均を使う。選んだ周波数だけで各枝の実数波形を再構成し、そこから逆流補正を計算する。観測波形から逆流を直接再投入する対照と、全周波数積を使う対照も置く。咽頭外の損失と声門入力は同じ収録に基づき、各枝の圧力源を同じ離散節点モデルに入れて鼻端の複素流量比を比較する。 [声門上の枝の節点解](fixed-vowel-i-velum-supraglottal-loss.md)

## 実測

400〜500 ms、内部96 kHzの9,600標本で、全周波数積と時間領域の二乗は両版で相対6.95×10⁻¹⁴以内だった。逆流時の補正まで加えた係数は実測波形を符号付きで二乗した係数に相対1.06×10⁻¹²以内で一致した。選んだ周波数で再構成した波形にも同じ照合を行い、相対1.12×10⁻¹²以内で一致した。

| 咽頭の圧力損失の計算 | 鼻端の複素相対誤差 |
| --- | ---: |
| 観測流量の2,310 Hz成分に接線抵抗を掛ける | 0.334754% |
| 接線項と1組の周波数積 | 0.220995% |
| 接線項と3組の周波数積 | 0.039441% |
| 3組と再構成波形の逆流補正 | 0.039232% |
| 3組と観測波形の逆流補正 | 0.039432% |
| 全110 Hz倍音の組と観測波形の逆流補正 | 2.59×10⁻⁸（相対値） |
| 全DFT周波数の組と観測波形の逆流補正 | 2.59×10⁻⁸（相対値） |

3組と再構成した逆流補正で鼻端誤差が88.28%減り、事前基準の50%を両版で満たした。接線項だけのときの振幅差−0.02298 dB、位相差+0.11789°は、それぞれ−0.00099 dB、−0.02151°になった。この条件で残った複素誤差は、咽頭内の実測二次損失による鼻端の寄与の大きさの21.82%。咽頭17枝の圧力係数のL2相対誤差は56.46%だった。3組は同じ収録の枝22→23で見つけたもので、結果は同一収録内での近似精度を表す。 [全判定と枝ごとの圧力源](../runs/fixed-vowel-i-pharynx-harmonic-pairs-20261124-repeat/summary.json)

観測では節点25→26から29→30までの5枝で逆流した。再構成ではこれらの5枝で逆流がなく、節点13→14から21→22までの9枝に逆流が現れた。符号が食い違ったのは、両版で17枝×9,600標本のうち5,924標本だった。観測した波形から逆流補正を正しく戻しても、鼻端の複素伝達の変化は咽頭内二次損失の全寄与の0.0114%だった。この条件の鼻端誤差低下は主に周波数積による。次は肺圧だけを7.2から5.76 cmH₂Oに変えて収録し、周波数対を固定したまま鼻端誤差と逆流判定を照合する。
