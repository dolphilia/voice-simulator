# seems の声帯振動ドリフト

比較するのは先行の音響段別計測と同じ `MK61_01` の `seems` の /i/。1.1525〜1.1775秒を使う。固定上流のドリフト振幅を既定の5セントから0セントにして、研究版の保存済み窓との距離を測る。先行の `fine` の音源比較ではドリフト・jitter・shimmerをまとめて止めた。[事前登録](../cases/tsp-seems-drift-only.json)・[先行の段別計測](tsp-seems-spectrum-stages.md)

## 上流の読解

- `chimera-cli/src/render.rs` の `say` はテキストを発音句に変換し、男性の基準F0を112 Hz、発話の開始時刻を0.05秒にしてジェスチャーを作る。出力は48 kHzで、声の内部計算は2倍の96 kHz。計画の時刻には秒を使う。
- `chimera/src/voice/human_voice.rs` の `HumanVoice::set_source` と `apply_source` が `SourcePatch` の音源設定を声帯へ反映する。既定の揺らぎはドリフト5セント、vibratoの深さ0セント、fry 0、roughness 0.1。roughnessから周期のjitter係数0.00455と振幅のshimmer係数0.042を設定する。`control` が発話計画に従う基準F0を蓄え、`render` は音響網の声門前後圧力差（dyn/cm²）を渡して声門面積（cm²）を更新してから、音響網を1標本進める。流量はcm³/s、放射への入力はその時間差分でcm³/s²。
- `chimera/src/sources/glottis.rs` の `Glottis::new` と `next` は、声門上下の圧差を平滑化し、初回を含め内部32標本ごとにピッチ倍率を更新する。乱数の種は4242、更新レートは3,000 Hz。振幅を \(d\) セント、状態出力を \(D\) とすると、振動周波数が基準F0の \(2^{dD/1200}\) 倍になる。位相は1周期を1として `f0 / 96000 / cycle_period_scale` ずつ進み、周回時に次周期の長さと振幅の係数を引く。面積は開口形状、平滑化済みの有声度、静的な隙間などで決まる。jitterとshimmerの設定が同じでも、ドリフトにより位相が1周する標本は変わる。
- `chimera/src/math.rs` の `Drift::new` と `step` は0.3、0.9、2.7 Hzの1極フィルターを使う。各状態はゼロから始まり、極係数 \(a=\exp(-2\pi f/3000)\) と入力係数 \(\sqrt{1-a^2}\) で更新する。入力は `Rng::gauss` の一様乱数4個の和を中心化して1.7320508倍した値。3状態に1、1/2、1/3を掛けて足し、1.4で割る。この更新はドリフト振幅0でも進む。
- `crates/chimera/tests/voice_source.rs` はtensionとbrightnessが閉鎖形状・出力の高域に及ぼす変化を確認する。`golden_voice.rs` は通常発話を含む固定出力とブロック分割の不変性を、`golden_analysis.rs` はLPC公開極を確認する。`math.rs` の `mulberry32_matches_typescript` は乱数の範囲を確認する。今回のF0比は乱数の状態更新から独立計算して比べる。

研究版の発話設定は `crates/vocal-core/src/voice.rs` でドリフトを0セントにしており、周期係数も上流と異なる。比較では上流のjitter、shimmer、圧力の相互作用を動かしたままにする。[研究版の音源初期化](../crates/vocal-core/src/voice.rs)

## 実測

固定上流の観測器に `drift_zero` を追加し、初回の `set_source` にドリフト振幅0だけを指定した。通常条件は未加工の上流CLIと既存WAVの両方に照合した。観測付きの両条件は116,132 PCMフレームで、発話計画はバイト一致した。窓の標本範囲は48 kHzで `55320:56520`、96 kHzで `110640:113040`。研究版は先行実行の窓を使用した。

| 条件 | 研究版までの声門流量の全変動距離 | 高域LPC極（Hz） | 極の帯域幅（Hz） |
| --- | ---: | ---: | ---: |
| 固定上流の既定 | 0.205283 | 2,228.1479 | 111.4430 |
| 固定上流のドリフト振幅0 | 0.113214 | 2,206.5029 | 122.4517 |
| 研究版の保存窓 | — | 2,212.4485 | 120.9718 |

1,950〜2,600 Hz内で規格化した声門流量パワーの距離は0.092069縮まった。研究版から固定上流を引いたLPC極の差は−15.6994 Hzから+5.9455 Hzになった。絶対差の縮小は9.7539 Hzで、登録した2 Hz以上の改善を満たした。FFTと直接フーリエ和の相対誤差は最大1.20×10⁻¹⁴、固定LPCと独立計算の最大差は1.01×10⁻¹¹ Hz。独立の放射・出力計算で両条件のPCMを先頭56,600フレームまでビット単位で再現した。

96 kHzで瞬時F0と位相は第0標本から変化した。独立計算とF0比の最大誤差は113,200標本で2.87×10⁻¹³セント。窓内の既定側の変動は停止側に対し−5.53〜−2.59セントだった。声門面積と流量は第8,081標本、声門上下の圧差と有声度は第8,082標本で初めて異なった。PCMは48 kHzの第4,061フレームから異なった。舌先位置と声のオン・オフの系列は観測範囲全体で一致した。計測6判定と事前登録の3仮説はすべて成立した。[計測要約](../runs/tsp-seems-drift-only-20261123-repeat/summary.json)

今回の効果量には、ドリフトを止めたことで周期をまたぐ時刻が変わり、圧力との相互作用が変わった分も含まれる。次はドリフト振幅0の発話で声門の振動計算に渡す圧差だけを既定条件の保存系列に置き換え、圧差を差し替えない条件と同じ窓で比べる。声門面積・有声度・流量とLPC極を観測し、時間依存の結合が差のうちどこまでを説明するか確かめる。

## 再実行

`research/experiments/chimera-rebuild` で別の実行IDを指定する。

```bash
CHIMERA_RUN_STORAGE=rtl9210b CHIMERA_RUN_BYTES=2147483648 \
  ../../.venv/bin/python tools/measure_tsp_seems_drift_only.py tsp-seems-drift-only-new
```

実行環境はmacOS 15.6.1 arm64、Rust 1.94.1、Python 3.14.4、NumPy 2.4.4。リポジトリの実験ディレクトリと `/tmp` の実行で、要約、条件別の計画、観測窓、スペクトル、瞬時F0、固定上流のLPC結果がバイト一致した。固定上流の試験4件は両方で通過した。

保存した `pitch-trace.npz` には両上流条件の瞬時F0と独立に計算したセント値、`drift-windows.npz` には声門と放射の観測窓とLPCへの入力、`drift-spectra.npz` には3条件の声門流量のパワーがある。固定上流のLPC結果は `upstream-envelopes.json`、試験結果と履歴はログとマニフェストにある。観測用の上流ビルドと全長の一時波形はRTL9210B-CGで処理した。[初回](../runs/tsp-seems-drift-only-20261123-a/manifest.json)・[再実行](../runs/tsp-seems-drift-only-20261123-repeat/manifest.json)
