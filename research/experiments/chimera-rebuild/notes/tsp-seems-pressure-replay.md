# seems の声門上下の圧力差を再入力する

1.1525〜1.1775秒の同じ /i/ で、上流のドリフト振幅0のまま、声帯の振動器に入る圧差をドリフト5セントの発話から得た系列に置き換える。先行の窓でドリフト停止による高域LPC極の移動は21.64 Hzだった。声門上下の瞬時圧差は両条件で平均約6,730 dyn/cm²、有声度は平均0.9965で、平滑化後の圧差が既定の有声ゲートの上端約3,923 dyn/cm²を超えると予想した。[事前登録](../cases/tsp-seems-pressure-replay.json)・[先行の比較](tsp-seems-drift-only.md)

## 上流の読解

- `crates/chimera-cli/src/render.rs` の `say` が辞書と発話計画から `HumanVoice` を作り、`render` を使って48 kHzのPCMを得る。男性条件では基準F0を112 Hz、ジェスチャーの開始を0.05秒とし、内部は2倍の96 kHzで更新する。同じ発話と初期状態を各条件に使う。
- `crates/chimera/src/voice/human_voice.rs` の `control` が調音形状、呼気の目標、声門の労力と基準F0を更新する。`render` は各内部標本で肺境界の圧力を更新し、音響網の気管末尾と咽頭先頭の圧力の差を `ParametricGlottis::next` に渡す。圧力の単位はdyn/cm²で、受け取った面積の単位はcm²。この面積を `AirwayNetwork::set_port_area` で声門枝に即時反映し、`step` が現在の音響網の圧力と面積から枝流量などを更新する。観測上の声門流量（cm³/s）は `step` 後、差し替える圧差は `step` 前の値である。
- `crates/chimera/src/sources/glottis.rs` の `ParametricGlottis::new` と `next` では、圧差の平滑状態をゼロから `s += (1−exp(−2π·30/fs))·(dp−s)` で進める。発声閾値2.5 cmH₂Oに0.8と1.6を掛けた区間で三次のsmoothstepを使う。さらに開大時の減衰と閉鎖係数を掛け、カットオフ25 Hzの1極平滑で有声度をその値に追従させる。圧差の効果はこの有声度を通じて動的な声門面積へ伝わる。周期位相の更新はF0と周期係数から決まる。`flush_tiny` は通常の制御更新時に極小の平滑状態をゼロに片付ける。
- `crates/chimera/tests/lung_port.rs` は摩擦音で肺側に圧力が残ること、肺境界の負荷を変えても持続音の声帯下圧と労力が保たれることを確認する。`golden_voice.rs` は固定発話とブロック分割時のPCM、`golden_analysis.rs` はLPCの公開極を照合する。研究版の既存の唇閉鎖ケースでも、振動器への圧差系列と音響網の圧力を別々に追っている。[唇閉鎖の圧差再入力](../tools/measure_glottal_feedback.py)

## 実測

4条件を同じ計画でレンダーした。ドリフト5セントとドリフト0は音響網から得た圧差をそのまま振動器へ渡す。残りの2条件はいずれもドリフト0とし、通常条件から取り出した圧差と、ドリフト0自身の圧差をそれぞれ振動器に渡す。計測用パッチは固定版の隔離コピーに適用した。

通常条件のPCMは通常CLIと既存WAVに一致し、ドリフト停止条件も前回のPCMハッシュに一致した。自己の圧差を使った対照は全116,132 PCMフレームと観測した内部状態で一致した。通常条件からの再入力は全232,264内部標本で供与側の系列と一致した。SciPyで独立に求めた圧差の平滑値と上流出力の最大誤差は2.82×10⁻¹¹ dyn/cm²だった。

| ドリフト0での圧差入力 | 平滑化圧差の範囲（dyn/cm²） | 高域LPC極（Hz） |
| --- | ---: | ---: |
| 各実行の音響網から取得 | 5,842.70〜7,423.54 | 2,206.50293058 |
| 通常条件の圧差を再入力 | 5,837.17〜7,423.50 | 2,206.50292916 |

両条件で有声ゲートの圧力成分は窓内2,400標本すべてで上限に達した。上限に対応する圧差は3,922.66 dyn/cm²。再入力による声門流量の高域パワー分布の全変動距離は3.42×10⁻¹⁰、LPC極の移動は−1.42×10⁻⁶ Hzだった。研究版の高域LPC極は2,212.44845 Hzで、約5.95 Hzの差が残った。

再入力で圧差と有声度が初めて変わった内部標本は8,082。声門面積は8,085、声門流量は8,086、音響網自身の声門上下の圧差は8,089で初めて異なった。瞬時F0と位相は同じだった。解析窓の有声度の最大絶対差は3.15×10⁻⁹で、圧力成分が上限に達する前の履歴が有声度の平滑状態に残ることと整合する。PCMの最初の差は48 kHzの第4,085フレーム。独立した放射・出力計算で解析窓を含む先頭56,600フレームを再現した。計測9判定と登録した2つの仮説は成立した。[実測の要約](../runs/tsp-seems-pressure-replay-20261123-repeat/summary.json)

この窓の結果から次は、ドリフト振幅を0に保ち、上流の周期長のjitterだけを0にする。研究版の当該ケースはジッター0で初期化される。有声ゲートの圧力成分が上限に達していない発声の立ち上がりでは、今回の小さな効果量を別の窓で確認する必要がある。[研究版の初期化](../crates/vocal-core/src/voice.rs)

## 再実行

`research/experiments/chimera-rebuild` で別の実行IDを指定する。

```bash
CHIMERA_RUN_STORAGE=rtl9210b CHIMERA_RUN_BYTES=2147483648 \
  ../../.venv/bin/python tools/measure_tsp_seems_pressure_replay.py tsp-seems-pressure-replay-new
```

`pressure-traces.npz` に先頭113,200内部標本の気道側の圧差、振動器への入力、平滑化後の圧差を保存した。発話計画、解析対象窓、スペクトル、上流LPC、試験ログもマニフェストから辿れる。観測用のビルドと一時波形、計測成果はRTL9210B-CGを使用した。実行環境はmacOS 15.6.1 arm64、Rust 1.94.1、Python 3.14.4、NumPy 2.4.4。実験ディレクトリと `/tmp` の実行で、要約、発話計画、解析窓、圧差系列、スペクトル、LPCがバイト一致した。[初回](../runs/tsp-seems-pressure-replay-20261123-a/manifest.json)・[再実行](../runs/tsp-seems-pressure-replay-20261123-repeat/manifest.json)

共通化した観測器で先行のドリフト比較を再実行し、要約、瞬時F0、観測窓、パワースペクトル、LPCが先行の保存出力とバイト一致した。[先行ケースの再確認](../runs/tsp-seems-drift-only-20261123-recheck-after-pressure/manifest.json)
