# FK61_01の枝41→42の流量差を口腔の上流へさかのぼる

[前回の二節点比較](tsp-fk61-control5632-mouth-flow.md#実測)では、5632以降の枝41→42の流量系列を上流に揃えるだけで、冒頭からPCM 2937まで一致した。今回は観測範囲を枝37→38と節点38〜43に広げ、境界の枝流量と口腔内の体積源を分ける。固定上流、研究版、下唇内面の評価順を上流に揃えた試験版を同じ発話条件で観測する。内部96 kHz、出力48 kHz、時刻・節点は0始まり。

## 呼び出し経路と連成の順序

上流CLIの `render text` から発話計画を作り、`HumanVoice::render` が64出力フレームごとに調音目標を更新する。2倍オーバーサンプリングでは5632・5760が制御境界で、各128内部標本にわたり管の形状を補間する。口腔の直列管は咽頭の後ろにあり、鼻腔へのポートは咽頭側に接続する。今回の節点38〜42では、接続の両側が口腔の直列枝になっている。 [テキストCLI](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera-cli/src/render.rs#L179)・[上流の発声](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/src/voice/human_voice.rs#L371)・[口腔と鼻腔への接続](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/src/voice/human_airway.rs#L150)

各標本では面積と長さを補間し、体積差から得た速度を隣接セルに配分して二段平滑に通す。枝の流量は前の節点圧・枝流量と新しい慣性・損失・乱流圧から計算する。枝の流量と壁流量を足し引きした後、圧力を更新する。内部節点では `q = (q₀ + U_in) − U_out − U_wall` を使い、`p_new = p_old + (Δt/C)q` とする。流量 `q` は cm³/s、圧力 `p` は dyn/cm²、コンプライアンス `C=V/(ρc²)` は cm⁵/dyn。節点43の圧力・慣性枝流量は並列R–L負荷と連成して更新する。 [上流の気道更新](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/src/airway/network.rs#L833)・[上流の放射負荷](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/src/airway/network.rs#L1123)・[研究版の枝・節点更新](../crates/vocal-core/src/airway/network.rs#L675)

逐次計算の外から枝37→38の流量を与え、以降の枝は各節点の再計算した圧力でつなぐ。観測版では、枝の旧流量・慣性・運動量、壁の旧速度・変位、節点圧、口端負荷を区別して採取する。口端慣性の最初の補正は、前の標本の更新後流量と慣性から始める。二重丸めを避ける独立した枝の根と、壁および圧力の既存の検算器を使う。 [枝の根の検算](../tools/measure_fixed_voice_glottal_branch.py#L261)・[連成を再現する計測器](../tools/measure_tsp_fk61_control5632_upstream_drive.py#L26)

固定上流の密閉腔圧縮・定常狭窄・閉鎖後の再開口の試験と、研究版の声門開口の即時更新中の幾何補間を検査する。実発話の通常CLIと観測版の全PCMを照合し、計測による出力の変化を確認する。 [上流の気道試験](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/tests/airway_adversarial.rs#L56)・[研究版の補間試験](../crates/vocal-core/tests/geometry_ramp.rs)

## 比較条件

観測は5630〜5875、逐次計算は5632〜5875。開始時の内部状態、境界の枝37→38、節点38〜41の体積源、節点42・43の体積源、局所の係数と乱流圧の5群を上流値へ交換する全32組を比較する。体積源は6節点で1節点ずつ交換する条件も設ける。枝40→41と41→42では5675・5723・5781・5863に旧圧・旧流量・慣性・損失・乱流の局所交換を行う。枝41→42を観測した上流の流量で固定した対照は、前回の二節点比較に照合する。出力段に戻す口端流量は、5863・5864の2標本と、5632〜5875の全区間の両方で比較する。壁と鼻端の放射は試験版の観測値を使う。 [事前登録](../cases/tsp-fk61-control5632-upstream-drive.json)

## 実測

固定上流と試験版を6節点のモデルで進め、244内部標本の枝、壁流量、節点圧、口端流量を観測と照合した。無交換のPCMと、枝41→42に上流の流量を与えた対照のPCMは、前回の二節点モデルに一致した。

| 内部標本 | 枝41→42の上流と試験版の差 cm³/s | 枝37→38だけ交換した変化 cm³/s | 節点38〜41の体積源だけ交換した変化 cm³/s |
| ---: | ---: | ---: | ---: |
| 5675 | −1.084×10⁻¹² | −4.476×10⁻¹³ | −6.821×10⁻¹³ |
| 5723 | −1.008×10⁻¹¹ | −6.782×10⁻¹² | −3.293×10⁻¹² |
| 5781 | −3.010×10⁻¹¹ | −2.227×10⁻¹¹ | −7.898×10⁻¹² |
| 5863 | −2.760×10⁻¹¹ | −2.307×10⁻¹¹ | −4.487×10⁻¹² |

5675では節点38〜41の体積源の効果が枝37→38の効果を上回った。5863では枝37→38だけの交換で枝41→42の流量差の約83.6%を再現し、節点38〜41の体積源を併せて交換すると約99.8%を再現した。体積源を1節点ずつ交換した6条件では、5863の枝41→42への影響は節点40の −2.398×10⁻¹² cm³/s が最大だった。枝41→42の1標本だけを検算すると、5723の旧流量・旧運動量の交換による変化は −9.777×10⁻¹² cm³/s、両端の旧圧の交換による変化は −3.020×10⁻¹³ cm³/s だった。流量差の大半を、その時点までに枝に蓄積した状態が伝えていた。

枝37→38だけを交換して5863・5864の口端流量を戻すと、冒頭からPCM 2937まで一致した。全244内部標本を戻すと、同じ入力交換で変換前の値が +9.860×10⁻¹⁵ 動き、丸めの境目までの +1.410×10⁻¹⁴ に届かなかった。枝37→38と節点38〜41の体積源をともに交換したものは +1.483×10⁻¹⁴ 動き、全区間を戻す条件でも一致した。全32組のうち、2標本を戻す場合に一致した16組はすべて枝37→38を交換した。全区間を戻す場合に一致した8組はすべて、枝37→38と節点38〜41の体積源の両方を交換した。 [交換結果](../runs/tsp-fk61-control5632-upstream-drive-20261123-registered/summary.json)

次は観測範囲を咽頭と口腔の接続まで広げる。制御境界5632以降に枝37→38へ入る流量を、口腔上流側の体積源・枝と咽頭側からの入力に分ける。5675までの局所体積源の影響と、5723以降に強くなる上流からの影響を同じ測定で照合する。

固定上流のセル数の計算に女性設定と96 kHzを入れると、気管13、咽頭15、口腔16セルになる。口腔の入口は節点28。接続枝27→28は管内の枝の後に登録されるため、節点28の収支では口腔最初の枝による流出が先に引かれ、咽頭からの流入が後から足される。入口を含めてビット照合するときはこの加算順も記録する。 [セル数と接続](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/src/voice/human_airway.rs#L108)・[枝の登録順](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/src/airway/network.rs#L440)
