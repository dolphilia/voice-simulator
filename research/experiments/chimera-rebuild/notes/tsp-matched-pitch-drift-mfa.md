# 4発話で低速F0ドリフトを止めたときのMFA境界

## 読解と事前登録

`FK61_01` の前回比較では、低速F0ドリフトだけを5セントから0にすると `again` の境界と旧研究版の全音素区間を再現できた。同じ条件を `MK61_01`、`FK61_02`、`MK61_02` に適用する。保存済みの比較では `FK61_01` の `again` に5窓、`MK61_01` の `plea`・`again` に10窓の開始位置差があった。合計15窓の開始位置を0セント条件で再現し、ほかの45窓は動かないと予測する。[事前登録](../cases/tsp-matched-pitch-drift-mfa.json)・[単独発話の比較](tsp-again-pitch-drift-mfa.md)

| 参照した処理 | 入力と観測点 |
| --- | --- |
| 固定上流 `crates/chimera-cli/src/render.rs` の `say`、`crates/chimera/src/voice/human_voice.rs` の `apply_source` と `render` | 同じ本文、体型、辞書で発話計画を作り、既定のドリフト、周期長ジッター、振幅シマーを渡す。位相と声門面積を内部96 kHzで進め、流量の時間差分を間引いて48 kHzのPCMにする。 |
| 固定上流 `crates/chimera/src/sources/glottis.rs` の `next` と `crates/chimera/src/math.rs` の `Drift::step`、研究版 `PitchModulation::step` | 3つの状態を32内部標本ごとに更新し、ゼロ初期値と乱数種4242から合成した雑音を `D` とする。通常条件と停止条件の瞬時F0比は `2^(5D/1200)`。研究CLIの姿勢・音響トレースは各出力フレームの内部標本を2つ進め、後者のF0を記録する。独立計算の奇数番の内部標本を使って照合する。 |
| 固定上流 `crates/chimera-cli/src/compare/tsp.rs` の `over_noise_floor`、`align_synth` | 発話全体の20 ms窓の平均二乗の95パーセンタイルから雑音床を求める。固定種の雑音を足した整列専用PCM16と同じ辞書・ラベルをMFAに渡し、各発話を別話者として整列する。 |
| 同モジュールの `Sig::formants` と `crates/chimera/src/analysis/lpc.rs`、試験 `compare::tsp::tests` と `golden_analysis.rs` | 整列境界から5つの25 ms窓を12 kHz上に配置する。女性のLPC次数は12、男性は14。無加工PCMからF1・F2を採り、固定Rust、独立計算、保存済みの窓開始位置を照合する。上流試験は整列用雑音の再現性と解析の固定出力を検査する。 |

## 実測

ドリフト停止で、旧比較の15窓のうち10窓の開始位置が12 kHz上の同じ標本に戻った。残る5窓は `MK61_01` の `again` で、/ɛ/–/n/ の境界は5セント条件と同じ2.030秒だった。旧研究版では2.050秒だった。旧比較で差のなかった45窓は、ドリフト停止でも開始位置を保った。事前予測のうち、旧差を全15窓で再現するという予測は外れた。

| 発話 | 評価窓 | 旧差のあった窓 | 旧位置を再現した窓 | 境界の観測 |
| --- | ---: | ---: | ---: | --- |
| `FK61_01` | 25 | 5 | 5 | `again` の /ɛ/–/n/ は2.040秒から2.060秒へ移動した。 |
| `MK61_01` | 25 | 10 | 5 | `plea` の /i/–/f/ は0.400秒から0.390秒へ移動した。 `again` の /ɛ/–/n/ は2.030秒を保った。 |
| `FK61_02` | 5 | 0 | 0 | 評価した `lent` の /ɛ/ の窓は同じ。評価区間外の `he`–`lent` の語境界と /i/–/l/ の音素境界は0.330秒から0.260秒へ移動した。 |
| `MK61_02` | 5 | 0 | 0 | 語・音素の全区間は5セント条件と同じだった。 |

窓の再現数は評価対象の強勢母音に対する値である。 `FK61_02` では旧比較に無かった70 msの移動が、評価外の /i/–/l/ で出た。逆に旧比較の `to`–`the` の50 ms差はドリフト停止でも残った。[整列区間と窓別の結果](../runs/tsp-matched-pitch-drift-mfa-20261123-a/summary.json)

通常CLIが記録した4発話の計521,718出力フレームで、5セント条件と0セント条件のF0比を独立計算と照合した。最大誤差は2.90×10⁻¹³セントだった。瞬時F0は全発話で最初のフレームから分かれ、無加工PCMの初差は出力4,060〜9,952標本だった。前回の `FK61_01` の0セント波形とMFA境界を再現した。

固定窓でのF2差は最大24.99 Hz（`MK61_02` の `lent` の90%窓）。同じ0セントPCMで窓を再整列位置へ変えた場合の最大差は101.67 Hz（`FK61_01` の `again` の90%窓）だった。 `MK61_01` の `plea` の90%窓では窓開始が4,530標本から4,421標本へ移り、同じ0セントPCMでF2は28.94 Hz下がった。4条件・各60窓の固定Rustと独立LPCの採択値は最大2.73×10⁻¹¹ Hz差で、欠測は0だった。[窓別の開始・F2採択](../runs/tsp-matched-pitch-drift-mfa-20261123-a/artifacts/window-comparisons.json)

## 実行と保存

macOS 15.6.1 arm64、Rust 1.94.1、Python 3.14.4、NumPy 2.4.4、MFA 3.4.3。研究ワークスペースから実行する。

```bash
CHIMERA_RUN_STORAGE=rtl9210b CHIMERA_RUN_BYTES=2147483648 \
  ../../.venv/bin/python tools/measure_tsp_matched_pitch_drift_mfa.py tsp-matched-pitch-drift-mfa-new
```

研究ワークスペースと `/tmp` から各8判定・上流7試験を通過した。各59出力のうち計時などを含む2実行ログを除いた57出力がバイト一致した。条件別のPCM、MFA入力・整列結果、固定Rustと独立LPCの窓別比較をRTL9210B-CGに保存した。連続F0の誤差は全フレームから計算し、F0比の系列は32内部標本ごとに保存した。通常CLIの全列トレースは一時領域で読み取った。[再実行のマニフェスト](../runs/tsp-matched-pitch-drift-mfa-20261123-repeat/manifest.json)
