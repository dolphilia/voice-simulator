# 口端の直列半セル慣性と一様管のエネルギー

## 固定上流と実験条件

固定上流 `c6147d0198890475dbe8a65a0bb8f56240c539b7` の `tests/airway.rs` では、`uniform_tube` が一様管の末端セル中心に `add_radiation` を接続する。 `AirwayNetwork::step` は枝の流量を先に更新し、末端では圧縮性・放射の抵抗と慣性をCrank–Nicolson法で連立する。 `rad_ul` は放射の慣性を流れる速度、`rad_u` は抵抗枝と慣性枝の合計流量で、後者は `radiated_flow` から取得できる。全放射の差分は `step` の戻り値。 `fdtd_peaks` はこの差分のFFTを角周波数で割り、周波数領域の節点回路と共鳴を照合する。今回も気道量はCGSで、圧力は dyn/cm²、体積流量は cm³/s、慣性は g/cm⁴、エネルギーは erg。[固定上流の一様管試験](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/tests/airway.rs)・[放射端の元の更新](../../../../docs/reference/chimera-vocal-synth/upstream/crates/chimera/src/airway/network.rs#L1121)

前回の伝達行列では口端までの半セルを補うと、3,250 Hzの差が−1.487 dBから+0.256 dBになった。今回は管の最後のセル中心と開口に同じ体積流量が通る直列慣性 `L_s=ρΔx/(2A)` を置き、通常の `vocal-cli render` で時間領域を計測する。17.5 cm・3 cm²、96 kHz、40セル、剛体、管内粘性なしを基準とし、47セルでも安定性を調べる。入口は体積0.001 cm³の1サンプルのインパルス。末尾を含む3秒の波形とエネルギーを測り、周波数比較だけ以前の6 kHz FIRを適用する。通常の直接終端は上流と以前の候補波形に照合する。[前回の仮説](uniform-grid-rate-sensitivity.md#口端の半セル)・[事前登録](../cases/uniform-outlet-half-cell.json)

## 更新式と離散エネルギー

終端セルの圧力を `p`、圧縮性を `C`、直列慣性の流量を `S`、並列負荷の慣性流量を `V` とする。末端セルへ内側から来る流量を `I`、開口における時間中点の圧力を `p_f` とする。上線は前後サンプルの平均。更新の連立条件は以下になる。

```text
C (p_new − p_old)/Δt = I − S̄
L_s (S_new − S_old)/Δt = p̄ − p_f
L_r (V_new − V_old)/Δt = p_f
S̄ = V̄ + p_f/R_r
```

`h=Δt/2` とすると、最後の2式から `p_f=(S̄−V_old)/(1/R_r+h/L_r)`。 `p̄=p_old+h(I−S̄)/C` を最初の式から代入すると `S̄` の一次方程式になる。まず `S̄` と `p_f` を決め、それから `p,S,V` の新値を出す。 `tube.outlet_half_cell` で半セルを選ぶ。 `measurement.radiation_energy` を指定した剛体・粘性なしのケースでは、開口圧、直列・放射慣性の流量、管の離散エネルギーもCSVに保存できる。[Rustの更新とエネルギー](../crates/vocal-core/src/airway.rs)・[CLIの設定とCSV](../crates/vocal-cli/src/main.rs)

4式にそれぞれ圧力・流量の中点を掛けると、末端の貯蔵エネルギー `(Cp²+L_sS²+L_rV²)/2` の1ステップの増分は `Δt(p̄I−p_f²/R_r)` になる。管全体では節点の圧縮エネルギーを足し、管内枝の運動エネルギーを整数時刻を挟む流量の積 `Lu^{n−1/2}u^{n+1/2}/2` で評価する。前後2ステップの枝更新を足すと、内側の枝のエネルギー変化と節点に対する仕事が打ち消し合い、全体は `ΔE=Δt(p̄_in Q_in−p_f²/R_r)` になる。管内の流量積を二つの半時刻の平均流量と差に分解すると、圧力勾配による負の項は圧縮エネルギーの `(cΔt/Δx)²` 倍以下。安定条件内では貯蔵エネルギーは非負になり、無入力では放射抵抗の散逸分だけ減る。この関係は壁の運動・粘性を除いた条件で判定する。[計測器で再計算するエネルギー収支](../tools/measure_outlet_half_cell.py)

周波数領域の独立計算には、並列負荷 `Y_R=1/R_r+1/(s_T L_r)` と直列慣性を合わせた `Y=Y_R/(1+s_T L_sY_R)` を使う。中点法の時間差分 `s_T=2j·fs·tan(ωΔt/2)` と、節点圧の中点への変換を入れて、三重対角の節点方程式を解く。前回は管内枝と同様に半セルの流量をスタガードな時刻に置いたので、終端と同じ時刻で連立する今回とは、半セル項に `1/cos²(ωΔt/2)` の違いが出る。3,250 Hzではこの違いも保存する。[前回の伝達行列](uniform-grid-rate-sensitivity.md#伝達行列による独立計算)・[中点法の独立計算](../tools/measure_uniform_waveguide.py)

## 口端の応答と減衰

| 剛体・管内粘性なし・96 kHz | 40セル・直接終端 | 40セル・半セルあり | 47セル・半セルあり |
| --- | ---: | ---: | ---: |
| クーラン数 | 0.8333 | 0.8333 | 0.9792 |
| 最初の非ゼロ放射の内部サンプル | 39 | 39 | 46 |
| 3,250 Hzの振幅差（対波動管） | −1.487 dB | +0.278 dB | +0.102 dB |
| 末尾0.1秒の最大貯蔵エネルギーと全区間ピークの比 | 2.77×10⁻¹⁰ | 2.51×10⁻⁷ | 2.99×10⁻⁵ |
| 末尾の口端流量の最大成分 | 30,070 Hz | 30,070 Hz | 41,430 Hz |

96 kHz・40セルの3,250 Hzの差の絶対値は **81.3%** 低下した。前回の+0.256 dBの予測との差は0.022 dB。第4共鳴付近を含む登録16点の最大振幅差は、直接終端の3.05 dBから0.619 dBに縮まり、0.9 dB基準を通過した。新しい中点法の独立計算とは、3条件を通じ、口端流量とその差分などの相対複素誤差が3.54×10⁻⁹未満だった。直接終端の時系列は当該条件の固定上流と4.30×10⁻¹⁵以内、保存済みの直接終端と最初の6列すべてで完全一致。半セルを入れると、初回の差は口端圧・放射流量のサンプル39に出て、入口圧には78で現れた。[波形と独立計算の結果](../runs/uniform-outlet-half-cell-20261121-b/summary.json)

放射抵抗の散逸と管全体のエネルギー増分の収支は、最大でもピークエネルギーの4.18×10⁻¹⁶の誤差。累積の最大誤差は1.72×10⁻¹⁵未満で、入力を止めた後の増加は丸めの範囲に収まった。半セルありの40セルでは、登録した減衰基準内で、直接終端より末尾の貯蔵エネルギーが多かった。どちらも末尾の主成分は離散分散式による上限30,103 Hz近くの30,070 Hz。47セルでは上限41,752 Hzに対して41,430 Hzだった。高い周波数の残留は、可聴帯の振幅を近づけた効果と合わせて記録する。[エネルギー・残留の数値](../runs/uniform-outlet-half-cell-20261121-b/summary.json)
