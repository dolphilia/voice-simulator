# E0証拠契約

固定根拠はv3。旧実験の音声・係数・採否を入力にしない。

| v3 | 設定・証拠 |
|---|---|
| 2節 | e0-spec.json のFs、band、bounds、split、input_files。生成器は変数と周波数だけを受領 |
| 3節 | objective、selection、epsilon。全評価の変数・g・R/M/J・番号を保存 |
| 4節 | optimizer、settings、budget、qualification、diagnostics。開始点実値・ライブラリ版・コードhashを保存 |
| 5節 | qualification/summary.jsonに設定選択または不通過を保存。測定は点検通過時のみ |
| 6節 | P1の固定仕様は刺激作成前に別途保存。知覚判定を数値で代用しない |

利得上限の丸め誤差で実行可能区間が空になる場合に限り、上限を次のbinary64値へ進める。1e-8の許容差は変更しない。

単体検証は実装検証であり、正式な自己回復点検と区別する。正式なqualifyは保存先が存在すれば再実行を拒否し、S1→S2を超えて試さない。実装誤りによる中断はinvalidとして保持する。測定のDcheckを用いた再適合は禁止する。

機械可読設定と実装の一致を確認してから正式点検を実行する。ここで設定した値を結果に応じて変更しない。P1の人による回答は未収集であり、推測で埋めない。
