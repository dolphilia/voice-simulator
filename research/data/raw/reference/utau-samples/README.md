# UTAU 音声サンプル参照メモ

このディレクトリには、音声合成エンジン研究用の UTAU 音源サンプルを配置する。WAV 音声、UTAU の原音設定 `oto.ini`、周波数情報 `.frq`、音源ごとの `readme.txt` / `character.txt` などを含む。

このディレクトリ配下の音声データ本体は容量が大きく、権利条件の確認も必要なため Git 管理から除外している。この README だけは、ローカルに配置したデータの構造を共有するために追跡対象とする。

## 概要

- 調査日: 2026-05-20
- 総容量: 約 1.4 GB
- 音源トップディレクトリ数: 11
- WAV: 5,704 files
- FRQ: 5,680 files
- `oto.ini`: 40 files
- 代表的な WAV 形式: Microsoft PCM / 16 bit / mono / 44,100 Hz
- 文字コード: `readme.txt`、`character.txt`、`oto.ini` は CP932 として読む必要があるファイルが多い

## ファイル種別

- `.wav`: 分析対象の音声サンプル。単独音、連続音、おまけ、台詞、息などを含む。
- `.frq`: UTAU が生成する周波数情報。F0 解析や UTAU 側の推定結果との比較に使える。
- `oto.ini`: 原音設定。エイリアス、オフセット、子音部、ブランク、先行発声、オーバーラップなどのタイミング情報を含む。
- `character.txt`: 音源名やアイコンファイルの参照を含む。
- `readme.txt`: 利用条件、配布元、バージョン、商用利用や再配布に関する注意を含む。
- `icon.bmp` / `icon.gif`: UTAU 音源の表示用画像。
- `.oremo-Scache`, `.bak`, `.DS_Store`: 研究用途では基本的に無視してよい補助・キャッシュ・OS 由来ファイル。

## 研究での使い分け

- 母音フォルマント分析には、まず `単独音/` の `あ.wav`、`い.wav`、`う.wav`、`え.wav`、`お.wav` 相当のファイルを使う。
- 話者差の比較には、同じ発音ラベルの WAV を複数トップディレクトリ間で比較する。
- 声色差の比較には、`単独音-light`、`単独音-vivid`、`単独音-Dark`、`単独音-Boyish`、`連続音-Breathy` などの派生サブセットを使う。
- 連続音の遷移・共鳴変化を見る場合は `連続音/` 系を使う。`oto.ini` のエイリアスとタイミングを併用すると、子音から母音への遷移区間を切り出しやすい。
- `息/`、`台詞/`、`おまけ/` は通常の母音フォルマント基準から外れる可能性があるため、分析対象に含める場合は別カテゴリとして扱う。

## 注意点

- このディレクトリは Git では音声データ本体を追跡しない。再現用スクリプトや分析結果をコミットする場合は、元データの存在を前提にしすぎないこと。
- 音源ごとの `readme.txt` に利用条件がある。再配布禁止、商用利用時の連絡、権利者確認などの記載があるため、公開資料や生成音声に使う前に必ず確認する。
- 日本語ファイル名には結合濁点を含むものがある。macOS 上では Unicode 正規化の違いでファイル名照合に失敗することがあるため、スクリプトでは存在確認を挟む。
- UTAU 系テキストファイルは CP932 前提で読む。Python では `encoding="cp932"`、CLI では `iconv -f CP932 -t UTF-8` を使うと扱いやすい。
- `oto.ini` の中身は CP932 のまま扱わないと文字化けしやすい。解析時は読み込み直後に UTF-8 へ変換し、元ファイルは変更しない。

```bash

find research/data/raw/reference/utau-samples -mindepth 1 -maxdepth 1 -type d | sort

# サブセット一覧
find research/data/raw/reference/utau-samples -mindepth 2 -maxdepth 2 -type d | sort

# ファイル種別の集計
find research/data/raw/reference/utau-samples -type f \
  | sed 's/.*\\.//' \
  | tr '[:upper:]' '[:lower:]' \
  | sort \
  | uniq -c \
  | sort -nr

# CP932 テキストを UTF-8 として表示
iconv -f CP932 -t UTF-8 research/data/raw/reference/utau-samples/金田朋子/単独音/readme.txt
```
