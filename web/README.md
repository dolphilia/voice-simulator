# Web Workspace

このディレクトリは、Web ベースの試作をまとめるための上位ディレクトリです。

現在のプロトタイプ:

- `prototypes/vowel-formant-prototype/`
- `prototypes/tube-vocal-tract/`
- `prototypes/waveguide-vocal-tract/`
- `prototypes/acoustic-fdtd-2d/`

役割:

- `vowel-formant-prototype/`: 3 バンドフォルマントフィルタによる軽量な試聴・調整台
- `tube-vocal-tract/`: 声道を複数セグメントの管として扱うチューブモデル試作
- `waveguide-vocal-tract/`: 改良版波動管、LF 音源、損失モデルを扱う試作
- `acoustic-fdtd-2d/`: 2D 音響シミュレーションの試作

起動方法や構成は、各プロトタイプ配下の README を参照してください。
