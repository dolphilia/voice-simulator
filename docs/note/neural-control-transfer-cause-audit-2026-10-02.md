# 制御移植で時間が短くなる原因の監査

2026-10-02。[追加比較](neural-assisted-extension-result-2026-10-02.md)の封印後、保存済みの教師・回帰係数・適合結果だけを解析した。生成、AI推論、再学習は追加していない。封印済みのコード・結果・合否は変更していない。

## 二つの異なる時間を混同していた

旧学習処理の出力は、教師音声の音素時間そのものではなく、VTLで教師へ近づけるために適合した指令時間である。開発12文でのVTL用の時間倍率は0.65–0.81だった。直接回帰が予測する合計時間と教師内部時間の比は、開発文で中央値0.680。音素列を従来の厳密照合で対応付けられた追加9文では中央値0.523だった。

この値をHMMの活動区間の秒数として扱うことには、合成器をまたいだ校正の根拠がない。単純に秒という単位が一致していても、VTL指令時間、教師内部token時間、実波形の活動時間は別の量である。これは移植時の時間短縮を説明する要因であり、認識誤りの全原因を確定するものではない。

## 文長の外挿を分解した

学習特徴行列は113音素行×101特徴、数値ランク52だった。正則化回帰なのでランク不足だけで実装不良とはしないが、独立な学習文は12件しかない。

各音素の基準継続長で重み付けした線形予測を、特徴群の寄与へ厳密に分解した。直接版の追加16文と開発12文の平均差は、継続長の対数補正について文長が−0.438、隣接音が−0.090、位置が−0.076だった。文長はF0の対数補正にも−0.276寄与した。蒸留版でも同様だった。

合計継続長の対数比の平均差は−0.717。これは音素別予測を指数変換して合計するため、線形寄与の合計とは一致しない。残差を別に保存し、寄与率を恣意的に100%へ正規化していない。文長だけを制限しても既定HMMの内容保持を回復できなかった前回の対照とも整合する。

詳細は[回帰監査](../../research/experiments/neural-control-extension/results/nas-extension-20261002-v1/post-analysis/regression-audit.json)。この解析は原因診断であり、新たな独立評価として数えない。

## 次の学習に使う量を分離した

[教師データ準備処理](../../research/experiments/neural-control-extension/prepare_acoustic_targets.py)を実装し、既存24音声から[新しい教師データ](../../research/experiments/neural-control-extension/results/nas-extension-20261002-v1/post-analysis/teacher-targets-v3.json)を作った。

- `teacher_internal_duration_seconds` は、教師が保存したtoken時間に由来する。人手で確定した音素境界ではない。
- `measured_f0_hz` は、既存WAVからDIO＋StoneMaskの70–800Hz範囲で測定する。未検出を欠損値とし、無声区間へF0を補間して正解値にしない。
- 合成器固有の指令値・VTL用の短縮補正は、このデータに含めない。将来の合成器ごとの校正と分離する。

固定キャッシュ内のMisaki `cutlet.py` は、「わ」等を`β`で表し、撥音を後続子音に応じて`m`や`n`へ変える。この実装で確認できた規則だけを[対応付け処理](../../research/experiments/neural-control-extension/teacher_alignment.py)に追加した。参照したコードのSHA-256をデータに保存した。

24件中23件の音素列を対応付けられた。残りのjf_alpha `unknown-08` は「箱」の`h`と`b`が一致しないため除外した。既存音声や教師の読みを修正したことにはしない。表記差4ケースの受理と、誤読・未許可の同一視・音素数不一致3ケースの拒否を検査した。これは対応付けコードの検査であり、音声品質の検査ではない。

## 現在の判断

次に必要なのは、長文だけを追加することではなく、**学習対象を合成器固有の指令値から分離し、文章文脈から予測する量と各合成器への変換を別々に検証すること**である。今回の23件は開発候補資料であり、今後の独立確認資料には数えない。

教師データの準備までは進んだが、品質達成は未証明。内容保護と自然さの最終確認には新しい評価が必要で、現campaignのAI枠300回は使用済みである。旧成果物の全ハッシュ一致を再確認し、追記の監査台帳だけを追加した。目標は未完了のまま維持する。
