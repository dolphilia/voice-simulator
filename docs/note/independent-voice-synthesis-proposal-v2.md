**明示的生成機構による音声合成の研究提案・改訂版**

推奨するのは、**公開された部分系の測定で、小型生成器の誤りを一つずつ切り分け、その後に人声としての成立を検証する経路**である。初回は音源の比較をしない。既知の声道応答を近似する実験によって、次の判断だけを変える。

**「後続の音源研究で、5対の極だけを持つ声道フィルタを研究用の基準として残すか、声道側の表現を先に拡張するか。」**

これは、人間らしい声の実現を声道測定の精密化へ置き換える提案ではない。音声全体を録音へ適合させると、声道の誤差を音源の変形で補えてしまう。その曖昧さを避けて最初の設計判断を下すため、入力と測定対象が明確な小実験を一回行う。以後、測定精度の追求を無期限に続けない。

本文では、一次資料で確認した事項を「資料上の事実」、そこからの判断を「推論」、新しく定める実験を「設計」として区別する。数値予算と許容誤差はすべて暫定的な設計値であり、実測速度、検出力、可聴差、品質を保証しない。本書は実験計画であり、データ取得・合成・試聴を実施した結果ではない。

**1．目的と、今回決めないこと。** 最終目標は、録音素片や学習済み音声生成器を最終音源にせず、少数の説明可能な状態・規則・入力から音声を新しく生成することである。人間の録音と機械学習は、測定・推定・探索・評価に利用できる。録音由来の波形表、詳細なスペクトル軌跡、周期列、録音へ一致するよう選んだ乱数種を、生成の供給源にはしない。

品質判断では、人声らしい音色として成立すること、音素を識別できること、発声や遷移が自然であること、指定した操作に応答することを分ける。音響特徴の一致は生理学的な正しさでも、自然さの証明でもない。実装が定義どおりに直った場合も、従来の知覚的な長所が維持されたかは別に扱う。

最初の実験E0が扱うのは、固定された声道模型の**振幅応答を小さいモデルで表す能力**だけである。共通制御規則、未知話者、時間一般化、知覚予測器の学習は含めない。位相、発声開始・終了、壁の運動、声門との相互作用も初回の結論に含めない。この限定により、音源や推定条件を追加して原因を見失うことを避ける。

**2．研究経路を選ぶ理由。** 明示的な音響生成器は最終候補として残すが、その適合を自然録音からいきなり始めるより、既に公開されている独立した測定を先に利用する。

| 経路 | 最初に分かること | 現時点の選択 |
|---|---|---|
| 自然録音へ音源・声道を同時適合 | 全体の再現能力。ただし誤差の所在が曖昧 | E0の後。内部原因への帰属を限定して使う |
| 公開された声道模型の応答を近似 | 未知の音源から分離した、声道表現の実用上の不足 | E0として採用。装置製作・三次元計算は不要 |
| 音声にEGG・気流・画像を加える | 音響的に同等な内部説明を追加観測で絞れる可能性 | その情報で選択が変わる競合説明が現れるまで保留 |

資料上の事実として、Kreimanらの声質再現研究は、準定常の/a/、録音由来のF0・振幅軌跡、知覚的な調整を用いている。Table Iには音源特徴だけでなく、最大11のフォルマントと帯域幅、3つのスペクトル零点なども記載される。全刺激に全自由度が必要だったという意味ではないが、**LF音源と5共鳴器だけで十分という根拠にはならない。** 本案は詳細な軌跡を省き、声道表現の一部分だけを別に試す。[Kreiman et al., 2021, Table I・合成手順](https://idiom.ucsd.edu/~mgarellek/files/Kreiman_etal_2021_JASA.pdf)

推論として、まず声道だけを測る方が、「音源を複雑にするべき」という誤った判断を安価に避けられる。ただしE0を通れば声道が人間について正しい、という推論はしない。対象と予算を固定し、結果を次の小実験へ渡す。

**3．人の新規参加なしに使う入力と、確認できた範囲。** E0にはDresden Vocal Tract Dataset（DVTD）の測定伝達関数を用いる。2026年9月13日の文献・配布ページ確認では、次を確認した。

| 資源 | 確認した内容 | E0での用途・限界 |
|---|---|---|
| DVTDの[公式配布ページ](https://springernature.figshare.com/articles/dataset/Dresden_Vocal_Tract_Dataset_complete_archive_/11897187) | 著者公開の全体ZIP、表示サイズ1.05 GB、CC0 | 配布先・利用条件を確認。ZIPや数値データは今回取得していない |
| DVTD論文のTable 1・Data Records | `s1-01-bahn-tense-a`と`s1-03-tiere-tense-i`の形状ID。各IDに対応する`XX-vvtf-measured.txt`。振幅と位相、100〜10,000 Hz、約0.961304 Hz刻み | この2形状の測定表だけを初回の対象に固定。日本語母音の達成ラベルではない |

| OPENGLOT Repository IV | 論文では/i/を指示したが実現音は[æ]〜[œ]、F0・発声様式に固定達成目標なし | 制御された/a/・/i/の収録代替にはしない。今回は使用しない |

DVTDの100 Hz未満・10,000 Hz超の値は測定結果でなく規定値で埋められるため使わない。位相には測定由来の線形項があり得るので、初回は振幅だけを判定する。以上は[DVTD一次論文の測定方法・Data Records](https://www.nature.com/articles/s41597-020-00597-w.pdf)に基づく。OPENGLOTの条件は[一次論文§2.5](https://math.aalto.fi/~jmalinen/MyPSFilesInWeb/OPENGLOT_accepted.pdf)で確認した。

実行時には、指定配布物から上の2つのテキスト表を取り出し、形状ID、列定義、周波数範囲、有限で正の振幅値を確認する。資料の条件適合性は確認したが、転送の成功や個別ファイルの完全性を検査済みとはしない。取得または形式確認に失敗した場合、E0の測定に基づく判断は停止する。必要な外部入力は**指定2形状の測定VVTF表が入った公開配布物**に限る。別データの名前だけを代入したり、生成した既知応答だけの検査でE0全体が成功したことにしたりしない。

**4．競合仮説と実装可能な比較。** 仮説は運用上の選択に限定する。

- **Hkeep：** 指定2応答について、5対の極だけのモデルで、事前に定めた振幅誤差を有限の探索予算内で満たせる。声道側はこの範囲の研究用基準として残せる。
- **Hextend：** その基準では不足し、少なくとも一方の応答で、零点1対を加えたモデルが許容誤差を満たす。音源側へ補正を足す前に、声道側の表現を変更する価値がある。

両モデルが失敗する場合や、探索不足で区別できない場合もある。この二仮説が、人間の発声についての全説明を尽くすとは考えない。

比較するのは、次の二つの安定した離散時間フィルタである。標本化周波数は設計値として16 kHz、判定帯域は100〜5,000 Hzとする。5,000 Hzは初期の部分系試験の上限であり、最終出力の品質帯域ではない。

`P5(z) = g / Π(i=1..5)[1 − 2r_i cos(ω_i)z⁻¹ + r_i²z⁻²]`

`P5Z(z) = P5(z) × [1 − 2ρ cos(ω_z)z⁻¹ + ρ²z⁻²]`

`r_i = exp(−π B_i / Fs),  ω_i = 2π f_i / Fs,  ω_z = 2π f_z / Fs`

| 項目 | 比較仕様 |
|---|---|
| パラメータ | P5は5周波数・5帯域幅パラメータ・利得の11変数。P5Zは零点半径ρ・周波数を加えた13変数 |
| 暫定範囲 | 極の周波数と零点周波数は100〜7,500 Hz、極のBは1〜3,000 Hz、ρは0〜0.999。極の周波数は昇順に整理 |
| 入れ子の関係 | ρ=0で分子は1となり、P5ZはP5へ厳密に戻る。このとき零点周波数は識別不能なので報告対象にしない |
| F0との関係 | フィルタ係数は絶対周波数で定義し、励振F0を変えても固定する |
| 位相 | 各伝達式が決める。位相パラメータや遅延補正は適合しない。位相の正しさを結論しない |
| レベル | 形状ごと・モデルごとに正の利得gを適合用点の対数誤差平均がゼロとなる値へ決め、その後固定 |
| 音源 | E0には導入しない。声道の測定振幅へ直接適合する |

Bは極半径を指定するパラメータであり、他の極・零点がある場合の観測ピークの厳密な半値幅と同一視しない。極・零点の相殺などにより係数が一意でなくても、今回は振幅近似の判断ができればよい。解剖学的な零点位置や音源の生理学的原因を推定する実験ではない。

**どの観測で分かれるか。** 適合に使わなかった周波数点で、P5に残るピーク間の落ち込み等の誤差をP5Zが減らすかを見る。音源を調整できないため、この実験内での改善を音源の変化へ帰属させる余地はない。P5Zでも極を再適合するので、固定した極に対する零点だけの効果や、同じ追加変数を別の構造に配分する案への優位は主張しない。勝利が示すのは「この入力・帯域・誤差基準では、その追加表現が有用」ということまでである。「人体にその零点が必要」「音色が自然になる」「5極対では数学的に表現不能」は結論できない。

本試験は**既知応答の近似**であり、形状から未知応答を予測する試験ではない。一次元管との比較は削除する。形状から係数を得る規則まで別途作らなければ、両者の入力情報を揃えられないためである。異なるF0の試験波形も初回には作らない。同じ線形フィルタの振幅誤差を倍音位置で再評価しても、新しい原因を識別できないためである。

**5．パラメータとデータの情報経路。** 各測定表の判定帯域内の行を周波数順に並べ、先頭を1番として、偶数番を適合用Dfit、奇数番を点検用Dcheckとする。これは近傍周波数への補間を点検する分割であり、独立した再測定や未知形状の検証ではない。近接点を独立標本として信頼区間を作らない。

| 情報・パラメータ | 決定元 | 固定する時点 | Dcheckの点検時に渡せるもの |
|---|---|---|---|
| 共通の式、次数、範囲、誤差、予算 | 本書と既知の生成応答による実装点検 | 公開測定の適合開始前 | なし。変更したら別実験として扱う |
| 2形状のID、対象帯域 | 公開論文のラベルと本書 | 結果を見る前 | なし。成績の良い形状への差替えは禁止 |
| 形状別の極・零点 | 各形状のDfitだけ | 適合終了時 | なし。保留点で再適合しない |
| 話者定数・母音の共通規則 | E0には導入しない。形状別係数は身体定数ではない | ― | 話者音声・母音特徴を受け取らない |
| 利得・観測補正 | gのみDfitで決定。既に公開されたVVTFを対象とする | 適合終了時 | 周波数依存の補正やマイクEQは追加しない |
| 条件入力 | 表の周波数座標。F0・イベント入力は導入しない | 点検対象の座標は分割時に固定 | 周波数のみ。Dcheckの振幅は点検器だけへ渡す |
| 最適化の乱数 | 固定した開始点生成規則・種一覧 | 測定値を使う前 | 良い結果の種だけを選別しない。開始点別の結果を残す |
| 生成の乱数 | E0のモデル応答は決定論的なので不要 | ― | なし |
| 保留した測定振幅 | 点検器だけがDcheckを読む | 候補フィルタを固定した後に開く | 候補側へ振幅列を渡さない |

一つの保留点での情報経路は、`形状ID → Dfitで固定した13個以下のモデル変数 → 指定周波数で式を評価 → 候補振幅`で完結する。点検器だけが対応するDcheckの測定振幅を読み、誤差を計算する。測定表を高密度なフィルタとして最終生成器へ渡さない。

別話者を扱う後段では、無適応生成、少数録音による適応、別話者での手順再検証を別の試験名にする。初回はどれも主張しない。将来の最初の話者試験には、方式を固定して新話者に再適合する「手順再検証」を選び、適応なしの生成と呼ばない。共通規則を試す際も、その式と推定可能な項を固定してから条件を保留する。

**6．最初の実験カード：E0。** このカードは、上記の公開配布物が取得できれば、新規の収録者・聴取者・専門装置を必要とせず完了できる。取得後の処理も含めて今後の作業であり、本改訂では実行しない。

|---|---|
| 一つの判断 | 対象帯域の研究用声道基準としてP5を残すか、声道表現の変更を先に行うか |
| 入力 | 指定2形状の測定VVTF表。数式から生成する、実装点検用の既知P5/P5Z応答 |

**手順は五つに限定する。**

1. **入力を確定する。** 指定2表の形式・対象帯域を確認し、Dfit/Dcheckを機械的に分ける。欠測や不正値の扱いを記録し、結果に都合の悪い区間を後から除外しない。形式が仕様と違う場合は適合前に停止する。
2. **比較手順が既知の差を扱えるか確認する。** 数式から既知のP5応答と、ρがゼロでないP5Z応答を各一つ作る。真の係数を代入して残差が数値精度内になること、未知初期値から各モデル自身の応答を暫定0.05 dB RMS以下へ回復できることを確認する。これは実装・探索の点検であり、人間についてのモデル妥当性ではない。係数が一意に戻ることは要求しない。
3. **公開測定のDfitへ適合する。** 範囲内の複数初期値と、P5解をρ=0でP5Zへ渡す初期値を用いる。各適合の予算1/4・1/2・全部で残差を残す。P5Zには必要に応じ零点が非ゼロの開始点も与える。開始点数や評価回数が同じというだけで公平性を宣言しない。
4. **モデルを固定してDcheckを開く。** 形状別に判定する。Dcheckで選んだ係数や重みへ戻さない。係数を修正するなら、そのDcheckは開発資料へ移り、最初の保留点検には合格したことにしない。
5. **採否と限界を報告し、終了する。** 下の規則で次の研究対象を一つだけ選ぶ。係数の比較だけでなく残差が集中する帯域を残す。合成器全体の最適化へ自動的に拡張しない。

**暫定的な採否規則。** 誤差を`e(f)=20 log10(|P(f)|/|H測定(f)|)`とする。形状ごとにDcheckのRMSが1 dB以下、最大絶対値が3 dB以下なら、この実験の振幅近似基準を満たすとする。これらは**工学的な暫定許容値**であり、自然さの実用差ではない。厳密な同一信号の再現や、可聴差未満を意味しない。

閾値は測定への適合前に固定する。所定値の半分・2倍で判断が変わるかは感度分析として併記するが、後から都合のよい閾値へ変更して成功にしない。閾値近傍で、開始点差・予算増加による残差の変化が判断を左右する場合は判断不能とする。参照測定の不確かさを数値化できない場合、結論は公開された数表に対する近似精度までとし、物理装置への絶対誤差保証にはしない。

| **判断不能：既知応答を回復できない、予算曲線が未収束、制約境界が結論を左右する** | 表現力の比較まで到達していない | 実装・探索・探索範囲を修正する。既知応答へ戻り、測定データを増やさない |
| **判断不能：配布物を取得できない、列や単位が確認できない** | 公開測定による判断はできない | 必要入力を指定2表に絞って報告。生成応答の点検だけを完了成果として区別する |

比較予算に達したら終了する。安定したP5Zの勝利もP5の数学的な最良誤差を証明しないので、「探索した範囲での研究用選択」と報告する。基準を満たすモデルがない場合、最も単純なモデルを次の比較用に残すことはできるが、それを品質成立や合格とは呼ばない。

**7．次に人の参加が必要になる条件。** E0の前に収録や試聴を要求しない。E0後も、必要な判断と観測を結び付ける。

| 新たに決めたい判断 | 必要になる情報 | 最小の次手 |
|---|---|---|
| 測定に合う声道と解析音源の組合せが、人声らしい音色として成立するか | 対象刺激に対する人の判断 | 固定した少数刺激の知覚予備試験P1。評価器は学習しない |
| 声道表現の改善が、知覚上も意味を持つか | 同じ音源・制御を使ったP5/P5Zの比較判断 | 差が最も大きい条件と、差が小さい対照条件だけを盲検比較する |
| 少数の共通規則で人間の発声条件をまたげるか | 条件が確認できる同一話者の適合用・確認用録音 | 公開録音の条件が合わなければ、まず1話者・1種類の操作について新規収録。話者一般化を同時に求めない |
| 音響的に同等な二つの状態説明のどちらを残すか | 両説明の予測が異なる身体観測 | 例えば接触に関する予測が分かれるときだけEGGを追加。流量の真値の代用にはしない |

P1の入口は、1秒の準定常発声、少数の固定したピッチと音源設定に限定する。数式から生成するLF型等の音源を使い、フレームごとの制御列は与えない。E0は位相を評価していないため、その組合せが知覚的に成立するかは新しい問いとなる。

P1の質問文は、例えば「録音か合成かを当てず、音色だけで答えてください。この音は、人の発声に似た音色として聞こえますか」とする。回答は「そう聞こえる／どちらともいえない／そう聞こえない」。母音名は事前に示さず、識別課題は別セッションまたは別参加者へ分ける。対照は、事前に固定した同程度の持続時間・再生レベルの自然な持続母音と、手続き的な純音・倍音複合音とする。対照も無作為順に混ぜ、原産地当ての手掛かりになるラベルを除く。

判断不能を欠測扱いせず3値の比率を報告する。自然録音への肯定回答が少ない、または対照を期待した方向に区別できない場合は、候補の不合格より先に課題の妥当性を疑う。P1は質問と対照の予備検証でもあり、小人数で得た肯定率を音声品質の一般的な成立率にはしない。

母音識別90%・自然録音との差10ポイント等の固定値を、現段階の採否に使わない。E0には不要であり、P1ではまず課題が意図した判断を測っているかを確認するためである。正式な知覚確認へ進むときに限り、独立した予備判断で意味のある差を定め、固定候補・固定条件の比較へ適用する。優位の区間が実用差を越えれば改善、改善幅の上限が実用差未満なら実用的な優位なし、その間なら判断不能とする。「有意差なし」で同等とは判定しない。

条件別の検定を多数行って成功だけを選ばず、確認対象の条件と主たる比較を一つに固定する。追加比較は探索的結果と表示する。母音識別や自然さの絶対基準が必要になる段階では、その基準の対象を条件別に定義する。人数・反復数はその問いと予備分散から決め、144発声や数千の回答試行を研究開始の条件にしない。

**8．評価器を最適化する探索を、別に監査する。** E0では知覚予測器・MOS予測器・ASRを作らず、使わない。将来、少数の知覚判断を再利用する価値が示された場合にだけ、次の仕組みを導入する。

資料上の事実として、評価基準自体への最適化が、モデル選択の過適合と楽観的な性能評価を生むことは一般の学習研究で示されている。ここから「音声の局所評価器でも、通常の保留検証だけでは探索後の候補を保証できない」と考えるのは、本提案の推論である。[Cawley & Talbot, 2010](https://www.jmlr.org/papers/v11/cawley10a.html)

| 役割 | データを用意する時点 | 許す使い方 |
|---|---|---|
| C：校正 | 計画的な少数の変更対と判断を用意 | 特徴、相互作用、評価器、探索範囲の設計。通常の保留検証はここに含める |
| A：探索結果の監査 | 評価器・探索法・探索予算を固定し、実際に探索した後 | 選ばれた最良候補に加え、予算途中の候補と無作為候補を新しく評価。予測と知覚判断の逆転を調べる |
| F：最終確認 | 監査後に採用候補を一つ固定した後 | 校正・監査に使っていない新しい判断で確認。同じ固定音の再評価でもよい。確認結果で再選択しない |

3役を3つの大規模コーパスにする必要はない。例えば予算の半分をC、残りをAとFへ分ける設計から始められるが、配分自体も仮である。重要なのは、Aが通常の無作為保留刺激ではなく**固定した探索が実際に選んだ刺激**を含むことと、Aを見て修正したらその監査データを次回の確認へ再利用しないことである。同じ参加者を使う場合も、刺激と判断の役割を分け、順序による学習効果を扱う。

人の不在中に許すのは、最後に監査した生成器・制御定義を基準とする、一回の予算付き探索である。探索前に、変更できる変数、その組合せ、候補数の上限、始点からの最大移動量と累積移動量を固定する。距離は校正時に使った各変数の変化幅で規格化し、直前の候補ではなく監査時の基準から測る。小変更を繰り返して範囲を拡大する運用はしない。

未校正の相互作用、音源・位相・雑音規則の変更、許容した累積変更量の超過、予測区間が採否の境界をまたぐ候補は留保する。特徴値が範囲内でも、これらの条件を満たさなければ校正内とは扱わない。複数評価器の一致や狭い予測区間でも、共通の盲点は検出できないので、探索候補の監査を代替しない。

監査前の成果は「評価器が選んだ未確認候補」である。技術的な破綻の修正や測定誤差の低減は別途報告できるが、知覚品質の採用済み基準は更新しない。人が不在なら、未確認候補を基準にして次の探索を積み重ねず、反例の解析や他の工学的課題へ作業を移す。監査で順位が逆転した場合、評価器の適用範囲または特徴を改訂し、新しい監査を経る。初回校正には、監査した生成器と探索手順の範囲を超える効力を与えない。

**9．工程を増やさないための制限と反証条件。** E0では、LFの形状補正、複数話者の録音、共通制御の回帰、EGG、3D計算、知覚評価器、音素一覧の拡張を削除した。いずれもE0の判断には不要である。係数100個・16 bit相当という一律上限も撤回し、各モデルの自由変数を列挙する。浮動小数点計算を使い、量子化誤差を表現力不足へ混ぜない。

高密度な録音由来情報を排除する境界は、係数のビット数だけでなく、生成時に何を参照するかで管理する。公開測定の数表は評価側に保持できるが、候補は固定した11または13変数から応答を計算する。後段でも録音IDによる専用処理や、任意精度の定数・コード・乱数への波形埋め込みは行わない。

| 最も強い反例 | 変更する方針 |
|---|---|
| 硬い模型でのみ現れる鋭い共鳴・谷を改善しても、人間の声質には意味がない | E0の高精度化を続けない。固定候補の知覚比較または軟らかい壁・実発声に関する別の根拠へ進む |
| 振幅が合っても、位相・音源との相互作用・時間構造により人工的に聞こえる | 振幅の合格を品質合格から外したまま、その残る一要因を次の競合仮説にする |
| P5Zが、測定誤差や特定の補間点だけを近似して勝つ | 別測定・別形状での手順再検証が必要。追加自由度を普遍的な声道構造として採用しない |
| 誤差基準を少し変えるだけで採否が反転し、次の発声生成の結果も変わらない | その工学的差へ予算を割かない。単純な比較基準を残し、知覚または制御の問いへ進む |
| 二つの形状を通しても、自然発声では声道の近似誤差と音源の誤差を分離できない | E0の成果を対象限定と認める。音源の生理学的原因を主張せず、予測が分かれる追加観測を選ぶ |

E0の成果は、小型の声道表現について**使える条件か、拡張すべき残差か、まだ比較できない理由か**を一つ得ることである。その後は固定した生成器で人声としての成立を確認し、成立した狭い範囲から制御へ進む。自律作業を進める根拠は、このように判断可能な問題を分けることであり、知覚品質を自動的に保証することではない。
