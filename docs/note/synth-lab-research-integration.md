# `synth-lab` 研究成果の統合方針

## 目的

中断した `synth-lab` には、一般的な音合成、信号解析、物理・数理モデル、音楽アプリ基盤に関する調査と探索 Notebook がある。本プロジェクトが物理モデルだけに方式を限定しなくなったことを受け、発声に近い音を明示的かつ制御可能に生成するという目的に照らして再利用する。

原文は [`docs/reference/imported-synth-lab/`](../reference/imported-synth-lab/) に由来と状態を明記して保存する。この文書は、その資料を Voice Simulator の現在の研究へどう接続するかを定める。旧プロジェクトのゴール、ディレクトリ構成、技術スタックを引き継ぐものではない。

## 適用の判断基準

次の条件を満たす知見を優先する。

- 人間の発声に近づけるための生成機構、制御、解析、比較に使える
- パラメータと信号経路を説明できる
- 録音断片や学習済み音声生成器を最終音源の中核にしない
- 小さな実験で有効性を検証できる
- 既存の比較評価基盤へ測定結果を接続できる

## 優先して活用する領域

### 1. 解析・評価

時間領域、スペクトル、F0、LPC、MFCC、ラフネス、非調和性などの整理は、生成音の観察と比較へ直接利用できる。まずは既存の波形比較ツールと評価基盤で不足している指標を洗い出し、声らしさに対する説明力と頑健性を確認してから追加する。

特に有望な用途は次のとおりである。

- RMS、エンベロープ、ZCR による発声開始・終了と雑音成分の観察
- スペクトル傾斜、重心、フラットネス、ロールオフによる音源・摩擦成分の比較
- F0 軌跡と有声確率によるピッチ安定性・非定常性の評価
- LPC、ケプストラム、MFCC による声道特性と音色差の補助的な比較
- ラフネス、非調和性、スペクトルエントロピーによる声質と周期性の補助評価

指標は単独で品質の正しさを保証しない。窓長、サンプリング周波数、F0 範囲、レベル正規化などの条件を固定し、参照音声・合成音・異常系で校正する。

### 2. 明示的な合成方式

既存のフォルマントフィルタと波動管に加え、次の方式を候補へ加える価値がある。

- 加算合成と調和成分制御: 声門音源の倍音傾斜や声質の制御
- FOF/CHANT 系: フォルマントごとの時間応答を持つ母音・音節生成
- Modal 合成: 声道や空洞の共鳴を疎なモードとして扱う軽量近似
- WDF・回路アナロジー: 損失、境界、非線形要素を明示した声帯・声道結合
- Two-Mass Model、van der Pol など: 自励振動と発声開始の低次元モデル
- 変調・確率過程: jitter、shimmer、息成分、微細な非定常性の制御

これらは方式名だけで採用せず、同じ入力条件と評価指標で既存方式と比較する。

### 3. 高忠実度モデルからの参照

FDTD、LBM、流体音響、弾性体モデルなどは、リアルタイム実装の直接候補だけでなく、軽量モデルが落としている現象を調べる参照モデルとして扱う。計算コストが高い手法は、限定した形状・帯域・短時間のオフライン検証から始める。

## 保留または限定利用する領域

- リズム、ビート、クロマ、Tonnetz: 発声単体の当面の評価には優先しない。抑揚、歌声、韻律を扱う段階で再評価する
- PCM 音源史、グラニュラー、連結合成: 分析・比較対象にはできるが、録音断片を最終出力の主要成分にする方式は採用しない
- WaveNet、DDSP などの学習済み生成方式: 最終音源には使わない。評価対象、パラメータ推定、実験補助として使う場合も独立した検証を行う
- JUCE、Cmajor、Monaco、VST3 の設計: 旧音楽アプリの構想であり、現在の Web プロトタイプの技術選定を変更しない。将来ネイティブ実装が必要になった時点で再評価する
- TDA、群論、量子・天文データの可聴化など: 発声への具体的な仮説が立つまで探索候補に留める

## 資料から正式な成果へ進める手順

1. 移管資料から、発声に関する具体的な仮説を一つ選ぶ
2. 一次資料と現行ライブラリ仕様で、数式・アルゴリズム・権利条件を確認する
3. `research/experiments/` に自己完結した実験を作り、入力、条件、評価、結果を記録する
4. 既存の参照音声と合成方式を同じ評価条件で比較する
5. 再利用する処理を CLI またはライブラリへ切り出す
6. 検証済みの結論だけを `docs/note/` の正式な知見へ反映する

## 最初の候補

短期的には、次の順が既存成果へ接続しやすい。

1. 既存の波形比較結果に、スペクトル傾斜・フラットネス・F0 安定性の候補指標を加える小規模な妥当性実験
2. 加算合成または FOF による声門音源・フォルマント励振を、現在の母音プロトタイプと比較する実験
3. Two-Mass Model または低次元自励振動子で、発声開始と非定常性を再現する実験
4. WDF または Modal 合成で、既存の波動管より軽量・安定な共鳴モデルが作れるかを比較する実験

探索 Notebook は結果を保持した参考実装であり、そのまま正式な評価コードにはしない。
