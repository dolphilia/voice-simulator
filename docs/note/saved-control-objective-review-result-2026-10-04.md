# 保存成果から制御目的を見直した結果

2026-10-04。承認された保存成果レビューを完了した。最終音源は非ニューラル、研究中のニューラル利用と無人実行を維持する。今回は音声品質の合格ではない。

## 結論

単独の非ニューラル未知文生成は、固定係数とHTS音源の隔離実行で工学的に確認されている。しかし教師からの品質移転、共有制御の未知文一般化、独立最終確認、日本語用知覚資格は未達である。ニューラルの学習lossが小さいこと、局所F0-MSEが改善すること、内容が保持されることを別々の結果として扱う。

保存共有制御のtrain MSEは直接0.445620、ニューラル0.064886、学生0.447843だった。ニューラルの学習時の優位は学生では再現されず、ニューラル自身も新8文の内容・支持条件を満たさなかった。学生の表現容量だけが失敗の原因とは断定できない。旧12文では直接・学生のF0-MSE改善があるが、新8文の両ASR全群条件を満たさない。直接・学生は各3条件、ニューラルは5条件で局所支持が欠損した。

音源・フィルタ対照では、候補欠損11件のうち5件がスペクトルの完全平坦化、2件が追加の単純励起で回復し、4件は継続した。時間・LF0が同じでも音源/フィルタと計測の相互作用がある。ただしこの54波形の内容ASRは0であり、平坦化を日本語品質改善とは呼べない。

短イベントの測定器は三campaignとも限定資格未達だった。同じ24保存信号の再評価は独立確認ではない。窓整合の境界除外による内側246/246の診断も、境界14大誤りを消す採択には使用しない。計測器資格だけを全音響研究の停止条件には拡大しない。
