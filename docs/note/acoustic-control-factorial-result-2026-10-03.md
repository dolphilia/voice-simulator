## 内容比較

短6文・長6文の12独立文、通常／変更の2指定、5方式で120最終WAV。Whisper base int8とReazonSpeech k2 int8で240認識、失敗・欠損0。かな変換とCERは従来方式のまま。以下は各条件191文字あたりの誤り数で、分母と文章は方式間で同じ。

|方式|Whisper 通常／変更|Reazon 通常／変更|両認識器・全比較群で保護|
|---|---:|---:|---|
|既定HMM|14 / 13|9 / 3|対照|
|直接F0のみ|17 / 17|7 / 4|不通過|
|直接継続長のみ|16 / 13|1 / 1|不通過|
|直接共同|18 / 10|4 / 2|不通過|
|蒸留共同|16 / 19|2 / 3|不通過|

事前条件は認識器ごとに、全体・短・長・変更指定4群の通常／変更／合算、計21群で対照以下の誤り数と欠損0。Reazonでは継続長単独が全21群・全24対で悪化しなかった。一方Whisperでは同方式の全体通常、長系列、変更指定群等が悪化した。直接共同もReazonの一部変更群で悪化し、蒸留共同はWhisper全体で悪化した。平均を両認識器で混ぜたり、良い系列だけ採択したりしていない。

たとえば「笛が鳴る。」の変更条件でWhisperの誤りは既定2、継続長単独5、蒸留共同6。「庭の隅に置いた鉢へ朝早く水を注ぎました。」の通常条件では既定2、直接共同5。どちらも実際の発音がこの認識文そのものだったという証明ではなく、保存された認識器の観測である。

旧8文での蒸留共同の合計改善は、この新12文の採択根拠にはならなかった。旧集合と新集合は文章が異なるため、実験間の差を制御方式だけの因果効果とは呼ばない。共同−F0単独−継続長単独＋既定の誤り数の合計差はWhisper −8、Reazon +5で一致しない。一般的な相互作用・統計的非劣性・知覚改善として解釈しない。

## 制御・測定の点検

120最終波形は全てE0通過、設定飽和0。各方式12対の指定応答は以下。F0相対応答誤差5%以内、活動区間長の相対応答誤差10%以内という事前診断幅を使用した。

|方式|F0応答 ACF / DIO|活動区間長応答|
|---|---:|---:|
|既定|12 / 11|10|

今回の主集計は70〜800Hzの自己相関（ACF）、旧音響改訂の応答集計はDIO/stonemaskだった。別途保存したDIO監査を併記し、旧版との件数を同一測定器の結果として比べない。120波形中2波形ではACFとDIO中央値の差が10%を超えた。どちらを正しい値とするかはこの比較では確定していない。

単独制御では24条件全てで非変更軸の指令を厳密に維持した。F0単独の実活動区間長は既定比0〜2%変化。継続長単独で半音指令を固定しても、F0中央値はACFで−9.21〜+2.87%、DIOで−3.94〜+1.18%変化した。ACFでは2条件が5%を超え、DIOでは0。指令の独立と実音響・測定の独立を同一視しない。

辞書診断は認識前に固定したMeCab辞書・上位16経路・同一分割／品詞／活用／原形の条件を維持した。曖昧な読みを含む記録はWhisper75/120、Reazon60/120。これは誤りの個数ではなく、文脈の読み候補が複数ある記録数。原稿に合わせて読みを選ばず、主CERは補正していない。この診断から内容の正解やASRの発音転記資格を認めない。
