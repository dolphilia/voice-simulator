# 実波形目標から共有制御へ移す比較：21文の目標資格と停止結果

2026-10-03。ユーザーの承認に基づき[共有制御比較案](../plans/waveform-target-shared-control-proposal-2026-10-03.md)を新ID `nas-wave-target-shared-20261003-v1` で実施した。**21訓練文の逆推定を完了したが、目標資格は10文で最低12文に届かず、共有fit・新文生成・AI評価を開始せず停止した。** 資料不足をゼロ目標・閾値緩和で埋めなかった。計画全体の品質条件は未達である。

## 実施した範囲

旧development21文、教師、前段、HMM、DIO＋StoneMask、固定共通支持域、母音・鼻音、3フレーム以上・50%以上有声、4基底、中心化先行・一様縮尺±3半音を使用した。追加教師・取得・共有fit・AIはいずれも0。

21文すべての既定・状態目標候補を先に生成し、状態snapshot一致、E0、内部不変を確認した。前回の4文の既定・状態目標候補は計8WAVのhashが完全一致。全入口を保存した後に逆推定を開始した。4文の支持域契約は旧hashと一致し、残り17文は教師採用区間と既定DIOの積集合を一度固定した。候補欠損に合わせて区間を削除・補間しなかった。

新8文候補は前段・履歴・語彙・音素文脈の重複だけを点検し、波形を生成していない。旧selection12文をfitへ転用せず、旧未使用最終確認群も保持した。

## 探索と失敗

実生成618回、598完了・20失敗。20失敗はいずれも固定局所有声支持域の欠損で、波形・DIO列・内部列・例外・台帳を保存した。信号生成やABIの失敗ではない。無効候補を受理せず、片側差分または更新の棄却へ進んだ。

差分は中央239、前進6、後退7、両側無効0の計252軸。追加縮小生成9回、実波形の正則化目的を厳密に減らした更新62件。1文は通常・許可縮小更新で受理できず直前波形を保持して停止した。反復上限・係数・差分幅・正則化は変更しなかった。

目標採否は実波形と工学条件だけから決まり、認識結果を使っていない。共有学習CLIの最低12文の拒否経路を別プロセスで検査し、台帳が変わらず、fit・新診断生成・AIが0であることを確認した。共有学習コードは未実行の準備段階であり、3方式の性能比較や学生への移行成功はまだ得られていない。

## 資料不足の原因と保存済み対照の可能性

各軸の更新幅は最大0.5、既定ゼロから最大3反復なので、最終係数の絶対値は最大1.5。15文の状態目標候補は係数のいずれかが1.5を超えていた。この制約と初期値が、状態目標候補より低いMSEへ届かない原因の一部になり得る。ただし、非線形性・有効域・正則化も関係し、これだけで原因を断定しない。

既定・状態目標・波形逆推定の保存済み実波形だけを静的に点検した。状態目標候補と波形逆推定候補に同じ支持域・工学・MSE・F0・活動長条件と「正則化目的が既定未満」を適用し、通過候補のうち目的が低いものを選ぶ**次案用の別規則**では17文（短10・長7）が揃った。状態目標候補7件・波形逆推定10件である。
