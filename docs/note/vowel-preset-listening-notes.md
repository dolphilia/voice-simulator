# 試聴メモ: 母音プリセットとスペクトル観察

## 目的

このメモは、`web/prototypes/vowel-formant-prototype/` の `reference` / `utau` / `tuned` プリセットを試聴・観察するときの記録欄である。

現在の Web プロトタイプには、0〜4 kHz のリアルタイムスペクトル表示と、選択中母音の F1/F2/F3 表示を追加している。実線のフォルマントマーカーは選択中のプリセットセット、薄いマーカーは同じ母音に対する他プリセットセットの目標位置を示す。

## 現在の前提

- `reference`: 手入力の初期フォルマント値
- `utau`: UTAU 分析から得た母音中央値ベースの候補
- `tuned`: 反復生成・比較実験で調整した候補

`tuned` は現時点では `/a/` のみ調整済みで、`/i/ /u/ /e/ /o/` は `utau` と同じ値を使う。

## /a/ の反映値

| セット | F1 Hz | F2 Hz | F3 Hz | 備考 |
| --- | ---: | ---: | ---: | --- |
| `reference` | 730 | 1090 | 2440 | 初期実装値 |
| `utau` | 962 | 1405 | 2378 | UTAU 分析値 |
| `tuned` | 1073 | 1405 | 2053 | 反復生成・比較実験の Web 反映値 |

`tuned` の F2 は、比較ツール側の参照 LPC で欠損しやすかったため `utau` 値を維持している。

## 観察時の見る点

- `reference` から `utau` / `tuned` へ切り替えたときに、F1/F3 のマーカーが想定通り移動するか
- 0〜4 kHz のスペクトルピークが、表示されている F1/F2/F3 と大きくずれていないか
- `brightness` を上げたときに高次フォルマント付近の相対量が増えるか
- `breathiness` を上げたときに 3.4 kHz 以上のノイズ床が増えるか
- `tractScale` と話者プリセットで、表示値と聴感上の母音高さが連動するか
