## 検証

- 全52,390ファイルを元のパスから読み直し、コピー時のSHA-256とサイズが一致した。
- 48件の既存封印文書は変更されていない。封印と移動済みファイルの対応20,580件（複数封印の重複を含む）もhashが一致した。
- 包括サイクルの全論理ファイルのサイズ・mtimeと位置台帳を照合した。媒体間のmtime精度差は、内容変更と区別して位置台帳に反映した。
- 元のパスからWAV、NPZ、Parquet、safetensors、wheelの形式・ヘッダーを正常に読めた。新規合成やモデル推論は行っていない。
- コピー破損、既存移動先、元ファイル変更、既存リンク、読み取り専用フォルダの権限復元等の安全性テスト7件に合格した。
- 一部のユーザー所有音声フォルダが0555で置換を拒否した。元データを保持して停止し、書込権限を置換時だけ追加する追記版へ修正した。対象と内容検証は変更していない。権限を一時変更した21フォルダは全件元の状態に復元済み。
- 移動台帳SQLiteの整合性検査に合格した。研究の生成・教師・AI評価・DSP・学習等の回数、campaign状態、既存論理容量、承認上限は変更していない。

## 容量と費用

- 内蔵の実空き容量：開始前 77,119,012,864 bytes（77.12GB）→ 最終 76,906,295,296 bytes（76.91GB）。
- 外部の実空き容量：開始前 246,511,775,744 bytes → 最終 224,962,781,184 bytes（224.96GB）。
- 包括台帳への今回の追加計上：経過時間 1258.0秒、累積書込 6,758,234,135 bytes。既存費用は引き継いだ。
- サイクル外の移動量も移動台帳に記録し、外部の実空き容量へ反映されている。研究の固定承認枠を自動拡張していない。

内蔵の現役リポジトリからデータ実体は移ったが、実空き容量に移動量相当の増加はまだ見られない。読み取り専用の確認ではTime MachineのローカルAPFSスナップショットが2件（`2026-10-07-181702`、`2026-10-08-001408`）残っている。旧ブロックが保持されている可能性がある。スナップショットや他の作業のデータは削除していない。
