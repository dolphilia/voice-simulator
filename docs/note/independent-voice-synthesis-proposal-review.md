## このレビューを読むAIエージェントへ

この文書は、対象提案書とその目的・制約、および対象提案書が引用する外部一次資料から評価したものである。既存プロジェクトの実装方式、実験結果、候補名、採否、保有資産を判断根拠として持ち込んでいない。それらを示すリンクも含めない。

改訂時も、既存プロジェクトのコード、データ、他の文書、Git履歴、過去の会話を調べる必要はない。対象提案書とこのレビュー、必要に応じた外部一次資料だけで独立した検討を続けてほしい。

以下は特定の合成方式を採用させる指示ではない。問題点を別の設計で解消したり、根拠を示して指摘を退けたりしてよい。指摘をすべて新しい工程に変換すると、かえって研究を重くする。結論を変え得る不足を優先し、重複する課題は一つの小さな実験で解くこと。

## 1. 総評と維持すべき点

本提案の最も価値がある部分は、目的を「録音の再現」から「少数の共通規則が未使用の操作条件でも成立すること」へ置き換え、失敗を表現力・推定・制御・観測・知覚の不確かさへ分解した点である。

特に次の判断は維持する価値がある。

- 知覚上の人声成立、音素識別、自然さ、制御性を別々に扱う。
- 音響一致を生理学的な内部状態の回復と同一視しない。
- 音響モデル、別の身体観測、既知入力の部分系実験を、情報源が異なる経路として比較する。
- 録音ごとの適合と共通規則からの生成を分ける。
- 既知解回復、多開始点、保留条件を使い、探索停滞だけで表現不能を断定しない。
- 録音由来の軌跡、専用コード、最適化した乱数種への情報の持ち込みを明示的に制限する。
- 人が不在でも確定できる工学的な成果と、知覚に関する主張を分ける。

一方、現在の「最小識別実験」は、実際には生成器の比較、条件共有、話者間確認、時間一般化、知覚予測器の校正を含む研究プログラムである。すべてを一度に満たそうとせず、最初にどの判断を変えるかを絞る必要がある。

## 2. 優先修正事項

### R1 — 共通規則と未使用話者の試験で、許される情報を確定する

対象: 第6節の条件別適合・共通規則・保留試験、第7節の話者別係数。

**問題:** 共通規則には話者・母音の定数が必要だが、確認用の新しい2話者について、その定数をどう得るかが未定義である。確認音声を使って定数や補正を調整すると、未使用話者に対する予測と、既知モデルの新話者への適合が混ざる。どちらも有用だが、支持できる主張が違う。

**求める改訂:** 次のいずれを試すかを明示し、必要なら別試験にする。

| 試験 | 許される入力の例 | 主張できる範囲 |
|---|---|---|
| 未使用話者への無適応生成 | 事前定義した条件入力だけ | 話者固有の適合なしで条件を生成できる |
| 少数録音による話者適応 | 明示した適応用録音と固定した推定手順 | 限られた適応後に別条件へ移せる |
| 未使用話者で方式を再検証 | 方式と適合手順は固定し、新話者で推定する | 同じ手順の有効性が別話者でも再現する |

共有パラメータ、話者定数、母音定数、イベント入力、観測系補正、乱数のそれぞれについて、「どのデータから決めるか」「いつ固定するか」「保留音声から何を受け取れるか」を表にする。

高F0・息漏れ・/i/の組合せ保留も、共有関数の形式によって意味が変わる。主効果・交互作用をどこまで許すかを決め、保留条件が学習条件から推定可能か確認する。識別できない交互作用を含めて失敗した場合に、生成器の能力不足と結論しない。

**解消の確認:** 一つの保留刺激について、生成に使う情報の全経路を列挙でき、保留対象からの目的外情報が入らないこと。

### R2 — M0/M1比較を、再現可能な操作と限定された結論へ落とす

対象: 第6節のM0/M1、第7節の生成器仕様。

**問題:** 「低域の倍音比と広帯域の傾きを変える二つの滑らかな補正」だけでは、比較する操作を一意に実装できない。絶対周波数上の補正か倍音番号上の補正かで、F0変更時の予測も異なる。

さらに、声道を共通のモデル形式にするだけでは、音源と声道の補償関係は消えない。各モデルで声道係数を再適合する場合と固定する場合では、M1の勝利の意味が変わる。M1は「追加した自由度に価値がある」を支持しても、「声門の形状が真の原因だった」をそのまま支持しない。

**求める改訂:** 補正の基底・単位・支持帯域・係数範囲・F0依存・位相規則・レベル処理を固定する。二つの補正が互いに、また元のLFパラメータと、ほぼ同じ変化を作っていないかを確認する。局所感度の比較はその一例であり、手法は固定しない。

比較を「制約した音源の形状を少し自由化する価値」の試験とするのか、「出力整形の追加自由度」の試験とするのかを選ぶ。後者なら、無理に生理学的な帰属を求める必要はない。前者を主張する場合は、声道の再適合や別の補正配置で説明できる可能性を排除する対照が必要になる。

パラメータ数が異なるため、同じ開始点数や評価回数だけで探索の公平性が保証されるわけではない。両モデルの既知信号での回復、予算に対する改善曲線、安定した結論が得られる範囲を報告する。

**解消の確認:** 係数ゼロでM0に戻ることを検査でき、勝敗から言えること・言えないことを事前に書けること。

### R3 — 最小実験を、人の参加前に完了する単位と知覚確認に分ける

対象: 第6節の144発声・20〜30人の試聴、第9節の資源と自律作業。

**問題:** 収録4人、試聴20〜30人×60〜100試行は、約1,200〜3,000の回答試行を含む。数値自体が不適切という指摘ではないが、「最初の小さな識別実験」と「方式の確認試験」と「局所評価器の学習」が一緒になっている。人の逐次関与を減らす目標に対し、開始時の負担と日程依存が大きい。

**求める改訂:** 最初に答える問いを一つ選び、次の二つの入口を具体化する。

- 追加収録・追加試聴が得られる場合の、最小の情報価値ある実験。
- それらが当面得られない場合に、外部の公開資源と生成信号で完了できる実験。

後者を一般的な「数値検証をする」で終わらせず、利用するデータの条件、競合予測、出力物、合成回数または計算予算、停止条件、結果別の次手を指定する。外部データが目的条件を満たさない場合は、その制約内で答えられる別の問いへ縮めてよい。

人の参加がない状態では、知覚品質が確認できないこと自体は欠点ではない。欠点は、それでも完了できる実験が実行可能な粒度まで定義されていないことである。

**解消の確認:** 新たな人の回答なしで、最初の実験を開始・完了・報告できるかが分かること。実行が不可能なら、必要な外部入力を一つに絞って示すこと。

### R4 — 一回の知覚校正を、適応的な探索へ繰り返し使う根拠を補う

対象: 第5節の局所知覚予測、第9節の初回校正後の自律改善。

**問題:** 話者や刺激対を外した通常の予測検証に通っても、その評価器を最大化する探索が作った候補に通用するとは限らない。探索は評価器にとって都合のよい領域へ選択的に進む。個別の変更が局所的でも、連続した変更の合成は校正対象から離れ得る。

提案は適用範囲外で留保すると述べているが、「どのように範囲外を検出するか」「検出できない誤りを何で監査するか」は未確定である。

**求める改訂:** 少なくとも、以下の役割を分ける。

1. 評価器を作る校正資料。
2. 評価器と探索手順を固定した後、その探索が実際に選んだ候補を調べる監査。
3. 最終的なモデル採用に使う確認資料。

この3役をすべて大きなデータセットにする必要はない。予算内の分割方法を提案する。予測不確実性・累積変更量・未校正の相互作用などに応じた留保規則と、人が不在の間に許す探索範囲も定める。

機械的な修正も、録音との従来の一致や知覚的な長所を変える場合がある。「定義どおりの実装へ直った」と「知覚品質が保持された」を別々に扱う。

**解消の確認:** 一度の校正を無期限の品質保証にせず、探索による選択バイアスを調べる手順と、その監査前に認める主張があること。

### R5 — 公開資料で確認できることと、提案モデルへの転用を明確にする

対象: 第3・4・9節の先行研究と公開資源。

**確認した点:** Kreimanらの研究の1秒の準定常/a/、10 kHz標本化、録音由来の制御軌跡という適用限定は、提案書が適切に扱っている。一方、同論文のTable IにはF1〜F11と帯域幅、最大3つのスペクトル零点なども挙がる。実際の全刺激で全自由度を必要としたという意味ではないが、少数音源変数だけの十分性を示した研究とも読めない。[Kreiman et al., 2021, Table I](https://idiom.ucsd.edu/~mgarellek/files/Kreiman_etal_2021_JASA.pdf)

**求める改訂:** その論文の生成器からM0/M1へ何を省略しているかを短く対応付ける。共鳴器5対という開始案を撤回する必要はないが、失敗した際に音源自由度だけへ原因を押し込まない対照を定義する。対象帯域・許容誤差に対して共鳴モデルが十分かを確認する方法を示す。

**追加で確認した点:** OPENGLOTの自然発声Repository IVは、内視鏡下で/i/を指示したものの、実際の音は[æ]〜[œ]になったと記載している。F0と発声様式にも固定した達成目標を用いていない。したがって、同期観測の診断には有用でも、提案された/a/・/i/×3 F0の確認資料にそのまま置き換えることはできない。[Alku et al., 2019, §2.5](https://math.aalto.fi/~jmalinen/MyPSFilesInWeb/OPENGLOT_accepted.pdf)

**求める改訂:** 公開資源について「入力として実際に得られるもの」「条件ラベルの意味」「答えられる問い」「代替できない新規収録」を示す。指示ラベルを達成された母音・F0条件と混同しない。

**解消の確認:** 資料の名前だけでデータ準備済みとせず、最初の実験に必要な条件の適合性が確認されていること。

### R6 — 経路Cのモデル比較で、未使用形状への予測方法を揃える

対象: 第4節、既知形状の模型に対する低次共鳴器と一次元管の比較。

**問題:** 一次元管は形状を入力にできるが、低次共鳴器はそのままでは未知形状から極・零点を決められない。保留形状の実測伝達関数に共鳴器を適合するなら、それは予測ではなく近似である。この差を残したまま比較すると、モデルの良否と入力情報の違いが混ざる。

**求める改訂:** 比較したいものを、次のいずれかへ明確化する。

- 同じ既知形状情報から未知の応答を予測する能力。その場合は共鳴器の係数を形状から得る規則も開発条件だけで固定する。
- 既知応答を小さなモデルに近似した後、別の励振で応答を再現する能力。その場合は形状への汎化と呼ばない。
- 形状を固定し、定義済みの負荷・境界変更への応答を予測する能力。その場合は両者の境界変更規則を明示する。

**解消の確認:** 比較する両モデルの入力と適合に使える観測が一覧化され、未知条件の測定を使わずに予測を出せること。

### R7 — 知覚判断と判定基準を、分析可能な仕様にする

対象: 第1節の人声成立、第6節の試聴と判定、第10節の暫定採用。

**問題:** 「人が声を出している音」という質問は、音響的な人声らしさと、録音の出自が人間かどうかの推測を混ぜ得る。また、先に母音名を答えさせると、その後の人声判断に言語的な手掛かりを与える。非人声対照の選び方によっても課題の難度が変わる。

**求める改訂:** 質問文、提示順序または課題分離、回答選択肢、対照音の選定規則、どの区間を試聴するかを指定する。曖昧さ・判断不能をどう扱うかも決める。

判定については、次を明確にする。

- 母音識別90%を、全体平均・母音別・条件別のどれに要求するか。
- 自然録音から10ポイントの非劣性を、どの確率差と片側区間で判定するか。自然録音自体の成立率が低い場合の扱いも定める。
- 音響的なδと自然さの実用差を分け、後者をどの独立した予備判断で固定するか。
- M1に「実用的な優位がない」と判定するには、優位を検出できなかっただけでよいのか、改善幅の上限が十分小さい必要があるのか。
- 多条件のうち一部だけ成功した場合の適用範囲と、多数の比較から成功だけを選ぶことへの対策。

第10節の「差を判断できない場合は最小実装を暫定採用」は、既に絶対的な成立条件を満たしている場合と、満たしていない場合を分ける。後者では、採用するのは次の研究用の比較基準であり、品質成立の判断ではない。

**解消の確認:** 同じ回答データを与えたとき、別の担当者が同じ採用・限定採用・判断不能を返せること。細かな閾値の追加より、判定対象の明確化を優先する。

## 3. 主たる修正の後に扱う点

| 点 | 改訂の方向 |
|---|---|
| 3反復で変動の分布を調べる | 周期間・発声内・反復間・話者間を区別する。反復3件で分布の裾まで推定したとはしない。必要な統計量を絞る |
| 持続時間変更の試験 | 定常部分を延長するだけなら自明に成功し得る。時間制御や変動過程について競合予測が分かれる操作を選ぶ |
| 100係数・16 bit相当・イベント8値 | 合理的な仮説上の予算だが、数値精度の上限か保存情報量の尺度かを明示する。余計な量子化誤差を品質限界に混ぜない |
| 観測系Mの補正 | 補正の関数形、共有範囲、独立校正の方法を指定する。雑音・部屋の特徴を知覚判断の手掛かりにしない処理は、発声自体を変えた可能性も記録する |
| 経路Aを先に選ぶ理由 | 絶対的な優位ではなく、目的に対する費用・得られる情報・次手を変える可能性で説明する。安価な経路B/Cの情報を先行利用する選択肢まで排除しない |

## 5. 改訂版に求める成果物

提案書を長くすることより、次の判断に必要な情報を揃えることを求める。

1. **目的と最初の問い:** 最初の実験が変え得る判断を一つに絞る。
2. **情報経路表:** 各パラメータ、適応入力、観測補正、保留条件の境界。
3. **比較仕様:** 実装可能なM0/M1、または理由を示した別の最小比較。
4. **実験カード:** 入力、手順、予算、観測、成功・失敗・判断不能時の次手。人の新規参加の有無で入口を分ける。
5. **校正と採用の境界:** 適応的探索による誤りをどう監査し、監査前に何を暫定的に許すか。
6. **改訂対応表:** R1〜R7の採用・代替解決・保留・反論と、その理由。

現在の提案から最も優先して残すべき核は、「失敗原因を見分けるために、予測が分かれる条件を選ぶ」ことである。改訂では、この原則を最初の実験そのものへ適用してほしい。方法やモデルを追加する前に、その実験が本当に競合説明を区別できるかを確かめることが重要である。
