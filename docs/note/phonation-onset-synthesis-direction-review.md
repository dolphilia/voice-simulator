# 調査メモ: 人間らしい母音立ち上がりの合成方針

作成日: 2026-08-25

実行計画: [`母音立ち上がり音源モデルの研究と統合`](../plans/phonation-onset-source-modeling-plan.md)

## 1. 結論

母音の立ち上がりは、単一のゲイン包絡ではなく、少なくとも次の四つの過程が時間差を伴って進む現象として扱うべきである。

1. 呼気と声門姿勢の準備
2. 小振幅かつ不規則な振動から周期振動への成立
3. 声門閉鎖、衝突、音源スペクトルの成立
4. 母音の調音目標への収束

最初に採るべき方式は、これらを少数の共有状態から駆動する**周期同期型のパラメトリック状態遷移モデル**である。次に、声門パルスを時変 LF モデルへ置き換える。それでも人間音声の開始効果を移せない場合に、二質量または body-cover 型の自励振動モデルへ進む。

既存の `phonation-onset-nonstationarity` 実験は置き換えない。凍結済みチェックポイントは、開始部仮説と現行 C 系列の限界を判断するための事前契約済みベースラインとして完了させる。その後に、声門音源の成立過程を主対象とする後継実験を別ワークスペースとして接続するのが妥当である。

## 2. このメモの位置づけ

既存の計画書 [`phonation-onset-and-nonstationarity-research-plan.md`](../plans/phonation-onset-and-nonstationarity-research-plan.md) は、H1〜H6、split、刺激、試聴前の判定規則を固定している。フェーズ0〜6は実施済みで、15提示の第1試聴だけが未回答である。

本メモは、その計画を結果を見る前に書き換えるものではない。以下を目的とする設計レビューである。

- 現行 C1〜C7 が何を検証でき、何をまだ再現していないかを明確にする
- 前回提案した実測軌道、時変 LF、自励振動の優先順位を具体化する
- 次の実験を既存研究へどう接続するか決める
- 物理モデルへ進む条件と、進まない条件を定める

## 3. 現時点の証拠

### 3.1 リポジトリ内の結果

development 6件では、音響活動開始から `stable_vowel_onset` 候補までの中央値が 110 ms だった。探索的中央値として、開始から安定部へ向けて F0、周期性、HNR、F1、F2 に変化が観測されている。

ただし、次の制約がある。

- 3話者、各2音源表情であり、同一条件の反復発声ではない
- 高めのF0を持つUTAU持続母音へ偏っている
- `stable_vowel_onset` は、現実装では `stable_source_onset` の30 ms後に置いた候補であり、formant安定化を直接検出していない
- HNRは周期性から代数的に導いた値、CPPは簡易 proxy であり、独立した複数の声質証拠ではない
- 知覚上のH1、H3〜H6は未回答である

したがって、110 msや各特徴の変化量を一般的な人間発声の既定値にはしない。現在の値は、候補範囲とテストfixtureにだけ使用する。

### 3.2 文献から支持される分解

人間の高速度撮影では、発声前の声帯内転と最終発声姿勢の形成が、実際の音響的発声開始より前から進む。modal、breathy、pressedで時間や声門形状も異なる。このため、音響活動開始から定常母音までを一つの補間曲線に縮約するのは不十分である。

健常成人の発声開始には、小さく不規則な声帯縁振動から定常周期振動へ至る短い区間が報告されている。これは、完成した周期音へ白色ノイズを加えることと同一ではない。

力学モデルでは、発声開始中の衝突増加だけでもF0上昇が生じ得る。したがって、F0軌道を独立したピッチ操作として与えるだけでなく、閉鎖・衝突状態と結び付ける候補に価値がある。

二層・二質量系の研究では、声帯剛性、形状、声門開大、声門下圧が発声閾値、開始F0、振動様式へ影響する。物理モデルは「より精密だから」ではなく、同じ少数の原因から振幅、周期、閉鎖、スペクトルを同時に生成できる場合に採用価値がある。

一方、声門逆フィルタリングは高F0、息声、soft voice、開始直後で誤差が増えやすく、source-filter interactionの影響も受ける。推定声門波形を正解として直接模倣せず、複数方式・信頼度付きのパラメータ候補として利用すべきである。

### 3.3 時間範囲を混同しない

文献にある数百msの「phonatory posturing」は、発声前の内転開始を含む。リポジトリで得た110 msは、音響活動開始から安定母音候補までである。両者は矛盾せず、別の区間を測っている。

合成器で直接再現する主対象は、まず可聴な次の区間とする。

```text
呼気が聞こえ始める
  -> 最初の振動
  -> 周期性の確立
  -> 音源声質の安定
  -> 母音調音の安定
```

無音中の声帯内転そのものは音として直接生成できないが、最初の呼気量、声門開口、発振閾値を決める初期条件として表現する。

## 4. 現行 C 系列が検証しているもの

現行 [`synthesis.py`](../../research/experiments/phonation-onset-nonstationarity/src/phonation_onset/synthesis.py) は、完全生成音によって次を比較できる。

- ゲイン包絡だけか、複数軌道を加えたか
- F0軌道の有無
- 非調波成分と声質変化の有無
- formant収束の有無
- 低周波変動を共有したか、独立にしたか

これは最初のablationとして有効であり、チェックポイントを破棄すべきではない。

ただし、最終的な開始モデルとしては次が不足している。

1. 全状態がほぼ同じsmoothstepで進み、安定化順序を持たない
2. 周期性未確立を主に付加ノイズで近似し、周期長や周期波形自体の成立を表さない
3. 倍音音源の声門パルス形状が時間変化しない
4. aspirationが声門開口、呼気、閉鎖状態と力学的に結び付いていない
5. `coupled`条件の共有ドリフト量が小さく、「共有する発声状態」の検定として弱い
6. 最終正規化により、開始部と安定部の相対エネルギー設計が診断しにくい
7. source-filter interactionを含まない

現在のC6がC1を上回らなかったとしても、「複合的な立ち上がりは無効」とは結論できない。結論できるのは、現在の特徴表現と操作量では効果を移せなかった、という範囲である。

## 5. 改良モデルの設計

### 5.1 四つの状態変数

一つの進行度だけで全軌道を動かさず、次の四変数を持つ。

| 状態 | 意味 | 主に駆動する量 |
| --- | --- | --- |
| `airflow(t)` | 呼気駆動の成立 | 全体エネルギー、aspiration、発振可能性 |
| `adduction(t)` | 声門閉鎖姿勢 | 開口率、閉鎖強度、息漏れ、衝突 |
| `coherence(t)` | 周期振動の成立 | 周期長分散、周期脱落、パルス間類似度 |
| `articulation(t)` | 母音目標への到達 | F1〜F3、帯域幅、声道損失 |

状態は独立ランダムにはせず、順序制約と小さな時間差を持つ。

```text
airflow上昇
  -> adductionが発振可能域へ入る
  -> coherenceが周期単位で上昇する
  -> 衝突・閉鎖が強まり音源スペクトルが成立する
  -> articulationが母音目標へ収束する
```

modal、breathy、hard/pressedは、同じモデルの初期条件と時間差で表す。

- modal: airflowとadductionが近い時刻で発振閾値へ到達
- breathy: airflowが先行し、adductionが遅く、残留声門間隙が大きい
- hard/pressed: adductionが先行し、圧力蓄積後に振幅が急増

最初の対象はmodalとbreathyに限定する。hard onsetは衝撃的過渡と高域エネルギーが大きく、別の安全なゲイン設計が必要である。

### 5.2 サンプル単位ではなく周期単位で成立させる

開始直後の重要部分は、5〜40 ms窓の平均だけでなく、最初の数周期の並びとして表す。

周期 `k` ごとに次を生成する。

- 周期長 `T_k`
- パルス振幅 `A_k`
- 開口率またはLF形状 `R_k`
- パルス波形の前周期との類似度
- aspirationとの比率
- 周期脱落または非常に弱い周期の有無

`coherence` が上がるにつれて、これらを安定分布へ収束させる。白色ノイズを周期音へ重ねるだけの条件は対照として残す。

開始時の不規則性は必ずしも純粋な乱数でなくてよい。減衰する位相摂動、振幅成長中の弱い周期、二つの近接振動モードの競合など、時間順序を持つ決定論的またはseed固定の過程も比較する。

### 5.3 時変 LF 音源

既存waveguideには簡易LF型音源があるが、`alpha=0`の半正弦・線形復帰による近似である。後継実験では、Webへ直接実装する前に、オフラインrendererで正規のLFまたはRd系パラメータ化を検証する。

時間変化させる候補は次である。

- 開口率
- 閉鎖時刻
- return phase
- excitation strength
- spectral tilt
- 周期ごとの小変動

`adduction`と`coherence`からこれらを導き、同時にaspiration量を減少させる。LF波形をリファレンスからコピーせず、逆フィルタリングで得た特徴範囲へパラメータを合わせる。

### 5.4 aspirationの扱い

aspirationは完成音への独立highpass noiseではなく、少なくとも次へ結び付ける。

```text
aspiration_gain
  = airflow
   * residual_glottal_gap(adduction)
   * turbulence_gate
```

フィルタ特性も固定せず、声門開口や声道入口の状態に応じて緩やかに変える。ただし精密な乱流計算は行わず、帯域制限ノイズと時間包絡による手続きモデルを先に試す。

### 5.5 調音軌道

formant軌道は、声門音源の改良と同時に複雑化しない。まず次の三条件で必要性を確認する。

- 静的formant
- F1/F2だけが異なる時定数で収束
- F1/F2と帯域幅が収束

現行の `stable_vowel_onset = stable_source + 30 ms` は生成値の根拠には使わない。formant confidence、安定値からの距離、連続した滞在時間を使う実測境界へ更新してから軌道を当てる。

### 5.6 自励振動モデル

時変LFと周期同期モデルで開始効果を移せない場合、二質量または簡易body-coverモデルを実装する。

最低限の入力は次とする。

- 声門下圧ランプ
- 声門初期開大または内転軌道
- 上下質量の剛性と減衰
- 衝突
- 声道側圧力の簡易フィードバック

物理モデルを採用する条件は、単に音が違うことではない。

- 複数の開始様式を同じ因果パラメータで生成できる
- F0、振幅、閉鎖、スペクトルの軌道を同時に改善する
- 未使用F0・母音へ規則を変えず一般化する
- パラメトリックモデルより知覚評価が上がる、または同等品質を少ない恣意的曲線で得る

これを満たさなければ、物理モデルは研究対照に留め、実用合成器には採用しない。

## 6. 解析系で先に直す点

凍結済みチェックポイントの音声と判定契約は変更しない。以下は後継実験用の解析v2で直す。

### 6.1 境界

- 時刻原点をファイル先頭ではなく `acoustic_activity_onset` にそろえる
- `first oscillation` と `reliable periodicity onset` を分ける
- `stable_source`をRMSだけでなく周期性、パルス類似度、声質proxyの滞在条件で決める
- `stable_vowel`をformant軌道から独立に検出する
- 固定40 ms窓による時間ぼけを避け、開始検出と声質推定で異なる窓長を使う
- 時刻だけでなく、発声開始後の周期番号でも正規化する

### 6.2 特徴

フレーム特徴に加えて、周期ごとの次を保存する。

- 周期長と振幅
- 隣接周期波形相関
- 最大下降速度の音響proxy
- 開口率・閉鎖率の推定候補
- 局所jitter / shimmer
- 周期が安定域へ入るまでの周期数

HNRとCPPは現在のproxy名を維持し、別測定のように重複カウントしない。逆フィルタリングはIAIF系だけに依存せず、少なくとも二方式の一致度と合成fixture上の既知誤差を報告する。

### 6.3 正規化

全区間を一括で同じdBFSへ正規化すると、開始部と持続部の比率が候補間で変わり得る。後継実験では、安定部のRMSまたは知覚ラウドネスを合わせ、その状態で開始部の相対包絡を比較する。

波形相関や単一の複合スコアはモデル選択に使わない。軌道ごとの成立確認と知覚評価を分離する。

## 7. 後継実験の条件

新しい条件名は既存C系列や持続部の実験Dと混同しないよう、S系列とする。

| 条件 | 内容 | 主な問い |
| --- | --- | --- |
| S0 | 現行C6の再現ベースライン | 実装世代間の接続 |
| S1 | 四状態・複数時定数、従来の倍音音源 | 単一smoothstepの限界 |
| S2 | S1 + 時変LF音源 | パルス形状成立の寄与 |
| S3 | S2 + 周期単位のcoherence成立 | 付加ノイズではない不規則開始の寄与 |
| S4 | S3 + adduction連動aspiration | 息から有声音への移行の寄与 |
| S5 | 簡易二質量/body-cover音源 | 自励振動の追加価値 |

一度にS0〜S5を全探索しない。S1〜S4を段階的に作り、主要因の一要因除去を含む小さな試聴で絞る。S5は「人間開始部の効果は確認されたがS4までで移植できない」場合、またはS4の曲線数が物理モデルと同程度まで増えた場合に着手する。

追加仮説は次とする。

| ID | 仮説 | 反証条件 |
| --- | --- | --- |
| N1 | 複数時定数の状態遷移は単一smoothstepより自然な開始を作る | S1がS0を一貫して上回らない |
| N2 | 時変声門パルス形状は静的倍音音源より寄与する | S2がS1を上回らない |
| N3 | 周期単位の振動成立は付加ノイズ近似より寄与する | S3と対応対照に差がない |
| N4 | adductionと結合したaspirationは独立ノイズより寄与する | S4と独立ノイズ対照に差がない |
| N5 | 自励振動モデルは簡易モデルより一般化または知覚で優れる | S5がS4を上回らず複雑さだけ増える |

## 8. リファレンスへの合わせ方

人間音声は、波形断片ではなく測定分布として利用する。

1. 発声開始境界と最初の10〜30周期を抽出する
2. フレーム軌道と周期軌道を信頼度付きで推定する
3. 話者・テイクごとの生軌道を保存する
4. 曲線を少数パラメータへ近似する
5. 個々の波形ではなく、話者間で共通する順序と範囲をモデルへ移す
6. developmentでパラメータ範囲を決め、checkpointではモデル選択だけを行う
7. holdoutでは規則を変更しない

最適化を用いる場合も、目的関数は波形RMSEではなく、次のカテゴリ別誤差とする。

- 発振開始と安定化の時刻
- 最初の周期数
- F0軌道
- 振幅軌道
- 周期間類似度
- H1-H2、傾斜、非調波比
- formant軌道

自動値は自然さを順位付けせず、参照範囲外の候補除外と操作成立の確認に使う。

## 9. データ計画

既存UTAUデータは、パイプラインの開発と初期候補作成には残す。一般化判断には別系統の収録を追加する。

最低限の次段階は次とする。

- 5話者以上
- `/a/ /i/ /u/`
- 各母音・開始様式で3反復以上
- modalとbreathyを必須とし、hard/pressedは任意
- 発声前300〜500 msを含む
- 同じマイク距離、無加工、低残響
- 話者単位でdevelopment/checkpoint/holdoutを分ける

可能なら音響信号とEGGを同時計測する。EGGがない場合は、閉鎖や衝突に関する量を「音響proxy」と明記する。

`research/data/sample-index.csv` と実際の参照音源台帳が分離しているため、後継実験前に入力、権利、split、hashを一つのmanifestへ統合する。

## 10. 評価

第1試聴の評価軸を維持する。

- 人間の声として聞こえるか
- 実際に発声している感じがあるか
- 開始が自然か
- 持続部が自然か
- 母音同一性が保たれるか
- ノイズ、クリック、楽器音、加工音として聞こえないか

主評価は対比較とする。参照への近さだけでなく、S系列同士のablationを比較する。単独のプロジェクト内評価者で方向を決める場合は、重複回答の一貫性と複数話者・複数seedでの方向一致を要求する。人間一般について主張する段階では複数評価者を用いる。

候補の採用条件は次とする。

1. 開始自然さまたは発声らしさがベースラインより一貫して改善する
2. 母音同一性を下げない
3. artifact評価の悪化で説明されない
4. developmentだけでなく未使用話者・母音で方向が再現する
5. 人間音声断片を含まない

## 11. 既存研究との接続判断

### 判断: 上書きも置換もしない

既存実験は、事前に凍結した仮説検証として価値がある。刺激や判定規則を今から上書きすると、結果を見ていない段階でも研究履歴と再現性を損なう。また、現行C系列は後継モデルのベースラインとして必要である。

### 接続方法

1. 現在の第1試聴をそのまま完了する
2. `analyze-listening`でH1、H3〜H6を分類する
3. 結果と本メモを参照する短いamendmentを既存計画へ追加する
4. 後継実験を `research/experiments/phonation-onset-source-modeling/` として作る
5. S0により現行C6との音響・知覚上の接続を保つ
6. 後継実験でモデルを選んだ後、既存計画のフェーズ8「持続部非定常モデル」へ戻る
7. onsetモデルと持続部モデルを固定してから `/i/ /u/` とholdoutへ進む

既存計画のフェーズ8へすぐ進むのではなく、開始仮説が支持された場合は、後継音源モデルをフェーズ7と8の間へ挿入する。開始仮説が支持されなければ、後継実験は開始せず、境界と刺激設計の再検証を優先する。

| H1不支持 | onset中心仮説を保留し、A系列の境界・長さ・話者を再検証する。S系列はまだ作らない |
| H1支持、H3不支持 | 人間開始部には効果があるが現行合成へ移せていない。解析v2とS1〜S4を最優先する |
| H1・H3支持 | 現行状態遷移にも効果がある。S1〜S4で必要要因を減らし、一般化を優先する |
| H4支持 | 共有状態モデルを中核にする |
| H4不支持 | 共有状態を棄却せず、現行C6/C7の操作強度が十分だったかを解析してから判断する |
| H5不支持 | onset中のformant複雑化を後回しにし、声門音源へ集中する |
| H6支持 | onset固定後、持続部の非反復変動モデルへ進む |

## 追記: 2026-08-25 最終分岐

統制したUTAU 8比較とJVS 4比較では、onset文脈が人間らしさで選ばれた例は0件だった。定常部のみ1件、`SAME` 11件であり、H1は反証とした。開始自然さもUTAUとJVSで方向が反転した。

したがって本メモのS0〜S5提案は実装しない。物理モデルを含むonset複雑化にも進まず、完全生成の定常母音が母音・人声として成立する基準系を先に回復する。次工程は [`完全生成母音ベースラインの成立回復`](../plans/synthetic-vowel-baseline-recovery-plan.md) に移管する。

## 13. 推奨実施順

### 直ちに行う

1. 凍結済み15提示をブラインド試聴する
2. 回答を検証・解析する
3. H1、H3〜H6を支持・反証・未判定に分類する

### 開始仮説が支持された場合

4. 解析v2を実装する
5. S0〜S2を作り、単一smoothstepと時変LFの寄与を比較する
6. S3、S4を順次追加し、周期成立と結合aspirationをablationする
7. checkpointでS系列を一つまたは二つへ絞る
8. `/i/ /u/` と新規話者へ固定規則で移す
9. 簡易方式で移植できない場合だけS5を実装する
10. onsetモデル固定後に持続部非定常モデルへ接続する

## 14. 最終提案

最終方式を今の段階で物理モデルへ決め打ちしない。研究上の主線は次とする。

```text
既存チェックポイント
  -> 開始部効果の確認
  -> 周期同期型の四状態モデル
  -> 時変LF音源
  -> 結合aspiration
  -> 未使用母音・話者への一般化
  -> 必要な場合だけ自励振動モデル
  -> 持続部非定常モデル
  -> Web waveguideへの統合
```

この順序は、録音断片や生成AIを最終音源にせず、観測された人間音声の時間構造だけを、説明可能で制御可能な生成機構へ移すというプロジェクト方針に合致する。
