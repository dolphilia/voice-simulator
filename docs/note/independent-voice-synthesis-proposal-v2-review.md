# 独立音声合成提案・改訂版のレビュー

作成日: 2026-09-13  
対象: `independent-voice-synthesis-proposal-v2.md`  
判定: **E0は実行に近い小実験になった。適合と合格条件の整合を修正してから実施する。研究全体の品質改善方針としては、E0から発声生成への接続を補う必要がある。**

## レビューの情報境界

対象提案書、前回レビューの論点、対象提案書が引用する外部一次資料に基づく。既存プロジェクトの実装、研究結果、候補名、データ保有状況は根拠にしていない。改訂するAIエージェントも、それらを調べる必要はない。

今回の指摘は、提案を再び大規模化する要求ではない。以下のV2-1を実行前に修正し、V2-2・V2-3は短い接続仕様・判断規則として補うことを優先する。全面的な再設計や、新しい計測装置・大規模な知覚評価器は要求しない。

## 1. 改善された点

前回の不確かさを、工程の追加ではなく問いの限定によって減らした点はよい。

- 初回の判断を、指定した測定応答に対するP5/P5Zの振幅近似へ限定した。
- モデル式、パラメータ範囲、利得処理、入れ子の関係、有限予算を定義した。
- 未知形状の予測ではなく、既知応答の近似と明示した。
- 周波数の偶奇分割を、独立な物理検証と呼んでいない。
- 公開配布先・条件の確認と、数値ファイルの取得・検査を区別した。
- 新規収録・試聴をE0の開始条件から外した。
- 将来の評価器について、校正・探索候補の監査・固定候補の確認を分けた。

DVTD一次論文でも、指定形式のファイル、線形振幅・ラジアン位相、周波数刻み、範囲外の規定値、VVTFの定義と声門境界条件を確認できる。入力資料に関する説明はおおむね適切である。[DVTD論文、Measurement of the volume velocity transfer functions / Data Records](https://www.nature.com/articles/s41597-020-00597-w.pdf)

ただし、E0の仕様が精密になったことと、音声品質へ近づく研究経路全体が十分に定義されたことは分けて評価する。

## 2. 重要な修正

### V2-1 — RMSを最小化する探索では、RMSと最大誤差の同時達成を判定できない

優先度: 高。E0の採否を左右するため、測定適合の開始前に修正する。

対象: 第4節の利得処理、第6節の適合と採否規則。

適合は対数振幅誤差の二乗平均を最小化するが、合格にはRMS 1 dB以下と最大絶対値3 dB以下の両方を要求している。二つは同じ目的ではない。RMS最良の候補が最大誤差で不合格でも、RMSを少し悪くすれば両方を満たす候補が存在し得る。

例えば、誤差が少数の点へ集中する候補はRMSが低くても3 dBを超え得る。一方、全点の誤差が約0.8 dB以内の候補なら両基準を満たすが、RMSだけでは前者より劣る場合がある。これは目的関数の一般的な性質であり、DVTDで実際に発生したという報告ではない。

利得gを平均誤差ゼロに固定する操作も、二乗誤差には最適だが、最大誤差の制約に対して常に最適ではない。探索が十分収束しても、この不一致は解決しない。

このままではP5を「表現不足」と扱い、実際には不要なP5Zを選ぶ可能性がある。また、P5Z自体にも同じ誤判定が起きる。

**修正案は二択でよい。**

1. Hkeep/Hextendを「定義したRMS最適化手順が返す候補の成績」という限定された手順比較へ変更する。不合格から表現拡張の必要性を直接判断しない。
2. RMSと最大誤差を同時に扱う適合に変更する。例えばDfitで最大誤差を制約にしたRMS最小化、または二つの上限に対する違反量の最小化を行う。利得もその問題に整合させる。

Dcheckを見て解き直す運用にはしない。候補選定規則はDfitだけで固定する。既知応答の点検には、平均誤差が小さいだけでは合格できない残差配置を含め、採用手順が意図した条件を扱えることを確認する。

完了条件: 不合格が「別の目的を最小化した結果」である可能性を排除するか、その可能性を残した手順比較だと明示すること。

### V2-2 — VVTFから試聴用の音圧信号へ移る接続仕様がない

優先度: 高。ただしE0の振幅近似自体は、この仕様なしでも検証できる。P1へ進む前に必須。

対象: 第3節の測定対象、第6節の「P5を固定した発声生成へ進む」、第7節のP1。

E0が近似するのは、声門側から口唇側への体積流量比である。P1ではこれをLF型等の音源と組み合わせるが、LF出力の物理量、フィルタ出力の意味、口唇側の流量から再生用音圧へ変換する処理が指定されていない。

この境界が曖昧だと、同じP5でも放射の微分効果を欠落・重複させ得る。P1の失敗を音源形状や声道次数の不足として誤解することにもつながる。

**最小の追記として、次を定める。**

- 音源が流量を返すか、その時間微分を返すか。
- P5/P5Zを通した各信号の量と単位、相対レベルの意味。
- 口唇流量から観測音圧への変換をどこで一度だけ適用するか。
- 測定VVTFに含まれる境界負荷と、別途適用する放射・観測変換の区別。
- 16 kHz、100〜5,000 Hzで適合したフィルタを、どのサンプルレート・帯域で試聴するか。

E0では5,000 Hz以上の応答と位相を合格判定していない。極を7,500 Hzまで許しているので、判定帯域外の応答がモデル間で異なる可能性もある。P1でその帯域を再生するなら、差の存在を把握し、E0で検証済みと扱わない。共通の帯域制限でP1を限定する案も選べるが、その場合は広帯域の品質確認ではないとする。

資料上もVVTFは流量比であり、耳に届く圧力そのものではない。[DVTD論文、式(1)と測定方法](https://www.nature.com/articles/s41597-020-00597-w.pdf)

完了条件: 人に聞かせる信号を、測定対象と矛盾しない一つの信号経路から再現できること。精密な放射モデルの新規研究までは不要である。

### V2-3 — 任意の振幅基準に失敗したことを、声道拡張の必須理由にしない

優先度: 高。研究の進路に関する修正。

対象: 冒頭の一つの判断、第6節の両モデル失敗時、第9節の反証条件。

E0が解く近似問題には意味がある。しかし、硬い模型の振幅応答へ1 dB RMS・3 dB最大誤差で一致することが、後続の人声生成でどの失敗を防ぐのかは、まだ示されていない。暫定的な工学値と明記したことは適切だが、その値を研究の優先順位に使う根拠が自動的に得られるわけではない。

特に、両モデルが失敗したら極数か零点構成を変更するという規則は、声道近似を次々と精密化する経路を残している。第9節はその危険を認めているが、E0の結果表からそのまま分岐できる停止条件にはなっていない。

**E0は一回の有界な診断として残してよい。** 次のいずれかを短く追記する。

- 許容値は研究用の便宜的な選定規則であり、失敗しても発声生成を止める必須条件にはしない。
- 追加の声道比較を認める回数・総予算と、それを使い切った場合の次手を定める。
- 残差が後続の発声に影響する可能性を調べる簡単な感度確認を、声道再設計へ進む条件にする。

励振を変えて同じ線形応答を測ることは独立した物理検証ではないが、どの残差が発声信号に現れるかを見積もる用途はある。独立性のない確認をすべて無価値とせず、その用途を限定する考え方が適切である。新しい主実験を増やす必要はない。

完了条件: E0の不合格から、根拠なく「音源研究より声道再設計を優先する」へ飛ばず、近似精度の追求を終える条件があること。

## 3. 実装時に固定すればよい小さな不足

### V2-4 — 未定義の分岐を既知応答の点検後に凍結する

対象: 第6節の探索、停止、判断不能。

「探索は安定」「未収束」「制約境界が結論を左右する」は判断として重要だが、現状では担当者ごとに異なる解釈になり得る。測定適合の前に、開始点の生成規則、予算の配分、予算曲線の評価方法、候補の選び方、境界値へ達した場合の扱いを設定として固定する。数値を今すべて推測して書く必要はない。

ρが非ゼロの既知P5Z応答を一つ使うだけでは、二つのモデルを区別する手順の検証にはならない。零点が判定帯域外にある、効果が小さい、極と近接して相殺する場合にはP5でも近似し得る。

自己回復試験は維持し、点検用応答の選定根拠を追加する。少なくとも、P5へ戻るケースと、判定帯域で零点の効果が明示的に現れるケースを区別する。後者でもP5の数学的最良誤差を証明する必要はなく、探索手順が不必要な拡張や既知の効果の見落としを起こしていないかを見る。

これは追加コーパスや新しい研究テーマではなく、E0の比較手順の動作確認である。

## 4. 指摘し直す必要のない点

次の事項は改訂版ですでに適切に限定されているため、再び大きな修正要求にはしない。

- 偶奇周波数分割に独立な汎化能力を求めないこと。本文は補間点検と明記しており、その範囲では使える。
- 位相をE0で適合しないこと。振幅近似という問いには整合する。問題は後続試聴への引継ぎである。
- 新しい話者・共有規則をE0から外したこと。ただし元の課題が解決したのではなく、後段へ移ったという扱いを維持する。
- E0で知覚評価器を学習しないこと。初回の必須条件を減らす判断として妥当である。
- 数値ファイルを未取得であること。今回が提案書作成なら欠陥ではなく、取得・形式確認を実行時の入口に置けばよい。

## 6. 推奨する次の行動

全面改稿をもう一度求める段階ではない。短い実施仕様の補足で十分である。

1. V2-1について、手順比較へ限定するか、合格条件に整合する適合へ変えるかを決める。
2. V2-3について、E0が失敗しても際限なく声道近似へ進まない出口を固定する。
3. 既知応答で探索手順を点検し、V2-4の設定を凍結してからE0を実施する。
4. P1に進む前にV2-2の信号経路と再生帯域を確定する。

E0は有用な部分系診断になり得るが、それ自体が人声生成の難所を解決するわけではない。改訂版の良さである「一つの判断に絞る」を維持しつつ、その判断が本来の目的へどうつながるかを失わないことが重要である。
