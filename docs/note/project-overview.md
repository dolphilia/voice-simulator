# Project Overview

## プロジェクト概要

このリポジトリは、人間の発声に近い音声を、明示的かつ制御可能な生成機構によって合成することを目指すプロジェクトである。

物理的な正確さは有力な手段であり、重要な研究対象でもあるが、それ自体を唯一の目的とはしない。声道、声帯、喉頭、呼気の物理・音響シミュレーションに加えて、調音モデル、ソース・フィルタモデル、フォルマント合成、手続き的な DSP、規則ベースの制御、数値最適化、複数方式のハイブリッドなどを比較し、人間の発声へ近づくために有効な方法を選択する。

方向性の重要な参考例に [Pink Trombone](https://dood.al/pinktrombone/) と [VocalTractLab](https://www.vocaltractlab.de/) がある。これらのように、音の生成過程を視覚的・聴覚的・構造的に理解できることを重視しつつ、母音・子音、声質、調音運動、話者差、声道の材質や形状などを、より幅広く制御できるシミュレーターを目標とする。

## 設計原則

本プロジェクトでは、次の性質を重視する。

- 音がプロジェクト内の生成モデルから生み出されること
- 発声を構成する要素を明示的に制御できること
- 生成過程を説明、観察、検証できること
- 特定の録音音声がなければ発声できない方式に依存しないこと
- 学習済みモデルの模倣能力そのものを音声品質の中核にしないこと
- 一つの理論や実装方式に早期に固定しないこと

物理モデルは、これらを満たしやすい中核的な候補である。一方、非物理的または近似的な方法でも、生成機構が明示的で制御可能であり、発声の理解や品質向上へ寄与するなら対象に含める。

## 対象とする手法

- 発声器官の物理、流体、音響シミュレーション
- 管モデル、デジタル導波路、波動方程式に基づくモデル
- ソース・フィルタモデル、フォルマント合成
- 手続き的な信号処理や物理モデリング音源の技術
- 調音イベントや音素遷移の規則ベース制御
- 明示的なパラメータを持つ数理・統計モデル
- 参照音声からの特徴量測定やパラメータ推定
- 数値最適化によるモデルの校正
- 上記を組み合わせたハイブリッド方式

## 最終的な合成方式の対象外

- 録音音声の断片を接続または再生する方式
- 録音・加工音声を最終出力の主要成分にするサンプルベース方式
- 大量の音声で学習した生成 AI やニューラルボコーダに音声生成を委ねる方式
- 高密度なスペクトル列や話者埋め込みなど、元の声を復元するための表現を主要な音源とする方式

これらは比較対象として調査できるが、最終シンセサイザーの中核には採用しない。

## 人間の音声の位置づけ

人間の音声は、生成素材ではなくリファレンスとして使用する。主な用途は、音響特徴の測定、合成結果との比較、聴感評価、パラメータ推定、回帰テストである。フォルマント、基本周波数、帯域幅、スペクトル傾斜、タイミングなど、生成モデルを校正するための明示的で低次元な特徴量は利用できる。

原理検証、比較、問題の切り分けなどの研究途中では、既存音声の加工や一時的なサンプル利用を許容する。その場合は、由来、ライセンス、加工内容、目的、最終方式への採用可否を記録し、実験限定の手段であることを区別する。

## 生成 AI の位置づけ

生成 AI は、リファレンスやテストケースの作成、ラベル・メタデータの候補生成、実験コードや解析の自動化など、研究を支援する目的で利用できる。生成条件と由来を記録し、人間の録音と区別する。

音声生成 AI の出力を比較や検証へ使うことはできるが、生成 AI の出力や学習済み音声生成機能を最終的な音源にはしない。機械学習を測定や研究補助に使う場合も、その結果を独立した音響指標や人による観察で検証する。

## 研究・実装の進め方

研究では、音響解析、信号処理、数値計算、知覚評価、モデル比較を扱う。研究手段を Python や Notebook に限定せず、課題に適した言語と形式を選ぶ。再現可能な処理は通常のプログラムや CLI を基本とし、Notebook は目視、試聴、対話的な操作に価値がある場合に使用する。

プロトタイプでは、音の変化をすぐに聴けること、モデル内部を可視化できること、パラメータを操作できることを重視する。研究コードと製品コードを早期に統一せず、実験で有効性が確認されたモデルから段階的に再実装・共通化する。

## 資料収集と調査方針

調査対象は音声生成に限定しない。音声学、調音、音響学、流体力学、数値計算、物理モデリング音源、サウンドエフェクト、知覚評価、最適化、可視化・操作系など、発声モデルの生成品質、理解可能性、制御可能性に寄与する分野を広く扱う。
