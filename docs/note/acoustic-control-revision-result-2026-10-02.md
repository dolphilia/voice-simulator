# 音響量を学習する制御への改訂結果

2026-10-02。[原因監査](neural-control-transfer-cause-audit-2026-10-02.md)を受け、同じcampaignの残るレンダー枠で改訂版を実装した。**非ニューラルで単独生成できる研究版を作れたが、内容と自然さは未検証であり、品質採択はしていない。**

## 学習対象と実装

VTLの指令時間を教師にする方法を外し、既存の教師WAVから測った活動区間長と有声F0中央値を学習した。教師内部token列は誤読を除く照合に使い、音響時間の正解値にはしない。活動区間は相対RMS、F0はWORLD DIO＋StoneMaskの70–800Hz範囲で測った。これらは知覚評価や局所境界の資格を与える測定ではない。

旧開発12文と追加の長い9文を学習に、旧選別6文と追加の長い6文を選別に使った。既知33文であり、独立した最終品質確認とはしない。「箱／ばこ」の誤読1件は除外した。

入力は音素群の比率、口蓋化・無声化の比率、高いモーラの比率、句とモーラ数の比率など10特徴。活動長は基準モーラ長に対する比、F0は220Hzに対する比を予測する。指定速度とF0比は予測後に明示的に適用する。文長そのものを独立した回帰項にして外挿する方式を外した。

直接回帰、2層16ユニットの研究用ニューラル制御、その出力を蒸留した回帰を同じ資料で比較した。標準化した音響目標の選別損失は直接0.3808、ニューラル0.6626、蒸留0.3815。正規化・資料の異なる旧損失との数値比較はできない。ここでもニューラル制御の優位性は確認できなかった。

## 新しい8文の工学比較

10–12音素の短文4件と42–50音素の長文4件を生成前に固定した。通常条件とF0参照180/260Hz・速度0.85/1.15の変更条件で、4方式・64音声を作った。基準HMMの校正を含め112回生成した。

合格件数は同じ8文の通常条件に対する比率についての値。F0相対5%、活動長相対10%は工学診断であり、内容・自然さの非劣性幅ではない。

|方式|F0比|活動長比|補正範囲の飽和|
|---|---:|---:|---:|
|既定HMM|8/8|7/8|0/16音声|
|直接回帰|7/8|7/8|0/16音声|
|研究用ニューラル制御|7/8|6/8|0/16音声|
|蒸留回帰|7/8|7/8|0/16音声|

前回の文章群と異なるため、前回の不合格件数との差を対応のある改善量とはしない。今回の全64音声は信号の健全性検査を通った。

## 一回の測定補正

最初の生成波形を測り、時間とF0のずれを一度補正する処理を直接版・蒸留版に追加した。同じ8文の32音声を再生成したため、これは工学修正の検査であり、新しい独立確認ではない。

|方式|F0比|活動長比|絶対F0目標への追従|絶対活動長目標への追従|飽和|
|---|---:|---:|---:|---:|---:|
|直接回帰・補正後|6/8|8/8|11/16|14/16|1/16|
|蒸留回帰・補正後|8/8|8/8|11/16|15/16|1/16|

補正前の絶対活動長の通過は両方式12/16だった。時間の追従は改善した一方、直接回帰のF0比は7/8から6/8へ悪化した。相対的なF0比が通ることと、予測した絶対F0へ到達することも別である。補正前後を保存し、全体の品質改善とは認定しない。

## 最終経路の依存検査

[研究用bundle](../../research/experiments/neural-control-extension/results/nas-extension-20261002-v1/acoustic-revision/bundle/README.md)には固定回帰、規則、非ニューラルHMMを入れた。回帰係数は各モデル20個、bundleは約0.886MB。Python・依存ライブラリ・辞書の容量はこの値に含めない。教師音声、ニューラル重み、発話別の軌跡は同梱していない。

別の未知2文×2モデルを通常環境とOS隔離で実行した。教師音声・ニューラルモジュール・開発コード・ネットワークへのアクセス拒否をprobeで確認し、4組すべてのfloat32波形が一致した。各実行は校正、初回生成、一回補正の3生成。実行内の測定時間は約0.15–0.36秒、最大RSSは約121–135MBだった。Pythonとライブラリの起動時間はこの測定時間に含めない。

起動例（研究版、品質未検証）:

```bash
research/experiments/autonomous-speech-synthesis/.venv-eval/bin/python -I research/experiments/neural-control-extension/results/nas-extension-20261002-v1/acoustic-revision/bundle/runtime.py --text '風が止む。' --model direct_non_neural --pitch-reference 180 --speed 0.85 --output /tmp/acoustic-revision-example.wav
```

このコマンドの再実行にも実生成の計数が必要。既存campaignを延長する指示ではない。`pitch-reference`は学習した声の高さに対する220基準の指定で、指定値そのものの絶対F0を保証しない。

改訂版の保存済み音声は104ファイル、通常／隔離の同一波形を除くと100音声。これを2認識器で診断する[評価対象一覧](../../research/experiments/neural-control-extension/results/nas-extension-20261002-v1/acoustic-revision/pending-content-evaluation.json)を固定した。必要なのは追加AI評価200回で、追加の教師生成・再合成・学習は不要。実行はしていない。内容診断が通っても、それだけで自然さや最終品質の達成にはしない。
