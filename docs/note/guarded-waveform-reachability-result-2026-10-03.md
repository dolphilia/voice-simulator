# 固定支持域を守る実波形F0逆推定比較の結果

2026-10-03。ユーザーの承認に基づき[片側差分・縮小更新案](../plans/guarded-waveform-reachability-proposal-2026-10-03.md)を新ID `nas-guarded-f0-20261003-v1` で実施した。**開発4文すべてで、実波形の到達性と事前の内容保護条件を通過した。** 前回停止した雨の文は、無効な摂動を棄却して有効な側の差分を使うことで3反復を完了した。非ニューラル実波形へ制御を移す観測として前進したが、未知文の共有制御や最終品質は未達である。

## 固定条件と再現

旧DIO＋StoneMask、70–800Hz／5ms、教師区間、HMM区間、4基底、固定共通支持域、3有声フレーム以上・50%以上、中心化先行・一様縮尺±3半音、正則化0.1、最大3反復、各係数更新最大0.5を維持した。教師生成・共有モデルfit・依存取得は0。最終合成は既存の非ニューラルHTSである。

全4文の既定・状態目標候補、計8波形を先に再生成し、旧WAV hashとの完全一致を確認した。全8件の一致を保存してから新規探索を開始した。旧support-contractもファイルhashまで同一で、欠損候補に合わせた支持域の選び直し・削除・補間は行っていない。

純粋関数の中央・前進・後退差分、両側無効と有効なゼロ勾配の区別、固定縮尺、範囲拒否に加え、探索へ接続した制御を合成なしの模擬例で検査した。片側無効で続行、両側無効で停止、通常更新棄却時の1/2・1/4、縮小上限3、非改善時の直前波形保持、同係数の再生成禁止を確認した。旧の準備用関数をそのまま新探索に接続し、準備時の検査結果を実波形の品質証拠に流用していない。

## 実波形の結果

MSEは共通支持域内の中心化F0形状誤差（半音²）。状態目標候補の欄も実波形で測った値である。全体F0差・活動長差は各文の既定に対する相対値。

|文|既定MSE|状態目標候補MSE|旧厳格法MSE|今回実波形MSE|全体F0差 DIO / ACF|活動長差|診断|
|---|---:|---:|---:|---:|---|---:|---|
|豆を煮る。|5.569298|4.345704|3.829554|3.829554|+4.569% / +4.485%|+0.000%|通過|
|笛を吹く。|4.778151|2.046270|1.916681|1.916681|-2.654% / +0.972%|+0.000%|通過|
|机の引き出しに古い手紙が入っています。|6.623475|5.526682|5.444168|5.444168|-0.895% / +0.263%|-0.385%|通過|
|雨がやんだので窓を少し開けました。|11.497733|6.656338|11.497733|6.236100|-0.178% / -2.287%|+0.000%|通過|

全4文で最終MSEが既定未満かつ状態目標候補以下、DIO・ACFの全体F0差5%以内、活動長差3%以内を満たした。最終12条件すべてで支持域欠損0、E0通過、内部不変。状態継続長、MSD、スペクトル、非周期性、LF0動的平均は固定した。前3文の最終波形は旧厳格法とWAV hashまで同一である。

雨の文のMSEは11.497733から6.236100へ**45.76%減少**した。通常更新3件はすべて実波形の正則化目的を厳密に減らした。目的値は11.497733 → 9.726666 → 8.247873 → 7.136100。最終4係数はすべて−1.5で、上限±3の内側。これを最適解・合成器の数学的上限とは呼ばない。

## 無効候補と探索の差

全4文で116回を実生成し、113件完了・3件失敗。失敗はすべて雨の文の固定区間label 10（/a/）で有声支持域が欠損したためだった。波形・DIO列・内部列・例外・費用を保存し、無効候補を受理しなかった。

|雨の文の反復|無効な摂動|使用した片側差分|通常更新|
|---|---|---|---|
|0|軸1 minus、軸3 plus|軸1前進、軸3後退|受理|
|1|軸3 plus|軸3後退|受理|
|2|なし|全軸中央|受理|

全48軸の差分は中央45、前進1、後退2、両側無効0。縮小更新の実生成は0であり、**今回の改善は片側差分の続行による観測**である。縮小更新の波形上の有効性は未検証のまま。旧雨の探索は6生成で最初の無効摂動に停止し、今回は29生成で3反復を完了した。反復上限や閾値を延長した結果ではない。
