## 1. 目的

この計画は、人間の音声らしさへ寄与する時間的要因を特定し、その知見を、録音断片や学習済み音声生成器に依存しない合成モデルへ移すためのものである。

特に次の観察を、検証可能な研究課題として扱う。

- 人間らしさは、持続母音の定常部分より発声開始付近で強く感じられる可能性がある
- 発声開始には、掠れ、息漏れ、不完全な周期性、音高と音量の確立、調音目標への接近が含まれる
- 持続部分にも、ビブラートだけではない微細な不安定性や緩やかな変化がある
- 人間音声の定常部分を短くループすると、人間らしさが低下する可能性がある

最初から新しい合成器を大規模に作るのではなく、音声の切除、ループ、交換、特徴軌道の解析によって寄与要因を切り分ける。その後、効果が確認された要因だけを簡潔な生成モデルへ実装する。

## 2. 背景と現在地

既存の比較評価では、現行の formant 合成について次が確認された。

- 5 母音と `し/す` は強制選択で識別できた
- brightness と breathiness の操作方向は識別できた
- 一方、自然さ、音素同一性、声質は低く、楽器、オルガン、管楽器、初期 PCM 音源のように評価された
- 人間音声は強いノイズを加えても人間由来と認識されたが、定常的な調波・formant 合成は明瞭でも人間音声と認識されなかった
- スペクトル target の改善は、holdout で知覚上の参照類似性を改善しなかった
- 自動指標による自然さの暫定総合判断は独立検証に失敗し、`aggregate=null` として棄却された

したがって、定常区間のフォルマントや平均スペクトルをさらに調整するだけでは、主要な失敗原因へ届かない可能性が高い。次の研究では、声門音源と声道の状態が時間とともに成立する過程へ焦点を移す。

ただし、「定常母音だけでは人間に聞こえない」と最初から結論しない。定常部分は母音同一性や声質を保持し得るため、失われるものが人間らしさなのか、発話らしさなのか、話者らしさなのかを実験で分ける。

## 3. 研究上の問い

### Q1. 発声開始部は人間らしさへどの程度寄与するか

開始部の有無と長さを変えたとき、母音同一性、自然さ、声質、発声らしさがどの程度変化するかを調べる。

### Q2. 開始部のどの変化が重要か

音量包絡、F0、周期性、声門音源スペクトル、息・掠れ、formant 軌道の寄与を個別および組み合わせで調べる。

### Q3. 定常部分の反復性は人間らしさを損なうか

ループ長、周期の完全反復、F0・振幅・声質の変動の有無を操作し、人間らしさの低下が継ぎ目のアーティファクトではなく、時間変化の消失によるものかを調べる。

### Q4. 微細変動はどのような構造を持つか

F0、振幅、周期性、スペクトル傾斜、ノイズ量が独立に揺れるのか、同じ発声状態に由来する相関した変化なのかを調べる。

### Q5. どこまで簡潔なモデルで再現できるか

物理モデルを直ちに全面採用せず、測定された軌道を少数パラメータで表す状態遷移モデルを先に検証する。簡易モデルでは説明できない差が残った場合に、声帯の lumped-mass、声門流、声道との結合など、より物理的なモデルへ進む。

## 4. 仮説

| ID | 仮説 | 主な反証条件 |
| --- | --- | --- |
| H1 | 発声開始部を残した刺激は、定常部だけの刺激より人間らしさが高い | 開始部の有無で一貫した評価差がない |
| H2 | 人間音声の開始部を合成持続部へ接続すると、合成音単独より人間らしさが上がる | 接続品質を統制しても改善しない |
| H3 | ゲインの立ち上がりだけでは、実際の開始部の効果を再現できない | ゲイン包絡だけで実開始部と同程度に改善する |
| H4 | F0、振幅、周期性、声質を相関させた変化は、独立ランダム変動より自然である | 独立変動と差がない、または独立変動が優れる |
| H5 | formant が目標へ収束する軌道は、「舌足らずさ」や調音の成立感へ寄与する | 静的 formant と差がない |
| H6 | 完全反復する短い定常ループは、継ぎ目を除去しても人間らしさが低下する | 十分な継ぎ目対策後に評価が低下しない |

H1 と H6 は人間音声内の加工だけで検証できる。H2 は因果関係を視覚化しやすい一方、話者、F0、formant、位相、接続点の不一致が交絡するため、補助的な証拠として扱う。最終判断は、複数の実験が同じ方向を示すかで行う。

## 5. 対象範囲

### 対象に含めるもの

- 単独母音の発声開始から定常区間まで
- 最初は `/a/`、次に `/i/` と `/u/`、最後に 5 母音への一般化
- modal、breathy、やや rough な開始様式
- F0、振幅、周期性、声質、formant の短時間軌道
- 定常区間の微細変動と低周波ドリフト
- 自動解析、刺激生成、比較評価、パラメトリック合成

### 初期段階では対象外とするもの

- 子音を含む一般的な連続発話
- 感情表現や歌唱表現の再現
- 特定話者の同一性を再現すること
- 録音断片の再生、連結、granular 合成を最終方式にすること
- 大量の音声で学習した生成モデルや neural vocoder を最終合成器にすること
- 3D 流体構造連成を最初から実装すること

開始部・持続部の交換や加工済み人間音声は、仮説検証用の刺激に限定する。採用候補の最終合成音へ人間音声の断片を残さない。

## 6. 実験データ

### 6.1 データ選定

最初の実験では、権利と由来を確認できる既存リファレンスから、次を満たす単独母音を選ぶ。

- 3 話者以上
- 各話者で `/a/` を 2 テイク以上
- 発声開始前の無音または環境音が一定量ある
- クリッピングがなく、開始部が切れていない
- 強い残響、伴奏、明示的な後処理がない、または処理条件を記録できる
- F0 と主な formant を開始部から追跡できる

UTAU 音源だけに結論を依存させない。初期実装には利用できるが、一般化判断では通常発話または単独発声として収録条件の明確な別系統の参照を追加する。

### 6.2 split

既存の比較評価用 split と混同せず、この研究用に次を定義する。

- `onset-development`: 区間検出、特徴設計、刺激条件の調整
- `onset-checkpoint`: 最初の試聴とモデル選択
- `onset-holdout`: 凍結した候補の最終確認だけに使用

同一話者、同一原音、同じ連続収録からの切り出しを split 間で共有しない。既存の比較評価で使用済みの holdout 回答を、新しい指標やモデルの調整に再利用しない。

### 6.3 台帳

各入力と派生刺激について、少なくとも次を保存する。

- 元ファイル識別子と hash
- 話者、母音、テイク、収録条件
- 権利・利用条件
- split
- 検出された発声開始、安定開始、終了時刻
- 加工手順、設定、乱数 seed
- 人間音声を含む実験刺激か、完全生成音か
- 最終方式への採用可否

## 7. 時間区間の定義

境界を単一の RMS 閾値だけで決めない。次の候補点を別々に保存する。

| 境界 | 意味 |
| --- | --- |
| `acoustic_activity_onset` | 背景より音響エネルギーが明確に上昇した点 |
| `periodicity_onset` | 有声周期性が継続して検出され始めた点 |
| `stable_pitch_onset` | F0 が局所的な許容幅へ入った点 |
| `stable_source_onset` | CPP、HNR、spectral tilt 等が安定域へ入った点 |
| `stable_vowel_onset` | F1/F2 軌道が定常値近傍へ入った点 |

一つの「onset 時刻」に縮約する前に、これらの時間差を測る。開始部は原則として `acoustic_activity_onset` から `stable_vowel_onset` までとし、固定長 40、80、160、240 ms の窓も併用する。

境界検出器は信頼度を出し、低信頼例を自動除外または目視確認候補へ送る。全ファイルの手作業ラベル付けを前提にしない。

## 8. 刺激実験

### 8.1 実験 A: 人間音声内の切除とループ

最も交絡が少ない主実験とする。同じ録音から次を作る。

| 条件 | 内容 | 調べるもの |
| --- | --- | --- |
| A0 | 元の発声 | 上限アンカー |
| A1 | 開始部を残し、定常部を自然に短縮 | 短時間化そのものの影響 |
| A2 | 開始部を除き、定常部だけを再生 | 開始部の寄与 |
| A3 | 定常部を長い区間でループ | 軽度の反復性 |
| A4 | 定常部を短い区間でループ | 完全反復の影響 |
| A5 | A4 に測定済み低周波変動を再付与 | 微細変動による回復 |
| A6 | A4 に独立ランダム変動を付与 | 相関構造の必要性 |

ループ条件では、周期境界または相関の高い境界を選び、equal-power crossfade を使う。クリック、音量差、明瞭な位相飛びを自動検査し、「ループが不自然」なのか「定常反復が非人間的」なのかを混同しない。

### 8.2 実験 B: 開始部と持続部の交換

次の条件を作る。

| 条件 | 開始部 | 持続部 |
| --- | --- | --- |
| B0 | 人間 | 人間 |
| B1 | なし | 人間 |
| B2 | 人間 | 現行合成 |
| B3 | 現行合成 | 人間 |
| B4 | 現行合成 | 現行合成 |
| B5 | 新しい開始モデル | 現行合成 |

交換前に F0、RMS、formant の代表値、スペクトル傾斜を可能な範囲で一致させる。接続部は複数の crossfade 長で自動検査し、接続アーティファクトの大きい刺激は試聴へ出さない。

B2 が B4 より高く、B3 が B4 と同程度なら、開始部の寄与を支持する。ただし人間開始部が人間音声の断片そのものを含むため、最終方式の成立を意味しない。B5 に効果を移せるかを必ず確認する。

### 8.3 実験 C: 合成開始部の要因除去

完全生成音だけを使い、次を段階的に追加する。

1. 定常合成音＋ゲイン包絡のみ
2. F0 の確立軌道を追加
3. 周期性の確立と cycle-to-cycle 変動を追加
4. spectral tilt、開閉特性、非調波成分の軌道を追加
5. formant の収束軌道を追加
6. 全要因を相関させた状態遷移を追加
7. 6 の時間軌道を崩して独立ランダム化した対照

単純に機能を足した順の優劣だけを比較しない。各要因を全モデルから一つずつ除く ablation も作り、どの成分が必要かを診断する。

### 8.4 実験 D: 持続部の非定常性

開始モデルを固定した後、持続部で次を比較する。

- 完全定常
- 周期的 vibrato のみ
- F0 の非周期的な低周波ドリフト
- 振幅の低周波ドリフト
- cycle-to-cycle jitter / shimmer
- spectral tilt とノイズ量の緩やかな変動
- 実測した相関構造を持つ結合変動
- 同じ分散だが相関と時間順序を崩した変動

変動量を大きくして効果を見せるだけでなく、人間参照分布内、境界付近、分布外の 3 段階を用意する。自然さが最大になる範囲と、単に「揺れて聞こえる」範囲を分ける。

## 9. 自動解析

### 9.1 フレーム単位の軌道

既存 extractor の F0、RMS、spectral centroid、flatness、onset/stable 情報を再利用し、次を開始部向けに拡張する。

- F0、voicing probability、周期長
- RMS、peak、crest factor
- CPP、HNR、非調波エネルギー比
- H1-H2、調波スペクトル傾斜
- spectral centroid、band energy、flatness
- F1/F2/F3 と bandwidth
- 各特徴の一次差分、二次差分、安定値までの距離
- 特徴間の遅延、相関、安定化順序

フレーム長は一種類に固定せず、短い開始現象と F0/formant 推定の安定性を両立するため、複数解像度を使う。生の時系列、平滑化系列、推定信頼度をすべて保存する。

### 9.2 周期単位の解析

有声周期を追跡できる区間では、次を測る。

- 周期ごとの長さと振幅
- 周期波形の相互相関
- 閉鎖に相当する急峻度の近似
- 周期性が安定域へ入るまでの周期数
- jitter / shimmer の局所値と時間変化

波形から信頼して推定できない量は「声帯の物理量」と断定せず、音響的 proxy として名前を付ける。逆フィルタリングや glottal closure instant 推定は、基礎的な軌道解析で不足が確認された場合に追加する。

### 9.3 軌道の表現

各特徴を単一平均値へ潰さず、次を併記する。

- 開始値、安定値、変化量
- 10%、50%、90% 到達時間
- overshoot と undershoot
- 最大変化速度
- 安定化時間
- 軌道間の時間差
- 低周波成分と cycle-to-cycle 成分の分散

これにより、「F0 が不安定」という一語を、開始時の上昇、長期ドリフト、周期ごとの揺れに分解する。

## 10. 合成モデル

### 10.1 最初の状態遷移モデル

初期モデルは次の状態を持つ。

```text
pre-phonation
  -> airflow / aspiration
  -> irregular oscillation growth
  -> modal establishment
  -> articulatory convergence
  -> nonstationary sustain
```

連続パラメータとして、少なくとも次を制御する。

- 周期励振の振幅
- F0 と周期性
- glottal pulse の開閉比または同等の声質パラメータ
- spectral tilt
- aspiration / 非調波成分
- F1/F2/F3 と bandwidth
- 各状態の継続時間と遷移曲線

ノイズは完成した周期音へ独立に加えるだけにせず、声門状態と同じ包絡または状態変数へ結び付ける。F0、振幅、声質、ノイズの変化にも共有する低次元の状態を持たせる。

### 10.2 調音軌道

「舌足らずさ」は曖昧な印象語として残さず、次の候補へ分解する。

- formant が目標から始まり、遅れて収束する
- 特定 formant だけ到達が遅い
- 目標を overshoot / undershoot する
- 帯域幅が開始時に広く、その後狭くなる
- 発声ごとに到達時間と軌道が小さく異なる

最初は測定軌道を補間曲線で近似する。必要性が確認された後に、舌・顎・唇などの調音器パラメータへ置き換える。

### 10.3 より物理的なモデルへ進む条件

次のいずれかが確認された場合に、lumped-mass 声帯モデルや声門流・声道結合を次段階として検討する。

- 少数パラメータの状態遷移では、人間開始部の主要な軌道相関を再現できない
- 声量や onset type を変えたとき、個別曲線の貼り替えでは一般化しない
- 衝突、閉鎖速度、圧力の発達を表すことで、複数の観測特徴を同時に説明できる見込みがある
- パラメトリックモデルの複雑さが、簡易物理モデルと同等以上になる

物理モデルは目的ではなく、観測された関係をより少ない仮定で説明し、制御可能にする選択肢として扱う。

## 11. 評価方法

### 11.1 自動評価の役割

自動評価は次に使う。

- 音量、F0、長さなど比較条件の統制
- クリック、切断、clipping、aliasing の除外
- 軌道が意図した操作方向へ変化したかの確認
- 人間参照分布から大きく外れる候補の除外
- 同じ特徴しか変わらない重複候補の削減
- Pareto front による試聴候補の選定

既存の Human-likeness 総合値は使用しない。カテゴリ別の生測定値と target similarity は診断に利用できるが、自然さの代理にはしない。

### 11.2 自動 gate

試聴候補は少なくとも次を満たすこととする。

- signal integrity に重大な失敗がない
- 比較意図に反する音量差がない
- F0 や formant を統制する実験では、許容範囲内に一致している
- 接続・ループ境界に局所的なピークや明瞭な不連続がない
- 目的とする操作以外の主要特徴差が記録されている
- 入力、設定、出力を hash から再現できる

許容値は development fixture で決め、試聴結果を見て都合よく変更しない。

### 11.3 試聴軸

試聴では次を分離する。

- 人間の声として聞こえるか
- 実際に発声している感じがあるか
- 目的母音として聞こえるか
- 声質が自然か
- 開始部が自然か
- 持続部が自然か
- 接続、クリック、ループなど加工由来の違和感があるか

「好み」は主要評価に混ぜない。自由記述では、掠れ、息、舌足らず、楽器的、機械的、周期的などの印象語を保存し、後から音響特徴との対応候補を作る。

### 11.4 試聴形式

主比較には、絶対評定だけでなく条件間の差を検出しやすい対比較を使う。

- A/B 強制選択: どちらが人間の発声に近いか
- 同点可の属性比較: 開始の自然さ、持続の自然さ
- 少数候補の 1〜5 評定: 過去評価との接続
- 同一刺激の重複: 評価者内一貫性
- 人間原音、加工人間音、現行合成: 尺度アンカー

1 評価者の結果はプロジェクト内の設計判断には使えるが、人間一般についての知覚的主張には使わない。一般化した結論が必要になった段階で、複数評価者、順序の均衡化、評価者間一致を導入する。

目的:

完了条件:

### フェーズ 2: 刺激生成とアーティファクト検査

目的:

- 実験 A と B の刺激を、試聴に依存せず生成・品質検査できるようにする

作業:

- 区間切除、時間短縮、周期整列ループ、crossfade、開始部交換を実装する

完了条件:

- 人間音声を含む刺激に実験限定ラベルが付く

ユーザーチェック: 不要。ここでは試聴を求めない。

### フェーズ 3: 開始部と持続部の特徴軌道

目的:

- 平均値では見えない時間変化を数値化する

作業:

- フレーム系列と周期系列を抽出する
- 安定値への到達時間、変化速度、overshoot を計算する
- 特徴間相関と安定化順序を集計する
- 話者内、話者間、母音間の分布を分ける
- 推定器の既知変形テストを追加する

完了条件:

- 各刺激について開始軌道を表とプロットで再現できる
- 既知の F0 ramp、amplitude ramp、jitter、formant transition に指標が反応する
- 欠損率と推定信頼度が報告される

ユーザーチェック: 不要。

### フェーズ 4: 人間開始部の低次元記述

目的:

- 合成へ移せる最小限の状態とパラメータを選ぶ

作業:

- 特徴の冗長性と相関を分析する
- 開始様式ごとの代表軌道と範囲を求める
- 独立ランダム変動と相関変動を区別する生成設定を作る
- 話者固有差より一貫する時間関係を優先して抽出する

完了条件:

- どの軌道を共有状態から生成するか説明できる
- パラメータが人間参照分布と対応する単位または範囲を持つ
- 不要な特徴を追加し続ける構成になっていない

ユーザーチェック: 不要。

### フェーズ 5: 簡易 onset 合成モデル

目的:

- 完全生成音で実験 C を成立させる

作業:

- 現行 Web 合成器またはオフライン renderer に状態遷移を実装する
- ゲイン、F0、周期性、声質、ノイズ、formant 軌道を段階的に追加する
- 全要因追加と一要因除去の ablation を生成する
- パラメータ sweep を自動実行する

完了条件:

- C1〜C7 と ablation を完全生成音として再現できる
- 操作した各軌道が測定上も意図どおりである
- 人間音声断片が生成物へ混入していない

ユーザーチェック: 不要。この段階では音を保存するが、採否判断を求めない。

### フェーズ 6: 自動比較と試聴候補の凍結

目的:

- 試聴数を抑え、結果を見て候補を差し替えることを防ぐ

作業:

- signal integrity と実験統制 gate を適用する
- 同等候補をクラスタリングまたは特徴距離で削減する
- 仮説ごとに対照を保った最小候補集合を選ぶ
- 音量正規化、匿名化、提示順 seed、重複刺激を固定する
- checkpoint 提示集合と回答前 hash を保存する

完了条件:

- 各仮説に必要な条件が欠けていない
- 1 セッションが過大でない
- 回答前に候補と分析手順が凍結されている

ユーザーチェック: 原則不要。再生できることの技術確認だけが必要な場合がある。

### フェーズ 7: 第1試聴チェックポイント

目的:

- H1、H3、H6 と簡易 onset モデルの方向性を確認する

実施順:

1. 実験 A の原音、開始部除去、長短ループ
2. 実験 A の相関変動と独立変動
3. 実験 C のゲインのみ、全要因、主要 ablation
4. 必要な場合だけ実験 B の交換条件

判断:

- 開始部の効果があるか
- ループによる低下が splice artifact 以外にもあるか
- どの要因を残して次へ進むか
- 「掠れ」「舌足らず」等の印象がどの操作と対応するか

完了条件:

- 全回答が schema を満たす
- 重複回答の一貫性を確認する
- H1、H3、H6 を支持、反証、未判定に分類する
- 次の実装へ残す要因を、結果を伴って記録する

ユーザーチェック: 必要。この計画で最初の本格的な試聴とする。

### フェーズ 8: 持続部非定常モデル

目的:

- 開始部の効果と持続部の微細変動を分離し、長い発声でも反復的に聞こえないモデルを作る

作業:

- 実験 D の変動モデルを実装する
- 分散、帯域、相関、時間スケールを参照分布から設定する
- vibrato と非周期ドリフトを別パラメータにする
- 同じ分散で時間順序を崩した対照を作る
- フェーズ 7 で不要と判断された要因を無条件に復活させない

完了条件:

- 定常、vibrato、独立変動、相関変動を比較できる
- 変動量が人間範囲内か分布外かを報告できる
- ループ長を変えても、同一の短周期パターンが露出しない

ユーザーチェック: 不要。

### フェーズ 9: 新規 holdout と最終試聴

目的:

- 凍結した完全生成モデルが、未使用条件でも改善するか確認する

作業:

- `/a/` の checkpoint で選んだモデルを `/i/`、`/u/` へ移す
- パラメータ規則を固定する
- 未使用話者・未使用テイクに対する onset-holdout 評価集合を作る

- 自動結果と試聴結果を別々に報告する

完了条件:

- checkpoint の回答を使った再調整後に、同じ回答を検証へ再利用していない
- 現行方式との差が、複数刺激で同じ方向を示す
- 音素同一性を損なって自然さだけを上げていない
- 結果が支持、限定支持、棄却のいずれかとして記録される

### フェーズ 10: 統合判断

目的:

判断候補:

- 簡易状態遷移モデルを Web プロトタイプへ採用
- onset の一部だけを採用し、持続変動は保留
- onset は有効だが簡易モデルへの移植に失敗したため、物理モデル研究へ進む
- 仮説を棄却し、別の要因へ優先順位を移す

完了条件:

- 完全生成音と研究限定刺激を明確に分ける
- 採用パラメータの意味、範囲、失敗条件を記録する

ユーザーチェック: 試聴結果の解釈に不明点がある場合のみ必要。

## 15. 成功条件

この研究の成功は「人間と区別できない音声」の達成ではなく、次を満たすことで判断する。

1. 開始部と持続部の寄与を、加工アーティファクトから分離して比較できる
2. 人間らしさへ寄与する時間軌道を、少なくとも一つ支持または反証できる
3. 人間音声断片を含まない生成モデルへ、その効果を移す試験ができる
4. 現行方式との差を、自動測定と試聴の双方で説明できる
5. 改善が音素同一性や明瞭さの低下による錯覚ではない
6. checkpoint と未使用 holdout を分け、結果を見た後の過適合を避ける
7. 効果がなかった要因も否定結果として再現可能に残す

自然さの単一総合点を作ることは成功条件にしない。まず開始部、持続部、音素同一性、加工アーティファクトを別々に判断できることを優先する。

## 16. リスクと対策

### ループの継ぎ目を非人間性と誤認する

対策:

- 周期整列、複数 crossfade、境界自動検査を行う
- 長いループと短いループを比較する
- 同じ処理を十分長い原音へ適用した control を置く

### 人間開始部と合成持続部の不一致を開始部の効果と誤認する

対策:

- F0、RMS、formant、spectral tilt を統制する
- 交換実験だけで結論せず、人間音声内切除と完全生成 ablation を併用する
- 接続違和感を独立評価軸にする

### ランダム変動を増やすほど自然になると誤解する

対策:

- 同じ分散で相関だけ異なる対照を作る
- 人間分布内と分布外の変動量を分ける
- roughness と naturalness を別に評価する

### ノイズを掠れ・息として扱いすぎる

対策:

- 周期成分との結合、spectral tilt、CPP/HNR の時間変化を同時に扱う
- 白色・高域ノイズの単純加算を対照条件にする
- 「息が多い」と「付加ノイズに聞こえる」を別項目にする

### 参照データの偏り

対策:

- UTAU、単独発声、通常発話由来の短母音を分けて報告する
- 話者単位 split を守る
- 話者、性別・年齢、収録条件を一般化できない場合は明記する

### 特徴抽出誤差を物理現象と誤認する

対策:

- 既知信号 fixture と複数設定で推定器を検証する
- 信頼度、欠損、設定間不一致を保存する
- 音響 proxy と声帯の直接測定を言葉上も区別する

### 試聴負担が増える

対策:

- フェーズ 0〜6 と 8 は試聴不要で進める
- 自動 gate、重複削減、対比較で提示数を抑える
- 第1チェックポイントと最終 holdout の2回に主要試聴を集約する

## 17. 優先順位

### 最優先

1. onset / stable 境界の再現可能な検出
2. 人間音声内の開始部切除・定常ループ実験

## 18. 最初の実装単位

最初の実装では、全フェーズを同時に始めず、次を一つの縦断的な最小実験として完成させる。

対象:

- `/a/`
- 3 話者以上
- 各 2 テイク以上
- A0〜A4
- 固定窓 40、80、160、240 ms

実装:

- onset / stable 検出
- 周期整列ループと crossfade
- F0、RMS、CPP、HNR、spectral tilt、F1/F2 の軌道
- signal / splice gate
- manifest、CSV/JSON、比較プロット

この最小実験で、刺激の再現性と加工アーティファクトの除外を確立する。その後に A5/A6、交換実験、完全生成モデルを追加する。試聴は完全な A 系列と最低限の合成対照が揃うまで行わない。

- [Comparing Measures of Voice Quality From Sustained Phonation and Continuous Speech](https://pmc.ncbi.nlm.nih.gov/articles/PMC5345563/)
