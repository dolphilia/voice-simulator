作成日: 2026-09-13  
状態: 実行中。E0点検不通過で規則どおり終了、P1固定刺激準備済み・知覚未確認。詳細は[実行報告](../note/independent-voice-synthesis-execution-report.md)  
設計根拠: [音声合成研究・E0実施提案 v3](../note/independent-voice-synthesis-proposal-v3.md)

## 1. 目的と今回の到達点

最終目的は、録音素片や学習済み音声生成器を最終音源にせず、説明・制御・検証できる生成機構から人間に近い音声を出力することである。人間の録音や機械学習は測定・推定・評価に利用できるが、録音由来の波形表、高密度な制御列、録音に合わせた乱数種などを最終音源の供給源にはしない。

今回の実行範囲は、次の三つに限定する。

1. **E0:** 公開された2つの声道模型の振幅応答をP5/P5Zで近似し、有限の手順で基準を満たす具体例が得られるか確認する。
2. **結果固定:** P5を残すか、P5Zも後続の比較候補として持ち越すかを形状別に決定し、再現可能な記録を残す。
3. **P1接続準備:** 選んだ固定フィルタから試聴可能な音圧信号へ至る処理を実装・点検し、限定した試聴候補を準備する。

E0の合格は人声としての成立を保証せず、不合格は発声生成を停止する理由にも、声道を複雑化する許可にもならない。正式な知覚判定はP1の別契約で行う。

## 2. 計画の適用範囲と仕様の正本

数式・候補選定・数値設定はv3を設計上の正本とする。本計画は、その仕様を実装・実験・記録へ落とす作業順序と完了条件を定める。実装者の判断で閾値やモデルを置き換えない。

開始時にv3の内容hashと、機械可読に転記した設定を保存する。文書と設定の不一致は適合前に解消する。矛盾や実装不能が見つかった場合は、その箇所だけを未解決事項として記録し、合格しやすい規則へ暗黙に変更しない。

新しい実験は独立したワークスペースに置く。既存プロジェクトの候補、試聴回答、採否、プリセットを、本実験の入力や探索の初期値に使用しない。過去の計画・結果は変更しない。

今回は行わないこと:

- 新しい極数・零点数・音源補正の比較。
- 自然音声からの音源・声道の同時推定。
- 話者適応、共通制御、他音素・動的発声への一般化。
- EGG、新規収録、模型製作、三次元計算。
- 知覚予測器・MOS予測器・ASRの導入。
- Webプロトタイプへの組込みや既定音の変更。

## 3. 実験条件

| 項目 | 固定する内容 |
|---|---|
| データ | DVTDの `s1-01-bahn-tense-a-vvtf-measured.txt` と `s1-03-tiere-tense-i-vvtf-measured.txt` |
| 入手先 | v3に記載された著者の公式配布物。取得・ファイル完全性確認は未実施 |
| 測定対象 | 指定境界条件の声門側から口唇側への体積流量比。人間の発声音圧全体ではない |
| 判定帯域・サンプルレート | 100〜5,000 Hz、16,000 Hz |
| モデル | P5: 極5対。P5Z: P5に零点1対を追加。ρ=0で厳密に包含 |
| 変数範囲 | 周波数100〜7,500 Hz、B=1〜3,000 Hz、ρ=0〜0.999、g>0 |
| 分割 | 帯域内を周波数順に並べ、1始まりの偶数行をDfit、奇数行をDcheck |
| 誤差 | dB誤差のRMSをR、最大絶対値をM、`J=max(R/1 dB, M/3 dB)` |
| 利得 | v3の区間交差と二分探索によって、Dfit上で同じJを最小化。平均誤差ゼロには固定しない |
| 選定 | 各形状・モデルに一候補。Dfitの `(J,R,M,開始点番号,評価順番号)` の辞書順 |
| 合否 | `Q=max(J_fit,J_check)`。Q≤0.999は合格、Q≥1.001は不合格、その間は境界で判断不能 |
| 知覚上の意味 | 上記の数値は設計上の工学基準。可聴差や自然さの閾値ではない |

Dcheckは独立した再測定ではなく、近隣周波数への補間点検である。点数を独立標本数として信頼区間を作らない。評価側は測定表を保持できるが、固定候補を評価する生成器へ渡すのはフィルタ変数と周波数座標だけとする。

## 6. 必須検証

実装に似た処理をもう一度書くだけのテストではなく、誤った採否や信号変換を検出する検証を優先する。

### 6.1 E0の数値核

- **K0:** v3の偏った100点の誤差を使い、平均ゼロの利得では最大誤差が不合格でも、同じ候補が利得変更によって合格可能であることを確認する。±0.6 dBの対照とのJ順位も確認する。
- **K1:** v3の既知P5について、ρ=0のP5Zとの複素応答一致、真値代入、未知開始点からの自己回復を検証する。
- **K2:** v3の帯域内零点の効果を直接確認し、P5Zの自己回復を検証する。P5が不合格であることは要求しない。
- 利得区間が空・接触・非空となる境界、定数誤差、J=0を扱う。二分探索後の実際のR/M/Jを必ず再計算する。
- Dcheckの値を変更しても、凍結前の候補とgが変わらないことを検証する。
- 選定済みP5をP5Z候補集合へ含め、包含関係に反した成績を検知する。
- 評価上限、途中最良候補の保持、早期停止、候補固定後の再適合禁止を検証する。
- 非有限値、範囲外、列・単位不整合を、単なる高い損失や欠損の無視として処理しない。
- 合格・不合格・境界・留保の組合せを用いた判定表の検証を行う。

数学的な自己回復と、公開測定への近似と、人声品質の成立は別の結果として出力する。

### 6.2 P1の接続

- 正弦流量の微分で振幅が2πf倍、位相が+π/2となる。
- 微分形音源を流量へ戻す経路と、流量入力の経路が一致する。
- 同じ入力に対するP5とρ=0のP5Zの出力が一致する。
- 折り返しを生じる倍音を生成せず、共通の帯域制限を適用する。
- レベル調整の履歴を保存し、リミッタやEQなしでクリッピングを防ぐ。
- 再生用のサンプルレート変換で16 kHz用係数を別レートへ誤用しない。

これらは工学検証であり、通過しても人声としての成立は認定しない。

## 7. 探索の実行規則

外側の探索はv3の有界修正Powell法を用いる。変数の正規化、Bの対数対応、PCG64・種20260913、4開始点の構成、極の保存時の並べ替え、数値停止条件をそのまま設定へ転記する。

S1は `xtol=1e-4, ftol=1e-6`、S2は `xtol=1e-6, ftol=1e-8` とする。S1で全点検が通ればS1を採用し、不通過の場合だけS2で一度全点検を行う。両方不通過なら終了する。点検対象を簡単にしたり、開始点を追加して通したりしない。

| 予算枠 | 上限 |
|---|---:|
| 公開測定: 2形状×2モデル×4開始点×2,000評価 | 32,000 |
| 既知応答: S1/S2合計 | 32,000 |
| 直接代入・Dcheck等の別枠 | 1,000 |
| E0全体 | 65,000 |

一評価の定義はv3に従い、利得二分探索では同じ誤差ベクトルの統計量を再利用する。計数を探索ライブラリ任せにせず外側でも管理する。別枠で応答を何回計算したかも保存する。

早期停止で余った予算を別開始点や測定へ回さない。P5Zは選定P5に依存するため、各形状でP5選定後にP5Zを実行する。全4候補の固定前にDcheckを採用判断へ使用しない。

v3の「予算内停滞」「境界の留保」「補間の留保」を機械的に計算する。合格候補は達成の具体例なので、停滞していないことや境界への近接だけで合格を取り消さない。不合格側に留保がある場合は拡張選択の根拠にしない。

公開測定への追加探索は0回、E0終了後のモデル構造変更も0回とする。実装誤りを発見した試行は無効として保持し、修正結果を元の試行の成功へ書き換えない。

## 8. 結果別の次の行動

| 結果 | 保存する判断 | 次の行動 |
|---|---|---|
| P5合格 | 指定数表・帯域の振幅基準達成 | P5を固定してP1接続へ |
| P5不合格・留保なし、P5Z合格 | 固定手順ではP5Zが基準達成に有用 | P5とP5Zを比較候補としてP1へ。P5を知覚的に棄却しない |
| 両候補不合格・留保なし | 今回の具体例は未達 | P5を未達の比較基準としてP1準備へ。次数は増やさない |
| 採否境界または不合格側に留保 | 拡張選択は判断不能 | P5を未確認の比較基準として保持して終了 |
| 入力・点検・実装の有効性なし | 公開測定に関する結論なし | 問題を限定して報告。可能なP1接続準備は進める |

P5の有効な適合結果が得られない場合、接続の数値検証にはv3のK1を使用できる。これは合成した既知モデルであり、公開測定への合格例とは扱わない。応答計算自体が不正なら先にその問題を解決する。

E0の成否で旧計画の結果を更新したり、別方式の優劣を推定したりしない。人声らしさ、物理装置への絶対精度、数学的な表現不能、未知話者への一般化は報告しない。

## 9. P1接続準備と、人の関与の境界

P1の信号経路はv3に従い、次の一本に固定する。

```text
解析的な声門流量 Ug
  → 保存したP5/P5Z（16 kHz、gを含む）
  → 口唇流量 Ul
  → p(f)=C・j2πf・Ul(f)
  → 共通帯域窓W(f)
  → 同一RMSへのスカラー調整と共通下方調整
```

流量の交流成分を扱い、微分形LF出力は非ゼロ周波数で流量へ戻す。観測側の微分は一度だけ適用する。v3の遠方場近似定数を固定し、測定VVTFに別の終端負荷を追加しない。

共通窓は100 Hz以下・5,000 Hz以上で0、100〜200 Hzと4,500〜5,000 Hzを半コサイン、200〜4,500 Hzを1とする。位相は候補式が決めるものであり、測定位相を移植しない。提示フェードを開始・終了の自然さの証拠にしない。

P1-1開始前に、解析的LFの採用式、形状定数、F0、U0、長さ、フェード、レベル、候補一覧を `p1-connection.json` へ固定する。必要な外部一次資料は調べてよいが、別方式の大規模比較や耳による逐次調整は追加しない。探索して良く聞こえる値を後付けした場合は、固定刺激による試験とは区別する。

P1-2は新たな試聴を必要とする。開始前に別の試聴契約で、問い、対照、対象参加者、回答形式、提示順、終了条件、結果の解釈範囲を定める。E0の1 dB・3 dBを知覚合格基準へ転用しない。

人が回答できない場合も、P1-0・P1-1までの実装と検証、成果物の保存は完了させる。その後は「固定刺激準備済み・知覚未確認」と報告する。追加の候補や試聴義務を無制限に積み上げず、予定した範囲で終了する。

## 11. この計画の完了条件

E0は、合格だけでなく、仕様に従って未達または判断不能を確定した場合も終了できる。ただし「公開測定について結論なし」と「有効な候補が未達」を分ける。

今回の自律作業範囲は、次をすべて満たしたとき完了とする。

- E0が仕様どおり終了し、結果と限界を再現可能に保存した。
- 有効なモデルがある範囲でP1接続の数値点検と刺激準備を完了した。
- 未実施の知覚判断を、音響値で代用していない。
- 次に必要な人の判断または外部入力を、固定された候補・具体的な不足とともに提示できる。
- 未達を理由に追加探索やモデル拡張を無計画に始めていない。

取得不能や実装上の未解決事項で必要な工程を終えられない場合は、計画全体を完了とせず「外部入力待ち」または「実装未完了」とする。独立して進められる工程を終えたうえで、不足と再開条件を保存する。仕様で定めた点検不通過によるE0終了と、未修正の実装不具合による中断も区別する。

その先の声道精密化、共有制御、音素拡張、知覚予測器は、P1や接続点検から具体的な根拠が得られた時点で、別の実験として計画する。
