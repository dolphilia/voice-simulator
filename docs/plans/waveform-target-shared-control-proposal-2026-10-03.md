# 実波形で到達した制御を共有規則へ移す比較案

2026-10-03。未実行の新1 campaign案。[片側差分比較の結果](../note/guarded-waveform-reachability-result-2026-10-03.md)は開発4文すべての到達性・内容保護を通過した。次の問いは、参照依存の逆推定で得た制御を、文章入力だけで生成できる固定サイズの非ニューラル関数へ移せるかである。無人実行・最終非ニューラル方針を継続する。

## 今回変えるもの

旧共有モデルの教師は、教師音声DIOとHMM状態LF0の差であり、実波形の誤差を直接最小化していなかった。次は**実際の非ニューラル波形で受理された逆推定制御を訓練目標にする**。同じ16特徴、直接回帰、研究用ニューラル、蒸留回帰を比較し、目標を変えた効果と学生への移行損失を分ける。

DIO＋StoneMask、教師区間、HMM区間、対象母音・鼻音、50%／3有声フレーム、中心化先行・一様縮尺±3半音、4基底の逆推定、状態継続長・MSD・スペクトル・非周期性・LF0動的平均の固定を維持する。局所タイミングや声質を同時に変えない。日本語の測定器・自然さが資格を得たとは扱わない。

### 1. 入口と逆推定目標

21文の状態snapshotを旧入力と比較し、ゼロ残差と既存の入口監査を検証する。現在4文の既定・状態目標候補はWAV hashまで一致させ、全入口検査完了前に探索・fit・ASRへ進まない。残り17文の共通支持域は、教師採用区間と新しい既定DIOの積集合で生成前段に一度だけ固定する。除外区間、独立文数、支持域数を保存し、候補に合わせて削除・補間しない。

現在と同じ、各係数±3、±0.25差分、通常更新最大0.5、正則化0.1、最大3反復とする。両側有効は中央、片側有効は片側差分、両側無効は停止。通常更新が無効・非改善のときだけ同方向1/2、1/4を試し、追加生成は各文合計3回まで。実波形の正則化目的が厳密に減った候補だけ受理する。

固定支持域欠損0、有限、E0、内部不変、最終実波形MSEが既定未満かつ状態目標候補以下、全体DIO・ACF差5%以内、活動長差3%以内の文だけを学習目標にする。不通過をゼロ目標や成功へ変換しない。採否と残差を全21文について保持する。短文・長文の双方を含む12独立文以上が通過しなければ、共有fit・新文生成・AIを始めず資料不足で終了する。この標本数は運用上の最低数であり、統計的な品質保証ではない。

### 2. 同じ共有表現で3方式を学習

受理済み係数から、実行時と同じ全対象有声音素・同じ中心化／縮尺で得た音素残差を訓練目標にする。測定に採用した支持域だけで訓練予測を中心化する旧の不一致を再導入しない。状態MSDから対象集合を決め、ラベル・特徴・生成した状態残差の一致を検査する。音素区間やフレーム数を独立発話数へ加算しない。

- 直接非ニューラル：旧16特徴の回帰16係数、ridge 10、発話等重み。
- 研究用ニューラル：同じ16入力、幅16・tanh2層・1出力、seed 20261003、500 step、Adam 0.005、weight decay 0.001。
- 学生：同じ16特徴・16係数・ridge 10で研究NNの訓練文上の予測を近似する。ネットワーク自体をCへ翻訳しない。

正規化は訓練群だけで固定。発話内中心化・最大絶対値3への一様縮尺を予測経路と最終レンダラーで一致させ、非有声・休止は変更しない。発話ID、WAV、教師特徴、保存軌跡を実行時入力に含めない。fitは3回だけで、同じcampaign中に正則化・特徴・ネットワーク規模を調整しない。旧状態目標版の共有モデルは保存対照として保持し、目標変化による制御差と費用を併記する。

### 3. 実波形で転移と内容を比較

旧12診断文では、保存済み教師に対する通常／変更条件の中心化F0形状を、各条件の既定から一度固定した共通支持域で比較する。教師内区間とHMM区間の対応は既存手法のまま、測定不能は欠損とする。新8文は新教師を作らないため、内容・工学・制御干渉を評価し、教師に対する局所F0改善を主張しない。

既存12文と新8文を別々に、従来の全体・短・長・4指定群について通常／変更／合算の21群で評価する。各認識器で既定以下のかな誤り、欠損0を診断保護とする。両集合を合算して片方の悪化を隠さない。辞書読み診断は主CERを書き換えない。

共有制御の研究上の採択には、全波形でE0・内部不変・固定支持域通過、対照同条件に対するDIOとACFの全体F0差5%以内・活動長差3%以内、新旧両集合の全内容保護、旧12文の発話等重みF0-MSEが通常／変更それぞれで全体・短・長の各群で既定以下かつ全体は厳密に改善、を認識前に固定する。NN・直接・学生を同じ条件で判定し、直接と学生の差、NNから学生へ移したときのMSE・かな誤り・干渉・モデル量を記録する。学生を無条件で選ばない。

### 4. 非ニューラル単独実行

直接・学生だけの固定サイズbundleを作り、ニューラル重み・推論エンジン・教師・参照音声・訓練記録・ネットワークを遮断した独立プロセスで新8文を生成する。通常実行とのWAV hash一致、モデル量が訓練文数に比例しないこと、文章から制御を計算していることを検査する。研究NN、発話別係数、参照依存WAVをこのbundleへ配布しない。

## 結果による次の判断

NNだけが通る場合は学生の表現・中心化・飽和の損失を保存し、次の表現拡張を別案にする。直接と学生が同程度なら費用と複雑さの小さい直接経路を優先する。どれも通らなければ目標の文間ばらつき、アクセント前段、局所時間、励起・スペクトルを分けて調べる。同じ枠で特徴や予算を増やさない。

この比較が成功しても、日本語非ニューラルの知覚資格、局所閉鎖・開放・摩擦・声質、独立最終品質確認は未達である。最終品質を宣言せず、次に変える機構を証拠から選ぶ。本案は新しい上限の承認後に実施し、現在の封印済みcampaignを再開しない。
