# voice-simulator

> **Note**
> この README は、プロジェクトの方向性を整理するための草稿です。内容は研究・実装の進展に応じて更新されます。

`voice-simulator` は、人間の発声に近い音声を、明示的かつ制御可能な生成機構によって合成することを目指すプロジェクトです。

声道、声帯、喉頭、呼気などの物理・音響モデルは重要な選択肢ですが、プロジェクトの目的を特定の方式に限定しません。物理シミュレーション、調音・音響モデル、ソース・フィルタモデル、フォルマント合成、手続き的な DSP、規則ベースの制御、それらのハイブリッドなどを比較し、人間の発声へ近づくために有効な方法を採用します。

一方で、録音音声の断片や加工音声を最終的な音源として再生する方式、大量の音声で学習した生成 AI やニューラルボコーダに音声生成を委ねる方式は、最終的な合成方式の対象外とします。人間の音声は、測定、比較、評価、パラメータ推定などのリファレンスとして利用します。

研究途中の原理検証や比較では、目的と由来を記録したうえで、既存音声の加工や一時的なサンプル利用を許容します。また、生成 AI は、新しいリファレンスやテストケースの作成、ラベル付け、解析・実験の自動化などに利用できます。ただし、その出力や学習済み音声生成機能を最終シンセサイザーの中核にはしません。

## 設計上重視すること

- 音がプロジェクト内の生成モデルから生み出されること
- 発声を構成する要素を明示的に制御できること
- 生成過程を説明、観察、検証できること
- 特定の録音音声がなければ発声できない方式に依存しないこと
- 一つの理論や実装方式に早期に固定しないこと

将来的には、母音・子音、発声の開始と終了、声質、調音運動、話者差などを扱えるようにすることを目指します。2D・3D の可視化や、直感的な操作と詳細な制御を両立するインターフェースも検討対象です。

## リポジトリの主な領域

- `research/`: 仮説検証、解析、評価、パラメータ推定、自動化を行う、言語や実行形式を限定しない研究領域
- `web/`: 音やモデルを対話的に操作し、聴覚・視覚の両面から確認する Web プロトタイプ
- `docs/`: 方針、調査結果、実験の要約、実装計画

研究・解析では、再現可能な処理を通常のプログラムや CLI として実装することを基本とします。Notebook は、グラフや音を人が順に確認する場合、対話的な操作に価値がある場合、説明と実行結果を一体で残す場合に選択します。

これまでの調査、解析、数値実験、Web プロトタイプの成果と課題は、[`docs/note/research-review-2026-08-13.md`](docs/note/research-review-2026-08-13.md) に総括しています。
